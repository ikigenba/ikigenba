# Decision 49 — Env-channel conformance: composed inventory root, manifest-surfaced tuning knobs, and a Spec-derived drift oracle

**Problem.** Three prompts values sit outside the suite's configuration
channels (root `project/design/D21.md`), and the manifest drift proof has a
hole:

- `PROMPTS_MANIFEST_ROOT` (the box inventory root the runner reads at run
  spawn) defaults to a compiled-in `"/opt"` at `cmd/prompts/main.go` — the
  box-path-literal pattern the root env contract forbids.
- `PROMPTS_RUN_TTL` is an env read with a code default no production channel
  states.
- **The Spec and the committed manifest have already drifted**: the compiled
  `Spec.ManifestExtras` declares `PROMPTS_MAX_INFLIGHT_CALLS` and
  `PROMPTS_MAX_CONCURRENT_RUNS`, but `prompts/etc/manifest.env` lacks both
  lines — and the R-8IAN-FB87 test did not catch it because it emits from a
  **hand-built `manifest.Fields` literal** rather than the compiled Spec. The
  oracle restates the answer instead of reading it, which is exactly the drift
  the adopted contract exists to prevent.

**Decision.** Bring every value into its channel and close the oracle hole.

1. **The inventory root composes from `IKIGENBA_ROOT`** (root
   `project/design/D11.md`): the read at the domain boundary becomes the
   contract ladder — explicit `PROMPTS_MANIFEST_ROOT` override wins; else a
   non-empty `IKIGENBA_ROOT` is the root (`/opt` on a box, where run spawns
   discover `<root>/*/etc/manifest.env`); else the dev fallback `.` (a
   `bin/start` checkout runs from the repo root, where `<svc>/etc/manifest.env`
   resolves). No `"/opt` literal remains in prompts production Go source.

2. **The tuning knobs surface in the manifest.** `Spec.ManifestExtras` gains
   `{Key: "PROMPTS_RUN_TTL", Value: "30m"}` after the two concurrency knobs it
   already declares, and the committed `prompts/etc/manifest.env` gains the
   three missing lines in Spec order:

   ```
   PROMPTS_MAX_INFLIGHT_CALLS=8
   PROMPTS_MAX_CONCURRENT_RUNS=8
   PROMPTS_RUN_TTL=30m
   ```

   The reads are unchanged (`config.EnvOrInt` / `config.EnvOrDuration`); in
   production the launcher exports every manifest key, so the manifest line is
   what the process receives, and the code defaults become dev fallback that
   must agree with the manifest's stated values.

3. **The drift oracle derives from the compiled Spec.** The composition root
   exposes its `Spec` through a `promptsSpec()` builder (the sanctioned shape
   notify/cron/gmail/sites already use; `main` passes `promptsSpec()` onward,
   and the closures keep their existing `storeRef`/`svcRef` capture wiring).
   The R-8IAN-FB87 test emits `manifest.Emit` over **`promptsSpec()`'s own
   fields** — App, Mount, Default, Port, MCP, Feed, Consumes, and
   `ManifestExtras` mapped verbatim — and byte-compares against the committed
   file, so a Spec-side extras edit that skips the committed manifest (this
   exact incident) fails the suite. The hand-built `manifest.Fields` literal in
   `TestManifestLibraryByteEqualsCommittedFile` is deleted.

4. **Adoption of the box-path-literal guard.** This Decision adopts the root
   env contract's `[proof: per-service]` id **R-VKB6-SHHV** (root
   `project/design/D11.md`): a source-scan test in `cmd/prompts/main_test.go`
   walks prompts' non-test `.go` files and fails on any `"/opt` string literal.

5. **The run TTL is bounded per the run-lifetime contract.** This Decision
   adopts `root project/design/D26.md`: `PROMPTS_RUN_TTL` is validated at the
   composition root against the contract's hard **6h** maximum (a named
   constant), and a configured value over 6h — or zero/negative — refuses to
   boot: `serve` exits nonzero with an error naming `PROMPTS_RUN_TTL`, the
   configured value, and the maximum. The run-token lifetime derives from this
   bounded value (D56); there is no other cap anywhere.

Classification notes (root `project/design/D21.md`), recorded so no value is
channel-less: `PROMPTS_OPENAI_AUTH_PATH` and `DROPBOX_BASE_URL` are dev-only
overrides with composed/derived production defaults (channel 4); the five
provider API keys are customer data in the app-config parameter (channel 2,
already declared by `.envrc`); `PROMPTS_CALLS_BODY_RETENTION_DAYS` is already a
channel-1 manifest knob.

**Rejected.**
- *Leave the drift test's hand-built `Fields` literal and just add the missing
  lines.* Restores byte agreement today and re-arms the same silent divergence
  tomorrow — the oracle must read the compiled Spec, not restate it. Rejected.
- *Put the run/concurrency knobs in the app-config parameter.* They are
  universal tuning, identical for every account; the parameter is for
  customer data. Rejected — channel 1.
- *An `os.Executable`-derived inventory-root fallback.* Couples path policy to
  install location; the root contract already rejected it for the one composed
  `IKIGENBA_ROOT`. Rejected.

**Verification.**
- R-M51H-QWOL — the inventory-root resolution follows the ladder exactly: with
  `PROMPTS_MANIFEST_ROOT=/x` set the resolved root is `/x` regardless of
  `IKIGENBA_ROOT`; with only `IKIGENBA_ROOT=/y` set it is `/y`; with neither it
  is `.` — never `/opt`. Substrate: unit test over the resolver with an
  injected `getenv`.
- R-M69E-4OFA — with no environment set, the resolved values of
  `PROMPTS_MAX_INFLIGHT_CALLS`, `PROMPTS_MAX_CONCURRENT_RUNS`, and
  `PROMPTS_RUN_TTL` equal the values stated in the committed
  `prompts/etc/manifest.env` (parse the committed file, compare against the
  code's resolved defaults) — an edit to either side alone fails. Substrate:
  unit test in `cmd/prompts/main_test.go` reading the committed manifest.
- Adopts **R-VKB6-SHHV** (root `project/design/D11.md`, `[proof: per-service]`)
  — no `"/opt` string literal in prompts' non-test Go source. Substrate: the
  source-scan test in `cmd/prompts/main_test.go`.
- Adopts **R-34EZ-J9BF** (root `project/design/D26.md`,
  `[proof: per-service]`) — with `PROMPTS_RUN_TTL=7h`, `serve` fails at
  startup: exits nonzero, error output names `PROMPTS_RUN_TTL` and the `6h`
  maximum, no server starts; with `PROMPTS_RUN_TTL=6h` it boots. Substrate:
  hermetic test driving the serve path with an injected environment.
- The closed oracle hole is proven by the **existing** adopted id R-8IAN-FB87
  (owned by D15's adoption): its test now emits from `promptsSpec()`'s fields,
  so it fails on the currently-committed tree until the manifest lines land —
  no new id; the substrate is corrected, not the behavior.
