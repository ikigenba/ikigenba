# Decision 48 — State paths come from `appkit/config`, never from a hardcoded `./tmp` default

## Decision

The composition root resolves prompts' durable state and cache roots through
`appkit/config`, the same resolver the chassis itself uses, instead of reading
`PROMPTS_DB_PATH` and `PROMPTS_GENERATION_PATH` out of the environment with
hardcoded fallbacks.

`config.Resolve` composes the suite's fixed on-box layout from `IKIGENBA_ROOT`
and honours an explicit `PROMPTS_DB_PATH` / `PROMPTS_GENERATION_PATH` override
when one is set, so the env contract is unchanged and simply moves behind the
chassis call:

```go
cfg, err := config.Resolve("prompts", "/srv/prompts/", registry.MustPort("prompts"), os.Getenv)
...
stateDir := filepath.Dir(cfg.DBPath)         // prompts.db, auth.json, runs/ (D39)
cacheDir := filepath.Dir(cfg.GenerationPath) // reclaimable generation sidecar
runsDir := filepath.Join(stateDir, "runs")
```

**The resolved values do not change.** With `IKIGENBA_ROOT=/opt` this yields
`/opt/prompts/state` and `/opt/prompts/cache`, exactly where the live database,
durable run directories, and generation cache already sit, so nothing on disk
moves. With the root
unset, as in a repo-root dev launch, it yields a `tmp`-rooted pair, exactly
today's dev default. This Decision changes only *where the default comes from*,
not what it is.

**What the old shape got wrong** is that the fallback was written as a literal
`"./tmp/prompts.db"` reached whenever `PROMPTS_DB_PATH` was absent, so the
binary ignored `IKIGENBA_ROOT` entirely and depended on something outside it
exporting the variable. When the on-box manifest stopped carrying those keys the
default became reachable in production, where a relative `tmp` resolves under
the root-owned service directory and startup fails on `mkdir`. The
`GENERATION_PATH` fallback had a second, quieter failure: it defaulted the cache
root to the *state* directory, so the reclaimable generation sidecar landed in
durable state.

**The state/cache split is preserved and is the point of using both fields.**
`cfg.DBPath`'s directory is durable state — the database, the OpenAI credential
file, and the `runs/<run_id>/` tree (D39); `cfg.GenerationPath`'s directory is
reclaimable cache — the generation sidecar. D39's rule that a run directory is
durable is why `runs/` resolves under state rather than cache, and this Decision
changes no path it resolves to.

**Nothing else moves.** The runner, the sandbox model (D5), the two loaders
(D40), `run_delete` (D41), and the calls surface (D28/D32) are untouched; they
receive the same absolute roots they receive today.

## Rejected

**Keep reading the env vars directly and re-add the keys to
`etc/manifest.env`.** Rejected: the manifest is committed and shipped per
version, so it can only carry facts true in every environment, and an absolute
`/opt/...` is a box fact. The root is already supplied per environment by
`IKIGENBA_ROOT`, and duplicating the composed layout in a config file lets the
two drift.

**Drop the `PROMPTS_DB_PATH` / `PROMPTS_GENERATION_PATH` overrides entirely.**
Rejected: `config.Resolve` already honours them, so they cost nothing to keep,
and `bin/start` uses them to pin dev state under the repo's `tmp/`. Removing a
working override is a behaviour change this Decision deliberately excludes.

**Add a `Router` accessor (`rt.DBPath()`) and read it from `Spec.Handlers`.**
Rejected: that is an `appkit` change, outside this project's scope boundary.
`config.Resolve` is already exported and pure, so the composition root can call
it directly with no chassis change at all.

## Verification

- R-LBH5-4LO0 — with `IKIGENBA_ROOT=/opt` in the injected environment and no
  explicit path overrides, the composition root's resolution returns a state
  directory of exactly `/opt/prompts/state`, so the durable runs root is
  `/opt/prompts/state/runs` (D39); a build that still falls back to a
  `tmp`-rooted literal fails.
- R-LCP1-IDEP — under the same rooted environment, the resolved cache directory
  is exactly `/opt/prompts/cache` and is **not** equal to the state directory,
  pinning the state/cache split that the old `GENERATION_PATH` fallback
  collapsed.
- R-LDWX-W55E — with `PROMPTS_DB_PATH` and `PROMPTS_GENERATION_PATH` both set to
  unrelated absolute paths and `IKIGENBA_ROOT=/opt` also set, resolution returns
  those overrides verbatim for the state and cache roots, so the explicit knobs
  still win over the composed defaults.
