# Decision 60 — The prompts-owned peer MCP client

## Decision

`prompts/internal/mcpclient` is the service's own minimal MCP client — the
dispatch substrate the suite gateway (D19) and the catalog fan-out (D6) stand
on. It exists because agentkit's MCP client is `internal` and unexported
(research §2), and it speaks exactly the wire contract in research §8: JSON-RPC
2.0 over HTTP POST to a peer's loopback `/mcp`, methods `initialize` (+ the
`notifications/initialized` notification), `tools/list`, and `tools/call`.

**Package shape**:

```go
package mcpclient

// Doer is the transport seam. The composition root passes the chassis's
// instrumented outbound client (rt.HTTPClient(...)), so every peer hop emits
// an appkit `outbound` telemetry record; tests pass an httptest-backed client.
type Doer interface {
    Do(*http.Request) (*http.Response, error)
}

// Client speaks MCP to one peer. baseURL is the peer's loopback /mcp endpoint;
// headers are injected on every request the client makes.
func New(doer Doer, baseURL string, headers map[string]string) *Client

// Instructions performs initialize and returns the server-level instructions
// string (empty when the server sends none).
func (c *Client) Instructions(ctx context.Context) (string, error)

// ListTools performs the initialize handshake then tools/list.
func (c *Client) ListTools(ctx context.Context) ([]Tool, error)

// CallTool performs the initialize handshake then tools/call, forwarding
// args verbatim as the request's arguments object.
func (c *Client) CallTool(ctx context.Context, name string, args json.RawMessage) (Result, error)

type Tool struct {
    Name        string
    Description string
    InputSchema json.RawMessage // relayed byte-verbatim; never parsed here
}

type Result struct {
    Text    string // concatenated text content blocks
    IsError bool   // the MCP result's isError flag
}
```

**Stateless per call.** A `Client` holds no connection state; each exported
method performs its own initialize handshake before its operation. On-box
loopback round-trips are sub-millisecond and gateway calls are rare within a
run, so no session or cache is kept — and when the suite later migrates to a
protocol revision without the handshake (research §8), the change is confined
to this package.

**Schemas are relayed, never interpreted.** `InputSchema` passes through as raw
bytes. This client validates nothing about a peer tool's arguments — the peer's
own validation (structured errors per D27) is authoritative, and the gateway
(D19) frames those errors for the model.

**Error taxonomy.** An unreachable peer, a non-2xx response, a malformed
JSON-RPC envelope, or a JSON-RPC error object each return a Go error that names
the peer's service; a well-formed `tools/call` result with `isError: true` is
**not** a Go error — it returns `Result{IsError: true}` so the gateway can
relay it as a tool result the model can react to.

## Rejected

- **Reusing agentkit's MCP client** — it is `internal/mcp`, unexported by
  design; there is nothing to import.
- **A persistent per-peer session (initialize once, cache the connection)** —
  state to invalidate, for a handful of loopback calls per run; and the
  handshake itself is scheduled for removal in the next protocol revision.
- **Parsing/validating peer schemas in the client** — a second validator that
  can drift from the peer's authoritative one, plus a new dependency, to
  pre-empt an error the peer already reports well (D27). Violates
  validate-at-the-boundary: the service boundary is the boundary.
- **A bare `*http.Client` instead of the `Doer` seam** — loses the chassis's
  instrumented outbound client at the composition root, and with it the
  `outbound` telemetry record per peer hop that D45 now claims.

## Verification

- R-OLVJ-TO7G — `ListTools` against a recording `httptest` peer performs
  `initialize` then `tools/list` on the peer's `/mcp` path, every request
  carrying the configured headers verbatim, and returns the peer's tools with
  `Name`, `Description`, and byte-identical `InputSchema`. A build that skips
  the handshake or drops a header fails this.
- R-OOBC-L7OU — `CallTool` forwards its `args` bytes as the `tools/call`
  `arguments` object byte-for-byte (asserted from the recording peer's view)
  and returns the result's concatenated text with `IsError` reflecting the
  peer's `isError` flag — a peer answering `isError: true` yields
  `Result{IsError: true}` and a nil Go error.
- R-OPJ8-YZFJ — every HTTP request the client makes goes through the injected
  `Doer` (a counting fake observes one `Do` per wire request and zero requests
  reach any default transport), which is what lets the composition root supply
  the chassis's instrumented client.
- R-OQR5-CR68 — against a peer that refuses connections, and separately a peer
  answering a JSON-RPC error object, each exported method returns an error
  whose message contains the client's configured service name; no method
  panics.
