# Decision 6 — `bin/bintest` proves the library-dependency contract (`root project/design/D22.md`)

**Decision.** The umbrella's library-dependency contract,
`root project/design/D22.md`, designates this tree as its **proof tree**: every
one of its Verification ids is marked `[proof: bin]`. The checks are inherently
repo-root-scoped — they read **every committed `go.mod` in the repo** plus the
committed `go.work` — so no single service's suite can own them, and
`bin/bintest` (D5's Go test module, already under the repo's green gate) is the
existing home for exactly this kind of check.

This Decision adds one test file to the `bintest` module carrying the four
contract behaviors, tagged with the umbrella's ids (owned by
`root project/design/D22.md`, minted there, not here):

- **R-3R5W-79JK** — in-repo libraries (`appkit`, `eventplane`, `registry`) are
  required at exactly `v0.0.0` with a matching relative `replace` (`../<lib>`).
- **R-3SDS-L1A9** — module paths in committed `go.mod` files are plain literals
  (no escape-carrying quoted strings; parsed path and written bytes agree).
- **R-3TLO-YT0Y** — all `github.com/ikigenba/agentkit` requires across the repo
  state one identical version.
- **R-3UTL-CKRN** — the committed `go.work` carries no `replace` directive.

Mechanics, per the contract's substrate line:

- `go.mod` discovery walks the repo root (the `bintest` package's ancestor, the
  same resolution D5 uses for scripts), taking every committed `go.mod` except
  ones under `testdata/` directories (fixtures are not consumers).
- Module facts are read from the **parsed module graph** — `go mod edit -json`
  per `go.mod`, `go work edit -json` for the workspace — never from a raw-text
  grep an escaped string could evade. The plain-literal check (R-3SDS-L1A9)
  additionally reads the raw file bytes and asserts each parsed module path
  appears verbatim.
- The tests run under the existing gate (`go test ./...` in `bin/bintest`); no
  new runner, no new module.

**Rejected.**
- *A shell script check in `bin/`.* The untested-tier rule (Conventions) is the
  point: a checker that nothing runs automatically rots exactly like the checks
  it replaces. `bintest` rides the enforced gate. Rejected.
- *Raw-text grep of `go.mod` files.* Already defeated once in this repo by a
  `\x`-escaped module path written specifically to evade a grep; the parsed
  module graph is the substrate that cannot be fooled by spelling. Rejected.
- *Proving the contract per-consumer (`[proof: per-service]`).* The agreement
  check (one agentkit pin repo-wide) is a property of the *set* of modules, not
  of any one consumer; fifteen local tests each seeing one `go.mod` cannot
  state it. One repo-scoped check can. Rejected.

**Verification.** This Decision mints **no ids of its own**: the four behaviors
above are owned and minted by `root project/design/D22.md`; this tree realizes
them as tagged tests in `bin/bintest`. They enter this tree's plan (the phase
that builds the test file) exactly like local ids.
