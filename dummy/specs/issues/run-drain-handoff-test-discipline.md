# Run drain handoff exceeds permitted test discipline

Filed during user-invoked `build-spec` for dummy at initial commit `48231bba3c6a3d73140dbf900a07ad0e0dbe3527`, after independent validation of the CLI leaf's coverage limitation.

R-ECC1-7TVM requires `Run` to pass `server.Serve` exactly five seconds for absent or empty `DRAIN_SECONDS`, exactly the accepted number of seconds when representable, and the largest `time.Duration` otherwise. R-DSTN-3I0I declares no serving or timer observation callback. dummy's AGENTS.md permits “the one `Run`-level overrun test” with `DRAIN_SECONDS=1`, alongside short `Serve`-level drain tests; it prescribes a real loopback or Unix listener and readiness synchronization. It also prohibits tests reading or inspecting source.

The leaf's helper tests cover duration calculation for defaults, ordinary values, representable limits and saturation; its real `Run` overrun observes one-second forwarding. These do not prove the other required handoff values. A counterexample keeps the helper unchanged and substitutes six seconds only when the parsed drain is five seconds immediately before calling `Serve`. The helper assertions and permitted one-second overrun still pass, but the default handoff violates R-ECC1-7TVM. Distinguishing that behavior through `Run` requires an additional default-drain timing case outside the prescribed one-second overrun.

This is a conflict with the declared test discipline, not absolute unobservability or an implementation defect. Go 1.26's standard `testing/synctest` offers fake time that could advance very large durations instantly. A default or saturated fake-time `Run` overrun would still be an additional overrun with a value other than one; pure in-memory transport would additionally replace the prescribed real listener. Hidden aliases, source inspection or an undeclared timer callback cannot establish the requirement within this build run's authority.

Evidence: the CLI coverage report `/tmp/scratch.CaIfBr`, prior challenge `/tmp/scratch.GuoF88`, and fresh dedicated validation `/tmp/scratch.qoGqsU`. The dedicated verifier explicitly considered standard fake time and confirmed the narrower test-discipline conflict. No gate failure is alleged; current implementation forwards the calculated drain, but the full requirement remains untagged rather than claiming incomplete proof.

Suggested resolution: permit additional deterministic `Run` drain cases and explicitly support simulated time and transport, or use `draft-design` to declare an observable serving/timer seam and re-mint the affected requirement. Neither read-only contract nor AGENTS.md can be changed during this run.
