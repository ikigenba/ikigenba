# Decision 11 — GitHub's outbound calls move onto the shared instrumented HTTP client

**Problem.** Every call `github` makes off the box — the app-JWT →
installation-token exchange in `internal/gh/token.go` and every REST v3 request
in `internal/gh/client.go` — currently runs on a client the service never
really builds: both `tokenSource.client()` and `Client.client()` fall back to
**`http.DefaultClient`**, and the composition root
(`internal/githubapp/spec.go`) passes `nil` in both the `Config` and `Handlers`
hooks. So the connector's entire conversation with GitHub is invisible to the
suite's telemetry, and it runs with **no timeout at all** — a hung GitHub
response parks the calling goroutine forever.

**Decision.** `github` keeps its existing injection seam — the
`httpClient *http.Client` parameter on `gh.NewClient`, which every offline test
uses to drive a stub `RoundTripper` — and changes what the **default** is: the
composition root supplies appkit's shared instrumented client, and the
package-level fallback stops being `http.DefaultClient`.

Consumed from appkit's design (see `project/research/research.md` — `github`
designs none of its internals):

```go
// appkit/httpclient
func New(opts httpclient.Options) *http.Client   // Options{Recorder, Timeout, Base}
```

`internal/githubapp/spec.go`, in the `Handlers` hook:

```go
hc := httpclient.New(httpclient.Options{
    Recorder: rt.Recorder(),      // nil when telemetry is disabled — still a working client
    Timeout:  30 * time.Second,
})
client, err = newGitHubClient(cfg, hc)
```

and both fallbacks in `internal/gh` become the instrumented client, so no code
path can reach `http.DefaultClient`:

```go
func (c *Client) client() *http.Client {
    if c.http != nil {
        return c.http
    }
    if c.ts != nil {
        return c.ts.client()
    }
    return httpclient.New(httpclient.Options{Timeout: 30 * time.Second})
}
```

with `tokenSource.client()` resolving the same way. `gh.NewClient` continues to
hand the one `*http.Client` it is given to both the REST `Client` and the
embedded `tokenSource`, so the **app JWT exchange and the installation-token
mint are recorded exactly like a REST call** — which is the traffic most worth
seeing when the connector stops authenticating.

**The `Config` hook keeps passing `nil`.** `Spec.Config` constructs a client
solely to validate that `IKIGENBA_APP_PRIVATE_KEY` parses; it issues no
request, and it runs before the runtime (and therefore the recorder) exists.
Its `nil` now resolves to the instrumented-shaped fallback rather than
`http.DefaultClient`, which costs nothing and records nothing because no call
is made.

**What `github` does not do.** The recording itself — `kind` `outbound`, the
`<METHOD> <host><path>` op, status, duration, request/response sizes and
digests — and the rule that `X-Correlation-Id` is propagated **only** to
loopback suite peers and never to `api.github.com` are the transport's, proven
by appkit's own ids. `github`'s obligation is exactly that its clients are
built through that transport.

**Judgment calls recorded.** (a) Adopting a **30-second timeout** is a
deliberate behavior change, not an accident of adoption: today there is none,
and an unbounded outbound call in a loopback connector that `prompts`, `scripts`
and `repos` all block on is a real hazard. It is stated here so the change is
reviewed rather than smuggled in. (b) The nil-fallback is filled with an
instrumented-shaped client (a `httpclient.New` with no recorder) rather than
left as `http.DefaultClient`, so there is exactly one way `github` builds an
outbound client and a future call site cannot regress by omission. (c) `Base`
is left at its default; `github` has no custom transport to compose over, and
tests inject a whole `*http.Client` at the existing seam.

**Rejected.**
- **Removing the `httpClient` parameter and building the client inside
  `internal/gh`** — the parameter is how every offline test (and the
  `newGitHubClient` indirection in `internal/githubapp`) drives the client
  without a network; deleting it would rewrite the test suite to gain nothing.
- **Passing the recorder into `internal/gh`** — pushes an appkit runtime
  dependency below the composition root, which this module's convention (all
  environment and runtime wiring read once at the boundary) forbids.
- **Keeping `http.DefaultClient` as the fallback and only wiring the
  composition root** — leaves a live, uninstrumented, untimed path one `nil`
  away, and `Spec.Config` already takes it.
- **A hand-rolled recording `RoundTripper` in `internal/gh`** — duplicates the
  shared transport, and the loopback-only correlation rule would then have
  eight independent implementations to get wrong.
- **Instrumenting only the REST client and leaving `tokenSource` on its own
  client** — the token exchange is the call whose failure the operator most
  needs to see, and the two already share one client.

**Verification.** (Offline, per this module's *Conventions*: injected stub
`RoundTripper`s and `httptest` servers; no unit test performs live network I/O.
The claim that a **real** authenticated GitHub call still succeeds through the
instrumented transport is **not** re-minted here — it is D2's existing
live-substrate id `R-DMUT-QF4A`, the `health` proof run against the live suite
per `project/github-verification.md`, which now exercises this client.)
- R-01NE-H6K8 — the `*http.Client` a `gh.NewClient(cfg, nil)` client resolves
  for a REST call is one built by `appkit/httpclient` — its `Transport` is the
  type `httpclient.NewTransport` returns — and it is **not** `http.DefaultClient`
  and **not** a client with a `nil` `Transport`. A build that restores the
  `return http.DefaultClient` fallback fails this.
- R-02VA-UYAX — the client a `gh.NewClient(cfg, nil)` client resolves for a
  REST call and the client its embedded `tokenSource` resolves for the app-JWT
  and installation-token exchanges are the **same** `*http.Client` value
  (pointer identity), so credential exchanges traverse the same instrumented
  transport; a build that gives the token source its own client fails.
- R-05B3-MHSB — `gh.NewClient(cfg, hc)` with a non-nil `hc` whose `Transport`
  is a test `RoundTripper` uses **that** client for both a REST request and the
  installation-token exchange: the stub observes both round trips and no
  request escapes to the network. The injection seam is unchanged by this
  Decision.
- R-06J0-09J0 — the client `gh.NewClient(cfg, nil)` resolves has a `Timeout` of
  exactly `30 * time.Second` — the discriminating property against today's
  behavior, where `http.DefaultClient`'s zero `Timeout` means a GitHub call can
  hang indefinitely.
