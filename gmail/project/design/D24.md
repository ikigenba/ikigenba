# Decision 24 — Env-channel conformance: the poll interval surfaces in the manifest

**Problem.** `GMAIL_POLL_INTERVAL` (the sync loop's tick, default `60s`, read
via `config.EnvOrDuration` at `cmd/gmail/main.go`) is an operator-facing tuning
knob that sits outside every configuration channel (root
`project/design/D21.md`): its default exists only in code, so no production
channel states or sets it.

**Decision.**

1. **The poll interval is a channel-1 manifest knob.** `Spec.ManifestExtras`
   gains, after the existing retention pair:

   ```go
   {Key: "GMAIL_POLL_INTERVAL", Value: "60s"},
   ```

   and the committed `gmail/etc/manifest.env` gains the same line. The read is
   unchanged; in production the launcher exports every manifest key, so the
   manifest line is what the process receives, and the code default becomes
   dev fallback that must agree with the manifest's stated value. The existing
   drift proof (R-8IAN-FB87, adopted in D13) pins the byte agreement
   automatically.

2. **Channel classifications recorded**, so no value is channel-less (root
   `project/design/D21.md`): `GMAIL_CLIENT_ID` / `GMAIL_CLIENT_SECRET` /
   `GMAIL_REFRESH_TOKEN` are customer data in the app-config parameter
   (channel 2, already declared by `.envrc`); `GMAIL_PORT` / `GMAIL_IP` are
   the standard appkit `<APP>_*` overrides (channel 4), re-read locally only
   to build the attachment content base URL.

3. **Adoption of the box-path-literal guard.** This Decision adopts the root
   env contract's `[proof: per-service]` id **R-VKB6-SHHV** (root
   `project/design/D11.md`): a source-scan test in `cmd/gmail/main_test.go`
   walks gmail's non-test `.go` files and fails on any `"/opt` string
   literal — gmail is clean today, and the guard keeps it that way.

**Rejected.**
- *Leave the poll interval code-default-only.* It is the same class of
  operator tuning the retention knobs already surface; one class, one channel.
  Rejected.
- *Route it through the app-config parameter.* It is universal tuning,
  identical for every account; the parameter is for customer data. Rejected —
  channel 1.

**Verification.**
- R-JWR1-BQ0J — with no environment set, the resolved `GMAIL_POLL_INTERVAL`
  equals the value stated in the committed `gmail/etc/manifest.env` (parse the
  committed file, compare against the code's resolved default) — an edit to
  either side alone fails. Substrate: unit test in `cmd/gmail/main_test.go`
  reading the committed manifest.
- Adopts **R-VKB6-SHHV** (root `project/design/D11.md`, `[proof: per-service]`)
  — no `"/opt` string literal in gmail's non-test Go source. Substrate: the
  source-scan test in `cmd/gmail/main_test.go`.
