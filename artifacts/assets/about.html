How it works

Artifacts are files kept by path. An agent or a service puts a file with an HTTP PUT to /files/<path> and gets it back with a GET, using curl and the caller's bearer token.

The MCP tools carry metadata only: import answers the URL and the headers to put a file, show and list answer the URL to get one, and delete removes one. The bytes never travel through the gateway.

Everyone signed in can read every artifact. Only an artifact's owner can replace it or delete it.

A PUT that carries an X-Artifact-Expires header sets when the artifact expires; once that time passes, the next hourly sweep removes it. Without one it is kept until it is deleted.
