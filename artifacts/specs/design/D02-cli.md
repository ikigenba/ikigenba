# D02-cli

artifacts as a command: what `cli.Run` does with the arguments, the exit codes, `db status`, and the three constants whose text is fixed here — the usage text, the manifest and the nginx fragment — with the two files under `etc/` that copy the last two. It is webhooks' command with artifacts' name, its own manifest and its own fragment.

An empty `Args` means serve (`D03-serve`). `--version` writes `Process.Version` and a newline; `manifest` writes `Manifest`; `--help` writes `Usage`; `db status` writes what appkit's `db.Status` writes for `state/artifacts.db` and `artifacts.Migrations()`. Any other `Args` is a usage error, diagnosed as webhooks diagnoses one: `artifacts: unknown option '<arg>'` or `artifacts: unknown command '<arg>'`, an empty line, and the hint to run `artifacts --help`. A command touches nothing but what it names: `db status` neither creates the database nor `state/blobs/`.

## The manifest

The manifest holds artifacts' name; its description, `pages.Description`; that it is not the default app; that it is an MCP service; that it does not serve guests (`guests = false`), so the host's nginx admits only a request with a credential, to the pages, to `/files/` and to `/mcp` alike; no secrets; an `[env]` table setting `ARTIFACT_MAX_BYTES` to `1073741824` and `IMPORT_SECONDS` to `600`; the `[database]` table that has the host keep and replicate `state/artifacts.db`; a `[resources]` table whose only line is `memory_max = "128M"`, enough because no body is ever held in memory; and, last, a `[home]` table whose only line is `group = "core"`.

## The nginx fragment

The fragment, `NginxConf`, is repos' fragment byte for byte, alignment included: it lifts nginx's body-size limit (`client_max_body_size 0`) so that artifacts, not nginx, enforces `ARTIFACT_MAX_BYTES` and answers 413 (`D05-files`); it turns off request buffering so that a body streams through to artifacts as it arrives; it keeps HTTP/1.1 to the upstream and response buffering on; it gives a transfer an hour each way; and it answers the event bus's two paths, `/events` and `/declarations`, 404 at the public name, as every app's does.

## Recorded decisions

- The fragment is repos' verbatim, as the decisions document asks: a 1 GiB body must stream, and repos already streams pushes of that size through nginx.
- The `[env]` table lists `ARTIFACT_MAX_BYTES` before `IMPORT_SECONDS`, the order `settings.Read` checks them in. `DRAIN_SECONDS` is the space's and is not in the manifest.
- `Manifest` and `NginxConf` are copied into `etc/` byte for byte, which a test proves through the root package's `Etc`.

## Consumer tasks

An operator's host reads `artifacts manifest` and `etc/manifest.toml` to learn the app, its database and its `[env]`, and drops `etc/nginx.conf` into artifacts' server block. A developer runs `artifacts --help`, `artifacts --version` and `artifacts db status` from the install directory. A test calls `cli.Run` with each `Args`, a temporary `Dir` and capturing `Stdout` and `Stderr`, and compares with `cli.Usage`, `cli.Manifest` (built with `pages.Description`), `cli.NginxConf`, `fs.ReadFile(artifacts.Etc(), ...)` and what `db.Status` writes for the same path.

- R-ZO6U-QAG6: The `internal/cli` package MUST export `Manifest` as a string constant whose value is exactly `app = "artifacts"\ndescription = "` followed by the text of `pages.Description` followed by `"\ndefault = false\nmcp = true\nguests = false\nsecrets = []\n\n[env]\nARTIFACT_MAX_BYTES = "1073741824"\nIMPORT_SECONDS = "600"\n\n[database]\nengine = "sqlite"\npath = "state/artifacts.db"\n\n[resources]\nmemory_max = "128M"\n\n[home]\ngroup = "core"\n`.

- R-ZRUJ-VLO9: The contents of `manifest.toml` and `nginx.conf` in the file system the root package's `Etc` returns MUST be exactly the bytes of `cli.Manifest` and `cli.NginxConf` respectively.

- R-ZUAC-N55N: `Run` MUST treat `Args` as a usage error unless it is empty or exactly one of `["--version"]`, `["manifest"]`, `["--help"]` and `["db", "status"]`; the offending argument MUST be `Args[0]` when it is none of `--version`, `manifest`, `--help` and `db` or when `Args` is exactly `["db"]`, `Args[2]` when `Args[0]` is `db` and `Args[1]` is `status`, and `Args[1]` otherwise.

- R-ZWQ5-EON1: When `Args` is not empty, `Run` MUST return without calling `LookupEnv`, `Unsetenv`, `Inherit`, `Now`, `Sleep`, `After`, `ImportAfter`, `Banner` or `MCP`, without reading `Rand` or calling the `Deliver` of `Sink` or `EventSink`, and, unless `Args` is exactly `["db", "status"]`, without creating, removing or changing anything under `Dir`.
- R-ZXY1-SGDQ: When `Args` is exactly `["db", "status"]`, `Run` MUST write to `Stdout` exactly the bytes appkit's `db.Status` writes for a `db.Config` whose `Path` is `filepath.Join(Dir, "state", "artifacts.db")` and whose `Migrations` is `artifacts.Migrations()` over the database as it is when `Run` is called, create nothing under a `Dir` that names an empty directory, and return `ExitSuccess` with nothing on `Stderr` when that call returns nil; and when it returns an error `err`, write exactly `"artifacts: " + r + "\n"` to `Stderr` in one write, `r` being `err.Error()` with every newline replaced by a space, and return `ExitServerFailed`.
