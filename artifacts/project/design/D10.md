# Decision 10 — Test strategy: adopt the suite testing-language contract

## Decision.

artifacts adopts `root project/design/D23.md` whole (cited, not restated) and
records its tree-local layer facts:

- **Layers present: hermetic and composed only**, both in the default gate
  (`cd artifacts && go test ./...`). Hermetic tests use temp-dir
  filesystems, real temp-file SQLite through the real migration runner, the
  real eventplane outbox, deterministic injected clocks, `httptest`,
  committed-file reads, real loopback HTTP between in-process servers, and
  the headless-Chrome wiring proof (D9). Composed tests build the real
  `cmd/artifacts` binary, run `serve`, and reach `/health` over loopback.
- **No live layer**, no `//go:build live` file, and no tree-local manual
  runbook: bringing the assembled stack up behind nginx on `:8080` (real
  session gating, real public download, real signed-link upload through the
  front door) is the suite's manual-layer check, not this tree's gate.
- **Environmental preconditions** beyond the Go toolchain: `go` on `PATH`
  with the module cache resolving the `replace` siblings, a POSIX `bash`
  with `grep`, and a headless-Chrome binary for the D9 browser proof —
  each a hard failure when absent, never a skip.
- **GOWORK mode:** tests, builds, and vet run in workspace mode through the
  repo-root `go.work`; `bin/ship artifacts` forces `GOWORK=off` outside the
  gate.

`AGENTS.md`'s Tests section declares all of the above, and the declaration
plus the skip ban are re-checked mechanically by the two adopted contract
ids below.

## Rejected.

- **A live layer against the deployed box.** Nothing in this tree talks to
  an external provider; every behavior is provable hermetically or
  composed, and the assembled-stack path is exactly what the suite's
  manual layer exists for.
- **Skipping the browser proof when Chrome is missing.** The skip ban is
  the point: a gate that silently skips its only interaction proof reports
  green while proving nothing. Chrome is a declared precondition.
