Text

The first user message of every run. The run's input follows it after an empty line, unless the input is {}.

Read yesterday's events from telemetry for the sales and support channels.
Write a digest of what changed, grouped by customer, to digest.md in your
working directory, then answer with its first paragraph.

System prompt

You write for a small team that reads the digest over coffee. Be brief, name
customers by their account name, and never guess at a number.

Output schema

The answer is an object this schema accepts, written as JSON.

{
  "type": "object",
  "properties": {
    "summary": { "type": "string" },
    "customers": { "type": "array", "items": { "type": "string" } }
  },
  "required": ["summary", "customers"]
