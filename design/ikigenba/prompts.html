prompts

Prompts run by an agent over the suite's models. An agent creates a prompt, naming a model and the text, and runs it; every run keeps its folder, its answer, its transcript and what it cost here.

Your prompts

Each one is a model and the text it is given. A run is one turn: the model reads the text and the input, uses the tools the prompt allows, and its final message is the answer.
