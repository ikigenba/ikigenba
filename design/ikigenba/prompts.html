MCP tools

Agents manage and run prompts with these tools, through the MCP gateway's call and mutate.

list
The prompts you own, by name.
show
One of your prompts, with its model, its text, its tools and its last run.
create
Create a prompt from a model and the text it is given.
update
Change the model, text, system prompt, tools or schema of one of your prompts.
delete
Delete one of your prompts and every run it has.
subscribe
Run one of your prompts each time an event matching a pattern is delivered.
unsubscribe
Stop running one of your prompts on an event it is subscribed to.
run
Start a run of one of your prompts and return its id and status.
runs
The runs of one of your prompts, newest first.
result
One run whole: its details, its usage and cost, its answer so far, and the files it wrote.
cancel
End one of your runs that is still queued or running.
