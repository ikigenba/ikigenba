Self-hosted internal tools

Your team's tools, on a host you own.

Ikigenba runs small, single-purpose services on one Linux host per space. Your people sign in once with their Google Workspace account; every service behind the space knows who they are without writing a line of auth code.

Create a space Read how sign-in works

What you get

Boring infrastructure, on purpose.

Each piece does one job and says exactly what it did. No agents to babysit, no control plane you can't read.

One sign-in for the space

Google Workspace accounts on your domain, and nobody else. nginx asks auth about every request, so services never see an anonymous one.

Identity as two headers

Every upstream request carries X-User-Id and X-User-Email. That is the whole integration.

Tokens for scripts and agents

Personal access tokens from your profile, shown once, stored only as a hash, with 30-day, 90-day, or no expiry.

One host per space

A whole deployment lives on a single Linux box: systemd units, sockets under /run/ikigenba, nginx in front. Easy to reason about, easy to replace.

Backups that restore

SQLite state streams continuously with Litestream. opsctl restore rebuilds a host from it, and that path gets exercised, not just documented.

Two CLIs, clear edges

devctl runs on your machine and manages spaces in AWS. opsctl runs as root on the host. Neither pretends to be the other.

How it works

Three commands to a signed-in service.

  1. Create the space

    From your checkout, with your own AWS credentials. devctl reads the root domain and region from infra/terraform.tfvars.json; it keeps no config of its own.

    $ devctl space create acme
space acme: host i-0c41… running, dns acme.ikigenba.com ready

  2. Install a service on the host

    opsctl lays the release down under /opt, wires its socket and nginx route, and starts it behind the identity check.

    $ ssh acme.ikigenba.com sudo opsctl install dummy
$ ssh acme.ikigenba.com sudo opsctl enable dummy

  3. Call it as yourself

    In a browser you just sign in. From a script, use a personal access token from your profile.

    $ curl -H "Authorization: Bearer $IKP_TOKEN" \
    https://auth.acme.ikigenba.com/me
{"id":"u_7Q2M…","email":"ada@acme.dev"}

Run it on your own AWS account.

The platform is source you build and run yourself. You pay AWS for one small host per space, and nothing else.
