MCP tools

Agents manage and run scripts with these tools, through the MCP gateway's call and mutate.

list
The scripts you own, by name.
show
One of your scripts, with its repository, its ref and its last run.
create
Create a script from one of your repositories and a ref.
update
Change the ref one of your scripts runs from.
delete
Delete one of your scripts and every run it has.
run
Start a run of one of your scripts and return its id, status and commit.
runs
The runs of one of your scripts, newest first.
result
One run whole: its details, its output so far, and the files it wrote.
cancel
End one of your runs that is still running.
