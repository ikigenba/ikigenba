# D04-store

The records: `internal/store`, which owns webhooks' two tables, `webhooks` and `deliveries`, in its SQLite database, `state/webhooks.db`, the rules a slug, a scheme and an id obey, the secrets it mints and how it keeps them, the errors every consumer tells apart, and the one line every consumer answers when the database cannot be reached. Opening, migrating, transactions and the failure seam are appkit's `db`. It follows cron's store, with a second table and a sweep.

## One database, one writer

webhooks is the database's only writer, and the database is the only record of its webhooks and deliveries. What a store holds when its handle is closed is what a store over the next `db.Open` of the same path holds; a test proves the records that way, never by reading tables. `store.New` builds a store over a handle and opens nothing. A store whose handle is failing (`SetFailing(true)`) answers every call with `ErrUnreachable` and changes nothing.

## Webhooks

A webhook's **id** is `whk_` and 16 lowercase hexadecimal digits, 8 bytes drawn from the random source when it is created, drawn again when they are a webhook's id already. Its **slug** follows cron's rule: 1 to 64 characters, a lowercase ASCII letter, then lowercase letters and digits with single underscores between them, never at the end. Slugs are one namespace for the whole space. Its **scheme** is `bearer` or `github-hmac`, fixed at create. Its **owner** is the creating caller's user id, kept with the email that caller's request carried. **Created** and **last received** are UTC to the second; last received is zero until its first delivery.

Its **secret** is minted by the store, at create and at each rotate, from 32 bytes of the random source, in auth's token form: `whs_` and the 32 bytes in unpadded Crockford base32, 52 characters. The store answers the secret to the call that minted it and keeps only what the scheme needs to check it: for `bearer`, its lowercase-hex SHA-256 (`SecretSHA256`); for `github-hmac`, the secret itself (`SecretPlain`), since an HMAC cannot be checked against a hash. That plaintext is an accepted risk, as the decisions document states: the suite has no encryption at rest anywhere.

## Deliveries

A delivery's **id** is `whd_` and 16 lowercase hexadecimal digits, drawn as a webhook's is. A delivery keeps the webhook's id, the time it was received (UTC to the second), its body exactly as sent, and three kept headers — `Content-Type`, `X-GitHub-Event` and `X-GitHub-Delivery` — each the empty string when absent. `Receive` writes the delivery and the webhook's last received in one `DB.Write`, so neither is kept without the other. A body longer than `MaxBody`, 1 MiB, is never kept. Deleting a webhook deletes its deliveries in the same write. `Sweep` deletes every delivery received before a given time.

## Errors

`ErrNotFound`, `ErrSlugTaken` and `ErrInvalid` are answers about the records; every other error satisfies `errors.Is(err, ErrUnreachable)`, and every consumer answers it with `Unreachable`, never quoting the cause. One fixed precedence decides a call that meets several conditions: a done context, then a failing store, then an invalid argument, then a missing record, then a taken slug, then a random source that fails.

## Recorded decisions

- The schema is the one migration `0001_webhooks.sql`: `webhooks` (`id`, `slug` unique, `scheme`, `secret_sha256`, `secret_plain`, `owner_id`, `owner_email`, `created`, `last_received`) and `deliveries` (`id`, `hook_id`, `received`, `content_type`, `github_event`, `github_delivery`, `body`), with indexes on `deliveries.hook_id` and `deliveries.received`. Times are RFC 3339 UTC to the second, which compare as text.
- The two secret columns are separate, exactly one set per scheme, so no reader can mistake a hash for a secret.
- A delivery's body is a `BLOB`, kept byte for byte; content type and the GitHub headers are text, the empty string when absent.
- Ids are drawn before the secret, so a test's random source yields the id's 8 bytes first and then the secret's 32.

## REQUIREMENTS

- R-YIX5-RXG3: The `internal/store` package, imported from the path `github.com/ikigenba/ikigenba/webhooks/internal/store` with the package name `store`, MUST export `type Config struct { Now func() time.Time; Rand io.Reader }`, `type Store`, and `func New(d *db.DB, cfg Config) *Store`, where `db` is appkit's package of that name; a nil `Now` or `Rand` meaning `time.Now` and `crypto/rand.Reader`.
- R-YK52-5P6S: The `internal/store` package MUST export `type Webhook struct { ID, Slug, Scheme, OwnerID, OwnerEmail string; SecretSHA256, SecretPlain string; Created, LastReceived time.Time }`, `type Draft struct { Slug, Scheme, OwnerID, OwnerEmail string }`, `type Arrival struct { ContentType, GitHubEvent, GitHubDelivery string; Body []byte }` and `type Delivery struct { ID, HookID string; Received time.Time; ContentType, GitHubEvent, GitHubDelivery string; Body []byte }`.
- R-YLCY-JGXH: The `internal/store` package MUST export the constants `IDPrefix = "whk_"`, `DeliveryPrefix = "whd_"`, `SecretPrefix = "whs_"`, `Bearer = "bearer"`, `GitHubHMAC = "github-hmac"` and `MaxBody = 1048576`, and `const Unreachable string`, a non-empty copy constant: the line webhooks answers wherever the database cannot be read or written.
- R-YMKU-X8O6: The `internal/store` package MUST export `func ValidID(s string) bool`, `func ValidDeliveryID(s string) bool`, `func ValidSlug(s string) bool`, `func ValidScheme(s string) bool` and `func HashSecret(secret string) string`.
- R-YNSR-B0EV: The `internal/store` package MUST export the variables `ErrNotFound`, `ErrSlugTaken`, `ErrInvalid` and `ErrUnreachable`, each a non-nil `error`, no two equal and none wrapping another.
- R-YQ8K-2JW9: The `internal/store` package MUST export the methods `List(ctx context.Context) ([]Webhook, error)`, `Get(ctx context.Context, slug string) (Webhook, error)`, `Create(ctx context.Context, d Draft) (Webhook, string, error)`, `Rotate(ctx context.Context, id string) (Webhook, string, error)`, `Delete(ctx context.Context, id string) (Webhook, error)`, `Receive(ctx context.Context, hookID string, a Arrival) (Delivery, error)`, `Delivery(ctx context.Context, id string) (Delivery, Webhook, error)` and `Sweep(ctx context.Context, before time.Time) (int64, error)` on `*Store`.
- R-YRGG-GBMY: `ValidID` MUST return true exactly when `s` is `whk_` followed by exactly 16 bytes each in `0`–`9` or `a`–`f`, and `ValidDeliveryID` exactly when `s` is `whd_` followed by exactly 16 such bytes.
- R-YSOC-U3DN: `ValidSlug` MUST return true exactly when `s` is 1 to 64 bytes long, its first byte is in `a`–`z`, every other byte is in `a`–`z`, `0`–`9` or `_`, no `_` is followed by another `_`, and its last byte is not `_`; so that `gh_push`, `a`, `tick`, `a1_b2` and 64 `a`s are valid, and `gh-push`, `GH_push`, `9am`, `_gh`, `gh__push`, `gh_`, `gh.push`, `gh push`, the empty string and 65 `a`s are not.
- R-YTW9-7V4C: `ValidScheme` MUST return true exactly when `s` is `Bearer` or `GitHubHMAC`, and `HashSecret` MUST return the 64 lowercase hexadecimal digits of the SHA-256 of `secret`'s bytes.
- R-YV45-LMV1: When `Create(ctx, d)` returns a nil error, the `Webhook` `x` MUST have an `ID` satisfying `ValidID` and differing from every webhook's the store holds, `Slug`, `Scheme`, `OwnerID` and `OwnerEmail` equal to `d`'s, `Created` equal to `Now()` in UTC truncated to the second and a zero `LastReceived`; the secret it answers MUST be `SecretPrefix` followed by 52 characters of the Crockford base32 alphabet `0123456789ABCDEFGHJKMNPQRSTVWXYZ`; and `x` and every later `Get` of `d.Slug`, on that store and on a store over a later handle for the same path, MUST have `SecretSHA256` equal to `HashSecret(secret)` and an empty `SecretPlain` when `d.Scheme` is `Bearer`, and `SecretPlain` equal to the secret and an empty `SecretSHA256` when it is `GitHubHMAC`.
- R-YWC1-ZELQ: `Create` MUST read exactly 8 bytes from `Rand` for each candidate id, writing `IDPrefix` and those bytes as 16 lowercase hexadecimal digits, drawing again when the candidate is a webhook's id the store holds, and then exactly 32 bytes for the secret, writing `SecretPrefix` and those bytes in unpadded Crockford base32; so that a `Rand` yielding `0x5a` for every byte gives a store that holds no webhook the id `whk_5a5a5a5a5a5a5a5a`.

- R-YYRU-QY34: `Get(ctx, slug)` MUST return the webhook, of any owner, whose `Slug` equals `slug` byte for byte, and an error for which `errors.Is(err, ErrNotFound)` is true when there is none; and `List(ctx)` MUST return every webhook, each once, in ascending byte order of `Slug`, and a non-nil empty slice when there is none.
