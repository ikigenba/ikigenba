# D02-cli

scrapes as a command: what `cli.Run` does with its arguments, the exit codes, and the two constants whose text is fixed here, the usage text and the manifest, with the file under `etc/` that copies the manifest. It is gmail's command with scrapes' name and its own manifest: eleven settings, the `application` group and no secrets. The nginx fragment and `etc/nginx.conf` are `D11-on-a-space`'s; `db status` is `D04-store`'s (R-0LA3-O8TQ, R-0MI0-20KF).

An empty `Args` means serve (`D03-serve`). `--version` writes `Process.Version`, the display string `main` read (`D01-layout-and-run-seam`), and a newline; `manifest` writes `Manifest`; `--help` writes `Usage`; `db status` writes what appkit's `db.Status` writes for `state/scrapes.db` and the root package's `Migrations()` (`D04-store`). Any other `Args` is a usage error: `scrapes: unknown option '<arg>'` or `scrapes: unknown command '<arg>'`, an empty line, and the hint to run `scrapes --help`. A command touches nothing but what it names: `db status` does not create the database, and no command reads the environment, the services file, a sibling or a source.

## The manifest

The manifest is a program-parsed file: opsctl, the sandbox and home read it, so its text is contract and is stated here byte for byte, and `etc/manifest.toml` holds the same bytes. It names the app `scrapes`; its description, decision 1's text, the same as `pages.Description` (`D08-pages`); that it is not the default app; that it is an MCP service (`mcp = true`), so the gateway offers its tools; that it does not serve guests (`guests = false`), so the host's nginx admits only a request with a credential; no secrets, since FMCSA's census, the SBA's PPP files, MnGeo's parcels and the Department of Labor's Form 5500 files are public and need no key; an `[env]` table holding the eleven settings' defaults as strings, in the order `settings.Read` reads them (`D01-layout-and-run-seam`), so the values the host writes into scrapes' environment are the ones scrapes applies when a setting is unset; the `[database]` table that has the host keep and replicate `state/scrapes.db`, the catalog of runs, and nothing else: the run files under `runs/` beside `state/` (`D04-store`) are regenerable by scraping again, so the host neither backs them up nor replicates them; a `[resources]` table whose only line is `memory_max = "256M"`, room for what a run holds at once: one source page held decoded (a Socrata page of 10,000 records, decision 1, more than an ArcGIS page of 2,000 features needs, the MN parcels pass's decision 11), the 16 MiB build buffer of encoded rows, one row per chunk while the chunks merge, and SQLite's page cache; no setting sizes memory, and the dirty page cache the budgeted writes leave is charged to the cgroup and accepted (`D11-on-a-space`); and, last, a `[home]` table whose only line is `group = "application"`: scrapes is the funnel's, not the suite's (decision 1). `DRAIN_SECONDS` is not in `[env]`: it is the space's, as for every app. `SCRAPE_WRITE_BUDGET` and `SCRAPE_PRESSURE_LIMIT` follow `SCRAPE_KEEP_RUNS`, and `FORM5500_YEARS` and `FORM5500_STATES` follow `MN_PARCELS_COUNTIES`, as `settings.Read` reads them. A Form 5500 run holds one record and one batch of a thousand rows at once, its zip being spooled to disk rather than held (`D05-scrapers`), so `memory_max` is unchanged.

## Exit codes

`ExitSuccess` (0), `ExitServerFailed` (1) and `ExitUsage` (2), as every app: a usage error, a setting refused or a socket missing is 2; a database that will not open, a start refused or a drain that ran out on requests is 1.

## Recorded decisions

- The usage text and the manifest are contract, not copy: each is a command's standard output or a file a program parses, so each is spelled here. The usage text's prose is scrapes' own.
- The description is decision 1's text, spelled in `Manifest` and declared with the same value as `pages.Description` (`D08-pages`); a test compares the two.
- The `[env]` values are compared with `settings.Defaults()` (`D01-layout-and-run-seam`), so a default cannot drift between the manifest and the code; `FMCSA_STATES`, `PPP_STATES` and `FORM5500_STATES` are compared with their default codes joined by `,`, `PPP_FILES` and `MN_PARCELS_COUNTIES` with their default names joined by `,`, and `FORM5500_YEARS` with its default years joined by `,`.
- `secrets = []` and `group = "application"` are decision 1's; `memory_max` is decision 1's `256M`, unchanged by the run-file store: its peak is one page, one 16 MiB buffer, one row per chunk and SQLite's page cache, well under it, so it is not raised.
- `[database]` names only `state/scrapes.db`: the run files are deliberately outside `state/`, so neither the backup nor replication takes them.
- No release is named in the manifest or in any requirement.
- `Manifest` is copied into `etc/manifest.toml` byte for byte, which a test proves through the root package's `Etc`; `etc/nginx.conf` is `D11-on-a-space`'s.
- `db status` is stated in `D04-store`, which owns the database; this document only routes `["db", "status"]` to it and names the arguments that are a usage error around it.

## Consumer tasks

An operator's host reads `scrapes manifest` and `etc/manifest.toml` to learn the app, its settings' defaults and its database. A developer runs `scrapes --help`, `scrapes --version` and `scrapes db status` from the install directory. A test builds a `cli.Process` with only `Args`, `Stdout`, `Stderr` and `Dir` (an empty temporary directory) set, calls `cli.Run`, and compares the returned value with `cli.ExitSuccess` or `cli.ExitUsage`, `Stdout` with `p.Version + "\n"`, `cli.Manifest` or `cli.Usage`, and `Stderr` with the exact diagnostic; to prove nothing else is touched it sets every other function field to one that records a call, `Rand` to a reader that records a read, the sinks to captures and `HTTP` to a client whose transport records any request, and asserts none was used and `Dir` is still empty. A test compares `cli.Manifest` with `pages.Description` and with the fields of `settings.Defaults()`, and reads `manifest.toml` from the root package's `Etc()` with `fs.ReadFile` to compare it with `cli.Manifest`.
