# D02-cli

scrapes as a command: what `cli.Run` does with its arguments, the exit codes, and the two constants whose text is fixed here, the usage text and the manifest, with the file under `etc/` that copies the manifest. It is gmail's command with scrapes' name and its own manifest: four settings, the `application` group and no secrets. The nginx fragment and `etc/nginx.conf` are `D11-on-a-space`'s; `db status` is `D04-store`'s (R-0LA3-O8TQ, R-0MI0-20KF).

An empty `Args` means serve (`D03-serve`). `--version` writes `Process.Version`, the display string `main` read (`D01-layout-and-run-seam`), and a newline; `manifest` writes `Manifest`; `--help` writes `Usage`; `db status` writes what appkit's `db.Status` writes for `state/scrapes.db` and the root package's `Migrations()` (`D04-store`). Any other `Args` is a usage error: `scrapes: unknown option '<arg>'` or `scrapes: unknown command '<arg>'`, an empty line, and the hint to run `scrapes --help`. A command touches nothing but what it names: `db status` does not create the database, and no command reads the environment, the services file, a sibling or a source.

## The manifest

The manifest is a program-parsed file: opsctl, the sandbox and home read it, so its text is contract and is stated here byte for byte, and `etc/manifest.toml` holds the same bytes. It names the app `scrapes`; its description, decision 1's text, the same as `pages.Description` (`D08-pages`); that it is not the default app; that it is an MCP service (`mcp = true`), so the gateway offers its tools; that it does not serve guests (`guests = false`), so the host's nginx admits only a request with a credential; no secrets, since FMCSA's census is public and needs no key; an `[env]` table holding the four settings' defaults as strings, in the order `settings.Read` reads them (`D01-layout-and-run-seam`), so the values the host writes into scrapes' environment are the ones scrapes applies when a setting is unset; the `[database]` table that has the host keep and replicate `state/scrapes.db`; a `[resources]` table whose only line is `memory_max = "256M"`, room for one Socrata page of 10,000 records held decoded while it is stored (decision 1); and, last, a `[home]` table whose only line is `group = "application"`: scrapes is the funnel's, not the suite's (decision 1). `DRAIN_SECONDS` is not in `[env]`: it is the space's, as for every app.

## Exit codes

`ExitSuccess` (0), `ExitServerFailed` (1) and `ExitUsage` (2), as every app: a usage error, a setting refused or a socket missing is 2; a database that will not open, a start refused or a drain that ran out on requests is 1.

## Recorded decisions

- The usage text and the manifest are contract, not copy: each is a command's standard output or a file a program parses, so each is spelled here. The usage text's prose is scrapes' own.
- The description is decision 1's text, spelled in `Manifest` and declared with the same value as `pages.Description` (`D08-pages`); a test compares the two.
- The `[env]` values are compared with `settings.Defaults()` (`D01-layout-and-run-seam`), so a default cannot drift between the manifest and the code; `FMCSA_STATES` is compared with the default codes joined by `,`.
- `secrets = []` and `group = "application"` are decision 1's; `memory_max` is decision 1's `256M`.
- No release is named in the manifest or in any requirement.
- `Manifest` is copied into `etc/manifest.toml` byte for byte, which a test proves through the root package's `Etc`; `etc/nginx.conf` is `D11-on-a-space`'s.
- `db status` is stated in `D04-store`, which owns the database; this document only routes `["db", "status"]` to it and names the arguments that are a usage error around it.

## Consumer tasks

An operator's host reads `scrapes manifest` and `etc/manifest.toml` to learn the app, its settings' defaults and its database. A developer runs `scrapes --help`, `scrapes --version` and `scrapes db status` from the install directory. A test builds a `cli.Process` with only `Args`, `Stdout`, `Stderr` and `Dir` (an empty temporary directory) set, calls `cli.Run`, and compares the returned value with `cli.ExitSuccess` or `cli.ExitUsage`, `Stdout` with `p.Version + "\n"`, `cli.Manifest` or `cli.Usage`, and `Stderr` with the exact diagnostic; to prove nothing else is touched it sets every other function field to one that records a call, `Rand` to a reader that records a read, the sinks to captures and `HTTP` to a client whose transport records any request, and asserts none was used and `Dir` is still empty. A test compares `cli.Manifest` with `pages.Description` and with the fields of `settings.Defaults()`, and reads `manifest.toml` from the root package's `Etc()` with `fs.ReadFile` to compare it with `cli.Manifest`.

- R-CU9O-1THF: The `internal/cli` package MUST export `Usage` as a string constant whose value is exactly `"Usage: scrapes [command]\n\nPublic records for agents: MCP tools at /mcp start scrapers and read\ntheir runs and rows, with a page of runs at /, and each run's rows\nstreamed to siblings, on the socket systemd passes in.\nWith no command, serve.\n\nCommands:\n  manifest    print the app manifest\n  db status   print applied and pending migrations\n\nOptions:\n  --help      print this help\n  --version   print the version\n\nExit codes:\n  0  success\n  1  failure\n  2  usage error\n"`.
- R-CVHK-FL84: The `internal/cli` package MUST export `Manifest` as a string constant whose value is exactly `app = "scrapes"\ndescription = "Public records about businesses in range, collected per source as rows per run"\ndefault = false\nmcp = true\nguests = false\nsecrets = []\n\n[env]\nSCRAPE_KEEP_RUNS = "2"\nFMCSA_STATES = "MN,WI"\nFMCSA_MIN_POWER_UNITS = "5"\nFMCSA_STATUS = "A"\n\n[database]\nengine = "sqlite"\npath = "state/scrapes.db"\n\n[resources]\nmemory_max = "256M"\n\n[home]\ngroup = "application"\n`, each `\n` denoting one line feed and each `"` one double quote.
- R-CWPG-TCYT: `cli.Manifest` MUST contain the line `description = "` followed by exactly the text of `pages.Description` (`D08-pages`) followed by `"`, so that the description the manifest publishes and the one the about screen shows are the same string.
- R-CXXD-74PI: The `[env]` table of `cli.Manifest` MUST hold, in this order and as the only lines between the line `[env]` and the empty line that follows it, `SCRAPE_KEEP_RUNS = "`, `FMCSA_STATES = "`, `FMCSA_MIN_POWER_UNITS = "` and `FMCSA_STATUS = "`, followed respectively by the decimal form of `KeepRuns`, the elements of `FMCSAStates` joined by `,`, the decimal form of `FMCSAMinPowerUnits`, and `FMCSAStatus`, each of `settings.Defaults()` (`D01-layout-and-run-seam`), and a closing `"`, so that the defaults the host writes into scrapes' environment are the ones scrapes applies when a setting is unset.
- R-CZ59-KWG7: The contents of `manifest.toml` in the file system the root package's `Etc` returns MUST be exactly the bytes of `cli.Manifest`.
- R-D0D5-YO6W: The `internal/cli` package MUST export `ExitSuccess`, `ExitServerFailed` and `ExitUsage` as untyped integer constants with the values 0, 1 and 2 respectively, and every call of `Run` MUST return one of them and no other value.
- R-D1L2-CFXL: When `Args` is exactly `["--version"]`, `["manifest"]` or `["--help"]`, `Run` MUST write exactly `p.Version + "\n"`, `Manifest` or `Usage` respectively to `Stdout` and nothing else, write nothing to `Stderr`, and return `ExitSuccess`; so that an empty `p.Version` writes exactly `"\n"`.
- R-D2SY-Q7OA: `Run` MUST treat `Args` as a usage error unless it is empty or exactly one of `["--version"]`, `["manifest"]`, `["--help"]` and `["db", "status"]`; the offending argument MUST be `Args[0]` when it is none of `--version`, `manifest`, `--help` and `db` or when `Args` is exactly `["db"]`, `Args[2]` when `Args[0]` is `db` and `Args[1]` is `status`, and `Args[1]` otherwise; so that `["db"]` names `db`, `["db", "bogus"]` names `bogus`, `["db", "status", "extra"]` names `extra` and `["manifest", "extra"]` names `extra`.
- R-D40V-3ZEZ: On a usage error from `Args`, `Run` MUST write exactly `"scrapes: unknown option '" + arg + "'\n\nsee 'scrapes --help' for usage\n"` to `Stderr` in one call to `Stderr.Write` when the offending argument `arg` begins with `-`, and exactly `"scrapes: unknown command '" + arg + "'\n\nsee 'scrapes --help' for usage\n"` otherwise, write nothing to `Stdout`, and return `ExitUsage`; so that `["bogus"]` writes `scrapes: unknown command 'bogus'` and `["--bogus"]` writes `scrapes: unknown option '--bogus'` as its first line.
- R-D58R-HR5O: When `Args` is not empty, `Run` MUST return without calling `LookupEnv`, `Unsetenv`, `Inherit`, `Now`, `Sleep`, `After`, `Banner` or `MCP`, without calling `Rand`'s `Read`, without sending any request through `HTTP`, without calling the `Deliver` of `Sink` or `EventSink`, without taking file descriptor 3 and without sending anything to a notification socket, so that a `Process` whose `Args`, `Stdout`, `Stderr` and `Dir` alone are set is enough for every command; and, unless `Args` is exactly `["db", "status"]`, without creating, removing or changing anything under `Dir`.
