How it works

sessions is the time ledger of the agent sessions people run against this space. On each person's machine the turns command reads the session files Claude Code, Codex CLI and Grok CLI write, and pushes what is new, as that person, every five minutes. A turn is one record: its session and, for a subagent, the session that ran it, the host and the person who pushed it, the working directory, the tool, the model, when it happened, whose turn it was (the person's, the agent's or a tool result's), and the token counts the tool reported. A turn pushed twice is one turn.

No text is kept: no prompt, answer, thought, tool call, tool result or file content. The one exception is a session that began with a command: the command's name and its argument are kept, so a /deliver session can be tied to the document it delivered. The session files stay where the tools wrote them, unchanged.

Every figure is derived from the turns, so a change to a rule, a price or the away limit recomputes them all. Attention is the time a person spends in a session, each turn capped at the away limit; wall time, agent time, tokens and dollars are derived alike, and a subagent's session rolls up into the one that ran it. Dollars come from a price table per model, and the kind of work from rules on host, folder and first command; a session no rule matches is untagged. Every change is made with the tools and recorded in telemetry. This page shows the business's totals by week and kind, never one person's.
