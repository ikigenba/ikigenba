telemetry

The suite's trail of events. Every service on this host records what it does here: each request it serves, each call it makes to a sibling, each MCP tool it runs, and the events of its own domain.

MCP tools

Agents search the trail with these tools, through the MCP gateway's call.

catalog
The services, the events each records, and the attribute keys each carries.
search
The records that match a filter, newest first.
count
How many records match a filter, grouped by a field or a time bucket.
trace
Every record of one request, from every service it touched, oldest first.
