# Decision 10 — Adopt the suite testing-language contract

## Decision.

telemetry adopts the suite's testing-language contract — `root
project/design/D23.md` — by value and without deviation. That contract owns the
four layer names (**hermetic**, **composed**, **live**, **manual**), the rule
fixing each layer by what a test may touch, the `//go:build live` mechanism, the
ban on `t.Skip` outside live-tagged files, and the requirement that every tree
declare its testing facts in its `AGENTS.md`. None of that is restated here.

D7 states telemetry's **substrate** rules — real SQLite, a real loopback
listener, an injected clock — and keeps them; this Decision states which
**layers** those tests sit in, what the tree must declare, and where the proof of
that declaration lives.

- **Layers present: hermetic and composed.** There is **no live layer**:
  telemetry contacts no external service and reads no credential, and its only
  outside-the-process dependency is the chassis recorder, which the e2e layer
  points at the test's own served instance. There is no tree-local manual layer;
  the suite-level full-stack check the contract names belongs to the repo root.
- **The composed tests are `internal/e2e/` and the boot smokes in
  `cmd/telemetry/main_test.go`.** `internal/e2e` stands up the real composed
  service — the actual `appkit.Spec`, a real ephemeral loopback port, a real
  temp-file database with the real migrations — and drives it only through
  `POST /ingest` and `POST /mcp`, including the restart-survival check; the
  contract names exactly that shape as composed. `cmd/telemetry/main_test.go`
  goes one step further and builds the real `telemetry` binary, running `bin/run
  serve` against a temporary `/opt/telemetry/`-shaped tree (D9).
- **Everything else is hermetic**: `internal/record`, `internal/db`,
  `internal/ingest`, `internal/retention`, and `internal/mcp` over temp-file
  SQLite through the real appkit migration runner, plus the `etc/nginx.conf`
  content assertions in `cmd/telemetry/nginx_test.go`. A real loopback listener
  is a hermetic substrate under the contract, so the transport tests that bind
  one without standing up the whole service stay hermetic.
- **Environmental preconditions beyond the Go toolchain: none.** The boot smoke
  invokes `go build`, which is the Go toolchain itself and so not an additional
  precondition. Nothing needs `git`, `python3`, a browser, a credential, or a
  running suite — and the one hazard that could smuggle one in is already closed
  by D9: the smoke disables the chassis recorder rather than posting at
  `registry.BaseURL("telemetry")`, which a stack telemetry does not own may hold.
- **GOWORK mode: workspace for local development, `GOWORK=off` for the
  production build.** telemetry carries its **own** `telemetry/go.work`
  (`use . ../appkit ../eventplane ../registry`) beside its entry in the
  repo-root workspace, so `go test ./...` run from `telemetry/` resolves the
  in-repo libraries through a workspace either way; `bin/ship telemetry` forces
  `GOWORK=off` and resolves them through the committed `replace` directives.
  telemetry is on the standalone-build side of the split the contract
  deliberately declines to unify.
- **telemetry has no `AGENTS.md` at all** — a defect against the contract's
  declaration requirement and against every sibling tree. The phase realizing
  this Decision creates it: what the service is, its layout, its Tests section
  carrying the four declarations above, and its versioning. Until it exists the
  doc-truth id cannot be realized, which is the intended pressure.
- **The declaration is proved, not asserted once.** Both proofs live in
  `cmd/telemetry/main_test.go`, beside the layout and manifest conformance proofs
  of D9, matching the suite pattern of a composition-root test reading
  `../../AGENTS.md` from disk.

The two ids below are the contract's `[proof: per-service]` ids; citing them is
adoption, so they enter telemetry's coverage denominator and are realized by
tests in `telemetry/`.

## Rejected.

- **Restate D23's layer table locally so this design reads self-contained.** A
  local copy of a suite contract goes stale the moment the umbrella Decision is
  rewritten; the suite rule is cite, never restate.
- **Leave the testing vocabulary in D7 and the plan README alone.** D7 calls
  `internal/e2e` "the end-to-end layer" and the plan's done bar carries its own
  no-skip sentence — two homes for words the contract now owns. D7 keeps its
  substrate rules (which are telemetry's own) and the plan keeps its done bar;
  both now name the layer in the contract's terms and cite it rather than
  restating the rule.
- **Fold this into D7 (test strategy).** D7 owns *which substrate falsifies which
  claim* — a telemetry-local architectural question. Adoption of an externally
  owned contract, with two externally owned ids hanging off it, is a different
  kind of statement; keeping it separate keeps legible which Decision states the
  behavior. It also mirrors D9, the other conformance-by-citation Decision.
- **Create `telemetry/AGENTS.md` as a spec artifact now.** Spec authoring is
  docs-only over `project/`; `AGENTS.md` sits outside it and is written by the
  build loop, from the phase this Decision produces. Naming the gap here and
  proving it closed by an id is the mechanism.
- **Declare the e2e layer live because it drives the real chassis recorder.**
  The recorder is a library already in telemetry's module graph, pointed at the
  test's own served instance on a loopback port. No external service, no
  credential — composed, not live.
- **Put the source scan in a new `internal/` package.** It needs only the tree
  root and `filepath.WalkDir`; keeping both proofs in `cmd/telemetry/main_test.go`
  puts telemetry's self-truth claims in one place.

## Verification.

Both ids are **adopted**, not minted here: they belong to `root
project/design/D23.md`, which states the behavior. These lines say only what
substrate proves them inside `telemetry/`.

- R-O1AD-MRKW — adopted from `root project/design/D23.md`. Substrate: hermetic —
  a Go test in `cmd/telemetry/main_test.go` reads the committed `../../AGENTS.md`
  from disk and asserts its Tests section declares the default-gate command
  (`go test ./...` run from `telemetry/`), names the layers present in the
  contract's layer names (**hermetic** and **composed**, the composed tests being
  `internal/e2e/` and the boot smoke, and that there is no live layer), states
  that there are no environmental preconditions beyond the Go toolchain, and
  states the GOWORK mode (telemetry's own `go.work` for development, `GOWORK=off`
  for the production build). The test fails when the file is absent, when the
  Tests section is missing, and when any one declaration is missing — naming
  which.
- R-O2IA-0JBL — adopted from `root project/design/D23.md`. Substrate: hermetic —
  a Go test in `cmd/telemetry/main_test.go` walks every `*_test.go` file in the
  `telemetry/` tree, excludes any file carrying a `live` build constraint, and
  asserts **zero** occurrences of `t.Skip`, `t.Skipf`, or `t.SkipNow`. The needle
  is assembled from parts at runtime so the scanning file never matches itself,
  and the scan names the offending file and line on failure.
