# D02-cli

connections as a command: what `cli.Run` does with the arguments, the exit codes, `db status`, and the three constants whose text is fixed here — the usage text, the manifest and the nginx fragment — with the two files under `etc/` that copy the last two. It is artifacts' command with connections' name, its own manifest and its own fragment.

An empty `Args` means serve (`D03-serve`). `--version` writes `Process.Version` and a newline; `manifest` writes `Manifest`; `--help` writes `Usage`; `db status` writes what appkit's `db.Status` writes for `state/connections.db` and `connections.Migrations()`. Any other `Args` is a usage error, diagnosed as artifacts diagnoses one: `connections: unknown option '<arg>'` or `connections: unknown command '<arg>'`, an empty line, and the hint to run `connections --help`. A command touches nothing but what it names: `db status` does not create the database, and no command reads a secret or calls a provider.

## The manifest

The manifest holds connections' name; its description, the same text as `pages.Description` (`D08-pages`); that it is not the default app; that it is an MCP service; that it does not serve guests (`guests = false`), so the host's nginx admits only a request with a credential, to the pages, to the connect and callback routes and to `/mcp` alike; the two secrets `GOOGLE_CLIENT_ID` and `GOOGLE_CLIENT_SECRET`, the same names auth lists, so the host gives connections auth's Google client; no `[env]` table; the `[database]` table that has the host keep and replicate `state/connections.db`; a `[resources]` table whose only line is `memory_max = "128M"`; and, last, a `[home]` table whose only line is `group = "core"`.

## The nginx fragment

The fragment, `NginxConf`, answers three things 404 at the public name. `/token/` and everything under it, as a prefix location with the `^~` modifier, so that a provider access token never leaves the host through nginx: the token route is reached only over the socket (`D07-token-and-disconnect`). nginx matches a location against the normalized URI, after decoding `%XX` escapes, resolving `.` and `..` and merging adjacent slashes, and a `^~` prefix that is the longest match stops the search before any regular-expression location (nginx's `location` directive documentation), so neither an escaped or doubled spelling of the path nor the git location of the host's server block reaches the app. And the event bus's two paths, `/events` and `/declarations`, as every app's fragment does. It changes nothing else: connections takes no large body and holds no long transfer.

## Recorded decisions

- The secrets are auth's two names (decision 3): production gets the web client, the sandbox the Desktop client, with no sandbox or devctl change.
- The manifest has no `[env]` table (decision 1): `DRAIN_SECONDS` is the space's and `IKIGENBA_CALLBACK_URL` the sandbox's, neither the manifest's.
- The `/token/` guard is a `^~` prefix rather than a plain prefix because the host's server block for a guest-less app holds a regular-expression location for git's smart-HTTP paths, which a plain prefix would yield to for a path such as `/token/info/refs`.
- The description is contract, not copy: decision 1 fixes it as the manifest's text, which the host parses, so `Manifest` spells it and `pages.Description` (`D08-pages`) declares the same value.
- `Manifest` and `NginxConf` are copied into `etc/` byte for byte, which a test proves through the root package's `Etc`.

## Consumer tasks

An operator's host reads `connections manifest` and `etc/manifest.toml` to learn the app, its secrets and its database, and drops `etc/nginx.conf` into connections' server block. A developer runs `connections --help`, `connections --version` and `connections db status` from the install directory. A test calls `cli.Run` with each `Args`, a temporary `Dir` and capturing `Stdout` and `Stderr`, and compares with `cli.Usage`, `cli.Manifest`, `cli.NginxConf`, `fs.ReadFile(connections.Etc(), ...)` and what `db.Status` writes for the same path.

- R-1FWC-76GF: The `internal/cli` package MUST export `ExitSuccess`, `ExitServerFailed` and `ExitUsage` as untyped integer constants with the values 0, 1 and 2, and every call of `Run` MUST return one of them.
- R-1H48-KY74: The contents of `manifest.toml` and `nginx.conf` in the file system the root package's `Etc` returns MUST be exactly the bytes of `cli.Manifest` and `cli.NginxConf` respectively.
- R-1IC4-YPXT: When `Args` is exactly `["--version"]`, `["manifest"]` or `["--help"]`, `Run` MUST write exactly `p.Version + "\n"`, `Manifest` or `Usage` respectively to `Stdout` and nothing else, write nothing to `Stderr`, and return `ExitSuccess`.
- R-1JK1-CHOI: `Run` MUST treat `Args` as a usage error unless it is empty or exactly one of `["--version"]`, `["manifest"]`, `["--help"]` and `["db", "status"]`; the offending argument MUST be `Args[0]` when it is none of `--version`, `manifest`, `--help` and `db` or when `Args` is exactly `["db"]`, `Args[2]` when `Args[0]` is `db` and `Args[1]` is `status`, and `Args[1]` otherwise.

- R-1LZU-415W: When `Args` is not empty, `Run` MUST return without calling `LookupEnv`, `Unsetenv`, `Inherit`, `Now`, `Sleep`, `Banner` or `MCP`, without reading `Rand`, without sending any request through `HTTP` or to any URL of an entry of `Providers`, without calling the `Deliver` of `Sink` or `EventSink`, and, unless `Args` is exactly `["db", "status"]`, without creating, removing or changing anything under `Dir`.
- R-1N7Q-HSWL: When `Args` is exactly `["db", "status"]`, `Run` MUST write to `Stdout` exactly the bytes appkit's `db.Status` writes for a `db.Config` whose `Path` is `filepath.Join(Dir, "state", "connections.db")` and whose `Migrations` is `connections.Migrations()` over the database as it is when `Run` is called, create nothing under a `Dir` that names an empty directory, and return `ExitSuccess` with nothing on `Stderr` when that call returns nil; and when it returns an error `err`, write exactly `"connections: " + r + "\n"` to `Stderr` in one write, `r` being `err.Error()` with every newline replaced by a space, and return `ExitServerFailed`.
