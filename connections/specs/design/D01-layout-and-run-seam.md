# D01-layout-and-run-seam

connections is the suite's OAuth broker: one Go binary that holds, for each signed-in user, at most one grant per outside provider, and hands short-lived access tokens for it to siblings on the host. A person connects an account at `/<provider>/connect`, which stores a pending state and sends the browser to the provider; the provider returns it to `/<provider>/callback`, where the code is exchanged and the grant kept (`D06-connect`). A sibling asks `GET /token/<provider>` over the socket for the caller's access token, refreshed first when it is about to expire (`D07-token-and-disconnect`). Grants and pending states live in the app's own SQLite database, `state/connections.db` (`D04-store`); the providers are a table in code (`D05-providers`); each connection created, deleted or broken is an event on the bus and in the trail (`D09-trail`); three MCP tools, `list`, `connect` and `disconnect`, are offered at `/mcp` (`D10-tools`); and a page of the caller's connections at `/`, a tools page at `/tools`, an about screen at `/about`, a notice page for a failed callback and the not-found page are served to a signed-in user (`D08-pages`), every page's footer showing the `Release` then the `Commit` of the identity the run read. This design is the structural ground the others stand on: where the code lives, the seam through which the process is run so that every part can be tested without a real process, the settings and how they are read, the paths, the migrations, where the identity and the display string come from, and the binary's wiring. It follows artifacts' layout and run seam, which is the precedent for everything here.

The module is `github.com/ikigenba/ikigenba/connections`, rooted at the sub-project directory, with `go.mod` beside `specs/`. Its `main` package sits at `cmd/connections`, because `devctl build` finds an app as a `package main` in `cmd/<app>` under the directory that holds `etc/manifest.toml`. `cmd/connections` is wiring only.

## The dependencies

connections depends on one module besides the standard library: `github.com/ikigenba/ikigenba/appkit`, required at a published release with no `replace` directive. Its `db` package brings the pure-Go SQLite driver, which keeps the release build cgo-free. connections uses appkit's `db`, `version`, `services`, `page`, `identity`, `mcp`, `telemetry` and `events`, and restates none of their contracts. It speaks OAuth to a provider with the standard library's `net/http` alone. Which release of appkit is data that `AGENTS.md` and `go.mod` hold.

## Where the environment is read

`main` makes the one read of the environment that is not `Run`'s own: it calls appkit's `version.Read` exactly once, first, and holds the result, the **identity**, whose `String()` is the **display string**. It hands the identity to `page.New`, whose banner carries its `Release` and `Commit` to every page's footer and to the about screen, and the display string to the `mcp.ServerConfig` its `Process.MCP` builds and to `Run` as `Process.Version`, which `Run` writes for `--version` and gives the run's writer as its version. Nothing below `main` calls `version.Read`. `Run` reads every variable through `Process.LookupEnv`: the two secret names of each provider entry (`GOOGLE_CLIENT_ID` and `GOOGLE_CLIENT_SECRET` for the one entry the table holds), then `DRAIN_SECONDS` and `IKIGENBA_CALLBACK_URL`, once each at start; `LISTEN_PID`, `LISTEN_FDS` and `NOTIFY_SOCKET` for the socket and readiness; and `IKIGENBA_SERVICES` once, when it starts to serve.

## Packages

The root package, `connections`, holds what the module embeds: `Assets` (the five templates), `Etc` (`manifest.toml` and `nginx.conf`) and `Migrations` (the one migration, `0001_connections.sql`, which creates the two tables `D04-store` describes).

The internal packages hold the concerns, one each: `internal/cli` (the run seam, the command, the serve path), `internal/settings` (the settings and the secrets), `internal/server` (a listener's life), `internal/store` (connections and pending states, `D04-store`), `internal/providers` (the provider table and the OAuth calls, `D05-providers`), `internal/urls` (the callback origin and the connect page's address, `D06-connect`), `internal/broker` (the operations routes and tools share, `D06-connect`, `D07-token-and-disconnect`), `internal/trail` (the events, `D09-trail`), `internal/tools` (the three tools, `D10-tools`), `internal/pages` (the templates' data and the page routes, `D08-pages`) and `internal/web` (the route table, `D03-serve`). Which imports which is guidance, not contract.

## The run seam

The run seam is `cli.Run`, which takes a context and a `cli.Process` carrying everything the program would otherwise take from the `os` package and the network, and returns the exit code. It is artifacts' seam without `After`, since connections has no sweeper, and with two fields more. `Providers` is the provider table the run serves; nil is `providers.Table()`, and a test hands a table whose entries point at a loopback fake provider. `HTTP` is the client every call to a provider goes through; nil is a client with a bounded timeout, and a test may hand one whose transport answers for a host that never resolves. `Now` is the clock every time connections stamps or compares is read from: a pending state's expiry, an access token's remaining life, a connection's `created` and `modified`, every event's time. `Rand` is the source of every value connections mints: request ids, connection ids, bus event ids, state values and PKCE verifiers.

## Settings

connections reads three kinds of value at start, in this order. First the secrets: for each entry of the provider table, in the table's order, the variable its `ClientIDVar` names and then the one its `ClientSecretVar` names; each must be set and not empty, as auth's Google settings must, and the first that is not is diagnosed `connections: <NAME> is not set`. Then `DRAIN_SECONDS`, the space's, 5 when unset or empty, spelled as opsctl writes an integer, as artifacts reads it. Then `IKIGENBA_CALLBACK_URL`, the origin a provider returns the browser to: when unset the callback origin falls back to the services file (`D06-connect`); when set it must be an origin value, as auth defines one, and anything else, the empty string included, is diagnosed `connections: IKIGENBA_CALLBACK_URL is '<v>', not an origin`. Each refusal is a usage error, written before `Run` looks for its socket.

## Paths

Relative to `Process.Dir` (the process's working directory when empty) the database is `state/connections.db`, opened with `db.Open`, `connections.Migrations()` and `Process.Now`; `state/` is created when absent. connections writes nothing outside `Dir`.

## Recorded decisions

- `After` is gone from `Process` with the sweeper: decision 7 forbids a sweeper and scheduled refresh, and decision 6's removal of expired pending states happens at start and whenever a new one is stored (`D03-serve`, `D04-store`), neither of which waits on a timer.
- `Providers` and `HTTP` are new fields: decision 2 makes the providers a table in code, and the brief's test plan, auth's loopback fake provider being the precedent, needs a run that talks to a fake. auth reached its fake through an issuer setting; connections has no such setting, since the table is code, so the test hands the table itself.
- `Run` treats a nil `HTTP` as an `*http.Client` whose `Timeout` is 30 seconds. This is implemented but is not a requirement: under the test policy, which never waits real seconds, no test can observe the bound, as artifacts' nil `After` could not be observed.
- The secrets are checked before `DRAIN_SECONDS`, and `IKIGENBA_CALLBACK_URL` after it, as auth orders its required settings before the drain and its origins after. The secret names come from the table, not from a list in the settings package, so a second provider brings its own two names with no change here.
- An `IKIGENBA_CALLBACK_URL` set to the empty string is refused, as auth refuses it; `DRAIN_SECONDS` set to the empty string is the default, as artifacts reads it. Each follows its precedent.
- The origin rule is restated in `internal/settings` (`settings.IsOrigin`) rather than taken from auth: a sibling's design is precedent, never a dependency.
- The secrets `Run` read are handed to the route table inside one `providers.Client` per entry (`web.Config.Clients`, `D03-serve`, `D05-providers`), so nothing below `Run` looks a variable up again.

## Consumer tasks

`main` calls `id := version.Read()` and `v := id.String()` and hands `cli.Run` a `cli.Process` whose `Args`, `LookupEnv`, `Unsetenv`, `Pid`, `Stdout` and `Stderr` are the real process's, whose `Version` is `v`, whose `Banner` is `page.New(pages.ServiceName, id).Banner` and whose `MCP` returns `mcp.NewServer(mcp.ServerConfig{Name: pages.ServiceName, Version: v, Telemetry: w})` over the writer `w` it is given, leaving the rest zero, so `Providers` is the real table and `HTTP` the bounded client; it cancels the context on `SIGTERM` or `SIGINT` with a cause whose `Error` is the signal's name, and exits with what `Run` returns. A test of the run seam builds a `cli.Process` with a temporary `Dir`, a `LookupEnv` over a map holding the fake entry's two secrets and an `IKIGENBA_CALLBACK_URL`, an `Inherit` returning a listener it bound, a `Now` and a `Rand` it controls, a `Providers` table of one entry whose URLs name a loopback fake provider (or the host `provider.invalid`, with an `HTTP` whose transport answers for it), and capturing sinks; it calls `cli.Run`, waits for `READY=1`, drives the listener with raw HTTP to `/<provider>/connect`, `/<provider>/callback` and `/token/<provider>` and with `mcp.Client` at `/mcp`, cancels, and inspects `Dir`, the captures and the streams. A test of settings calls `settings.Read` with a lookup over a map and compares with `settings.Defaults()` and `Drain()`, calls `settings.Secrets` with a list of names, and calls `settings.IsOrigin` on the values auth's rule names. The one test that execs the binary sets `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET` and `IKIGENBA_CALLBACK_URL` to values of its own in the child's environment, composes non-empty `IKIGENBA_COMMIT` and `IKIGENBA_RELEASE` into it and, after setting the same two values with `testing.T.Setenv`, computes the identity it expects with `version.Read`, the display string with its `String`, and the about screen with the `Banner` method of `page.New(pages.ServiceName, id)`; it never lets the binary reach Google, since nothing it asks makes a provider call.
