# Decision 78 — The public tier is read-only: browse + keyword search, no inference

**Decision.** The public tier serves anonymous visitors, so it must cost nothing per request beyond a DB read: it gets **browse and keyword search**, never `ask` and never an embedding call. The private tier keeps the full D43/D44 experience (ask + both retrieval lanes + orphans), per scope. This Decision owns the public tier's page states and the no-inference wall.

## Public tier states (per public scope)

- **Public home** (`GET /public/{scope}/`, no `q`) — the search box (same `q` form, resolving against the tier+scope base) plus a **browse index**: the scope's subjects listed as links (name-ordered by public path, the D11 order), so a visitor has a foothold into the content without knowing any name. The D43 orphan index is a curation view for the owner and stays private-tier; the public foothold is the plain subject list. Name+version footer as everywhere.
- **Public search results** (`GET /public/{scope}/?q=…`) — runs the **D31 keyword lane only** (FTS over the scope, D74-bounded) and renders the matching subjects as a linked result list under the search box; the honest empty case is a plain "no matches" line with the form still present. No `Asker`, no `Mentioner` over an answer, no embedding — the meaning lane (D32) requires embedding the query through prompts, which is inference an anonymous visitor must not be able to spend.
- **Public subject page** (`GET /public/{scope}/subject/{type}/{slug}`) — the D45 rendering unchanged (prose through the D48 `md` renderer, D58 inline links, outbound/inbound footers), scoped and composed with public-tier links. Reading a compiled page costs no inference; only its production did.

The **private tier** home/ask/subject states are the existing D43/D44/D45/D46 behaviors, re-rooted at `/private/{scope}/` and partition-bounded by D74 (its orphan index and ask both take the path scope).

The public handlers are wired **without** the `Asker` seam entirely — the no-inference wall is structural (the public route table has no code path that can reach `Ask` or `/embed`), not a conditional.

**Rejected.**
- **Ask for anonymous visitors** — an unauthenticated LLM-inference endpoint on the open internet is a cost/abuse hole; the operator explicitly chose read-only.
- **Meaning-lane search on the public tier** — query embedding is an inference call; same hole, smaller. Keyword-only keeps the anonymous path DB-pure.
- **The orphan index as the public foothold** — orphans are a curation signal ("what nothing references"), not an entry point for a stranger; the full subject list is the honest browse surface.
- **Rate-limiting public ask instead of removing it** — rate limiting is infrastructure the suite does not have per-anonymous-visitor, and "cheaper abuse" is still abuse; removal is the simple, complete answer.

**Verification.** httptest against the web handler; real temp SQLite where the lane/scope behavior is the substrate:
- R-HUFU-ASVW — The public home for a public scope renders the `q` search form **and** the scope's subjects as links (path-ordered), each href inside `/public/{scope}/subject/…`; a subject from another scope is absent.
- R-HVNQ-OKML — `GET /public/{scope}/?q=…` returns matches from the keyword lane as a linked subject list, and **no public-tier route ever invokes `Ask`**: a recording `Asker` stub wired into the handler observes zero calls across public home, public search, and public subject requests (the public wiring takes no Asker at all).
- R-HWVN-2CDA — A public search with no keyword matches renders a plain no-matches body with the search form still present — a 200, no error page, and still no ask fallback.
- R-HY3J-G43Z — The public subject page renders the compiled prose as sanitized markdown with the D58 inline links and both footers, every subject link composed on the public tier (`/public/{scope}/subject/…`); a private-scope subject requested on the public tier stays the D76 404.
- R-HZBF-TVUO — The private tier keeps ask and orphans, scoped: `GET /private/{scope}/?q=…` invokes `Ask` exactly once with that scope and the decoded question, and the private home renders the scope's orphan index (not the all-subjects browse list).
