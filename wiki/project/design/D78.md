# Decision 78 — The public tier is read-only: browse + keyword search, no inference

**Decision.** The public tier serves anonymous visitors, so it must cost
nothing per request beyond a DB read: it gets **browse and keyword search**,
never `ask` and never an embedding call. The private tier keeps the full
D43/D44 experience (ask + both retrieval lanes), per scope. This Decision owns
the public tier's page states and the no-inference wall.

## Public tier states (per public scope)

- **Public home** (`GET /public/{scope}/`, no `q`) — the D43 page shape on the
  public tier: the title, the search box (same `q` form, resolving against the
  tier+scope base, Search-labeled per D79), and the **Suggested pages**
  section — the scope's seven newest subjects (D81), the anonymous visitor's
  foothold. Anything older is reached through keyword search. The D80 shell
  frames it as everywhere.
- **Public search results** (`GET /public/{scope}/?q=…`) — runs the **D31
  keyword lane only** (FTS over the scope, D74-bounded) and renders the
  matching subjects as a linked result list under the search box; the honest
  empty case is a plain "no matches" line with the form still present. No
  `Asker`, no `Mentioner` over an answer, no embedding — the meaning lane
  (D32) requires embedding the query through prompts, which is inference an
  anonymous visitor must not be able to spend.
- **Public subject page** (`GET /public/{scope}/subject/{type}/{slug}`) — the
  D45 rendering unchanged (prose through the D48 `md` renderer, D58 inline
  links, outbound/inbound footers), scoped and composed with public-tier
  links. Reading a compiled page costs no inference; only its production did.

The **private tier** home/ask/subject states are the D43/D44/D45 behaviors,
re-rooted at `/private/{scope}/` and partition-bounded by D74 (its ask takes
the path scope; its home list is the same D81 suggested list).

The public handlers are wired **without** the `Asker` seam entirely — the
no-inference wall is structural (the public route table has no code path that
can reach `Ask` or `/embed`), not a conditional.

**Rejected.**
- **Ask for anonymous visitors** — an unauthenticated LLM-inference endpoint
  on the open internet is a cost/abuse hole; the operator explicitly chose
  read-only.
- **Meaning-lane search on the public tier** — query embedding is an inference
  call; same hole, smaller. Keyword-only keeps the anonymous path DB-pure.
- **A browse-all subject index as the public home list** — the prior shape of
  this Decision, retired by operator direction: every scope home shows the
  seven newest (D81); keyword search remains the full enumeration path.
- **Rate-limiting public ask instead of removing it** — rate limiting is
  infrastructure the suite does not have per-anonymous-visitor, and "cheaper
  abuse" is still abuse; removal is the simple, complete answer.

**Verification.** httptest against the web handler; real temp SQLite where the
lane/scope behavior is the substrate (the public home's list content is D81's
R-HOPU-H1YI):

- R-HVNQ-OKML — `GET /public/{scope}/?q=…` returns matches from the keyword
  lane as a linked subject list, and **no public-tier route ever invokes
  `Ask`**: a recording `Asker` stub wired into the handler observes zero calls
  across public home, public search, and public subject requests (the public
  wiring takes no Asker at all).
- R-HWVN-2CDA — A public search with no keyword matches renders a plain
  no-matches body with the search form still present — a 200, no error page,
  and still no ask fallback.
- R-HY3J-G43Z — The public subject page renders the compiled prose as
  sanitized markdown with the D58 inline links and both footers, every subject
  link composed on the public tier (`/public/{scope}/subject/…`); a
  private-scope subject requested on the public tier stays the D76 404.
- R-HPXQ-UTP7 — The private tier keeps ask, scoped: `GET /private/{scope}/?q=…`
  invokes `Ask` exactly once with that scope and the decoded question, while
  the public tier's search route invokes it zero times.
