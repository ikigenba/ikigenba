# Decision 66 — nginx: forward the edge-minted correlation id on gated locations, strip it on the ungated one

**Decision.** `wiki/etc/nginx.conf` forwards the chain id the same way it already forwards owner identity. Every location that proxies to the wiki loopback upstream sets `X-Correlation-Id`: to the value captured from the auth subrequest when the location is gated, and to the empty string when it is not.

The four **gated** proxying locations — `= /srv/wiki/` (session), `/srv/wiki/subject/` (session), `/srv/wiki/static/` (session), and the bearer-gated `/srv/wiki/` prefix — each gain:

```nginx
auth_request_set $wiki_correlation $upstream_http_x_correlation_id;
proxy_set_header X-Correlation-Id $wiki_correlation;
```

The `proxy_set_header` is the load-bearing half. nginx does not forward an inbound client header as a proxy header unless explicitly set, and the last `proxy_set_header` for a name wins, so this **replaces** any client-supplied `X-Correlation-Id` — the identity-hygiene argument the fragment already spells out for `X-Owner-Email`, applied to the chain id. A client cannot graft itself onto another chain.

The one **ungated** proxying location, the PRM bootstrap `= /srv/wiki/.well-known/oauth-protected-resource`, runs no `auth_request` and so has no minted id to capture. It sets the header empty and lets the chassis mint:

```nginx
proxy_set_header X-Correlation-Id "";
```

`@wiki_authn_500` proxies nothing and is untouched.

This is a **structural** Decision: the fragment is nginx configuration, not Go, and wiki's convention (D47, D60) proves such changes with a named fragment-check phase — a deterministic grep over the shipped artifact — rather than an `R-id` test. It mints no ids of its own; the behavior it enables is proven by D64's ids, which assert what wiki does with the id once it arrives.

**Rejected.**
- **Reading a client-supplied `X-Correlation-Id` on the ungated PRM path** — lets a public caller choose its own chain id. Stripping to empty and letting the chassis mint is the only safe default.
- **Adding the capture only to the bearer-gated MCP prefix** — the session-gated human surface (`= /srv/wiki/`, `/srv/wiki/subject/`) drives real asks and real inference calls; leaving it out would make exactly the human-initiated chains unreconstructable.
- **Omitting the line on `/srv/wiki/static/`** — it is a gated proxying location; leaving one such location unset breaks the uniform, greppable invariant and makes the next fragment edit a judgment call.

**Verification.** None — structural. This Decision changes shipped configuration and enables behavior proven elsewhere (D64); its own acceptance is the deterministic fragment check its plan phase carries.
