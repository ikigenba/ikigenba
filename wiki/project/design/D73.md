# Decision 73 — Testing-language conformance: adopt the suite contract and move the env-gated smokes into the live layer

**Decision.** wiki adopts the suite testing-language contract
**`root project/design/D23.md`** by value: the four layer names
(hermetic / composed / live / manual), the rule that the default gate carries
only hermetic and composed tests, the single live mechanism (`//go:build live`
plus a documented invocation, hard-failing on absent credentials), the ban on
`t.Skip` outside live-tagged files, and the requirement that the tree declare its
testing facts in `AGENTS.md`. The contract is cited, never restated — nothing
here redefines a layer or re-specifies the mechanism.

**wiki's declared facts.** These are the tree-specific values the contract asks
each adopter to state; they are what the `AGENTS.md` Tests section and the design
Conventions must say:

| fact | value |
|---|---|
| default-gate test command | `cd wiki && go test ./...` (also reachable as `make test`) |
| layers present | **hermetic**, **composed**, **live** |
| environmental preconditions beyond the Go toolchain | none — the `autotune/` scorer executables the folder tests shell are committed in-tree and run under the same Go toolchain |
| GOWORK mode | workspace (the repo-root `go.work`); the production build forces `GOWORK=off` via `bin/ship wiki` |
| live invocation | `cd wiki && go test -tags live ./...` |
| live credentials | `WIKI_LIVE_PROMPTS_URL` — the base URL of a **running** prompts service on loopback, which holds the provider key (the `/embed` smoke); `OPENAI_API_KEY` — the real judge model's key (the two autotune judge smokes) |
| when the operator runs live | at **deploy verification** for wiki, and whenever a change touches `internal/llm`'s prompts client or an `autotune/` judge prompt or scorer |

The **composed** layer is `cmd/wiki`'s boot and module-wiring tests plus the
`internal/db` migration run over the real binary's embedded set; the **hermetic**
layer is everything else in the default gate, including every scorer path that
runs with `SCORE_SKIP_JUDGE=1` over committed fixtures. wiki has no
**manual**-layer check of its own.

**Three env-gated smokes move behind the tag.** wiki's three live checks predate
the contract and all carry the shape it bans — silently live when the
environment happens to be supplied, silently green when it is not:

1. `TestEmbedAgainstLivePrompts` (**R-15NY-IF46**) in
   `internal/llm/embed_test.go` skips unless `WIKI_LIVE_PROMPTS_URL` is set.
2. `TestCompileScoreLiveJudgeReturnsComposedRubricScore` (**R-AFK7-HJ0T**) and
3. `TestSynthesisScoreLiveJudgeReturnsComposedRubricScore` (**R-AGS3-VARI**) in
   `autotune/folders_test.go` skip unless `WIKI_TUNE_LIVE=1` **and**
   `OPENAI_API_KEY` are both set.

All three move — unchanged in what they assert — into new sibling files carrying
`//go:build live` (`internal/llm/embed_live_test.go` and
`autotune/folders_live_test.go`), keeping their existing ids. Their env guards
become hard failures naming the absent variable. The `WIKI_TUNE_LIVE=1` sentinel
is **deleted outright rather than converted**: it exists only to keep a live test
out of the default gate, which is now the build tag's job, so preserving it would
give the boundary two mechanisms that can disagree. `OPENAI_API_KEY` and
`WIKI_LIVE_PROMPTS_URL` survive as genuine credentials, hard-required.

None of the three is reclassified to the **manual** layer: each states a
mechanically checkable assertion (vector count and dimensionality; a rubric's
subscore names, their `[0,1]` range, and the `0.60·gate + 0.40·judge`
composition) and needs no operator judgment to read its result. The manual layer
is for checks automation cannot reach even with credentials, and these are
reachable.

After this change `t.Skip` does not appear anywhere in the tree.

**Rejected.**

- *Keeping `WIKI_TUNE_LIVE=1` alongside the build tag as a second safety.* Two
  gates for one boundary is one gate too many: the tag already keeps the code out
  of the default binary, and a surviving env sentinel would make an explicit
  `-tags live` run silently do nothing.
- *Reclassifying the judge smokes to the manual layer because "a model's output
  is a judgment call."* The tests assert the **scorer's** contract around the
  judge — subscore names, ranges, and the composition weights — not the judge's
  taste. That is automatable, and a runbook would be strictly weaker.
- *Converting the guards to `t.Skip` with a louder message.* The contract bans
  skipping outside live-tagged files and requires a live test to fail loudly on
  missing credentials; a skip in an explicitly-invoked live run reports green
  having proven nothing.
- *Leaving the smokes in place and merely documenting them.* Documentation does
  not stop a default-gate run with the suite `.envrc` loaded from making a real
  provider call — the defect is in the code, so the fix must be.
- *Restating D23's layer definitions in this design.* A local copy of a suite
  contract is drift by construction; the citation is the whole mechanism.
- *Minting fresh wiki ids for the two contract behaviors.* The contract marks
  both `[proof: per-service]`; citing them is adoption, and re-minting would
  create a second handle for one behavior.
