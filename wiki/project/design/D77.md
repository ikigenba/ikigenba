# Decision 77 — nginx: the two scope tiers (public ungated, private session-gated)

**Decision.** wiki's nginx fragment (`wiki/etc/nginx.conf`) restructures the human-surface locations around the D76 tiers, mirroring the sites precedent (`sites/etc/nginx.conf`, its public/private static tiers). This is a **config** change — structural, no Go R-ids; its proof is a named fragment-check in the realizing phase (the D39/D47 pattern).

The fragment after this Decision, most specific wins:

| Location | Gate | Serves |
|---|---|---|
| `= /srv/wiki/.well-known/oauth-protected-resource` | open | PRM bootstrap (unchanged) |
| `= /srv/wiki/` | **session** + `@login_bounce` | the D76 root redirect (logged-in humans only) |
| `/srv/wiki/public/` | **open** (no auth_request; empty identity headers, `X-Correlation-Id` stripped to empty like the PRM location) | the public tier — wiki itself enforces the visibility wall (D76: private scope → 404) |
| `/srv/wiki/private/` | **session** + `@login_bounce` | the private tier |
| `/srv/wiki/static/` | **open** (was session) | shared assets — `tokens.css`/fonts are not sensitive, and public pages must style |
| `/srv/wiki/` (prefix) | **bearer** (`/_authn`) | `/mcp`, `/health`, `/feed` (unchanged) |

The former `/srv/wiki/subject/` session location is **removed** — subject pages now live under the tiers. The session-gated locations keep the D60 `error_page 401 = @login_bounce;` line; the public and static locations carry no gate and no bounce. The two tier locations proxy with the sub-path preserved (`proxy_pass http://127.0.0.1:3001/public/;` / `…/private/;`), so the Go mux sees the D76 routes. The public location, like the PRM bootstrap, sets `proxy_set_header X-Correlation-Id ""` and blanks the identity headers so an anonymous request arrives with no trusted identity and no client-spoofable headers pass through.

The trust boundary is unchanged: nginx remains the sole gate; in-process every route is ungated and no wiki handler reads a token. What is new is that the public tier deliberately carries **no identity at all** — wiki's public handlers never read `X-Owner-*`, and the visibility wall (which scope may be served ungated) is wiki's in-process check against its own registry, the same division of labor sites uses.

**Supersessions (notes added).** D47's location table (the `/subject/` and session-gated `/static/` rows) and D60's three-location bounce list are superseded by the table above; D60's principle (session gates bounce, bearer and open locations never do) is unchanged and now applies to the root + `/srv/wiki/private/`.

**Rejected.**
- **Session-gating `/static/` and duplicating assets under the public tier** — two copies of the same bytes to keep an asset gate that protects nothing (design tokens and fonts are public in every sense).
- **Dynamic per-scope nginx config (a location per public scope)** — nginx config is authored verbatim and shipped static (D39/D47 precedent); visibility is wiki state and belongs behind wiki's own check.
- **Auth fall-through on one stable location** — rejected in D76.

**Verification.** None minted — structural. The realizing phase's Done-when is a fragment grep: the `location /srv/wiki/public/` block exists with no `auth_request`, the `location /srv/wiki/private/` block exists with `auth_request /_session-authn` and the bounce line, no `location /srv/wiki/subject/` remains, and `/srv/wiki/static/` carries no `auth_request` — plus the suite's existing local nginx smoke still passing.
