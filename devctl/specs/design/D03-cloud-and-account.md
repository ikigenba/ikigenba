# D03-cloud-and-account

Cloud interfaces use devctl vocabulary; the AWS adapter remains the sole SDK
consumer. Account properties select region, resource names, retention policy and
four backup periods. A profile is an opaque shared-config name. Restore no
longer opens a second account or copies backups. `LaunchReady` is a
side-effect-free probe: it asks EC2 whether a launch spec would be accepted,
which is how a caller confirms a just-created instance profile has become
usable before it commits to a real launch.
