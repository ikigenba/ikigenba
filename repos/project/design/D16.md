# Decision 16 — Adopt the suite testing-language contract

**Decision.** repos adopts the suite's testing-language contract,
`root project/design/D23.md`, by citation. That contract owns the four test
layers (**hermetic / composed / live / manual**) and what each may touch, the
single mechanism for live tests (`//go:build live`, invoked as
`go test -tags live ./...`, hard-failing on absent credentials), the ban on
`t.Skip` outside live-tagged files, and the requirement that every tree declare
its own testing facts in its `AGENTS.md`. This Decision restates none of that.
It records only the repos-specific facts the contract asks this tree to declare,
and adopts the contract's two per-service ids.

**The layers repos has.** Two, both in the default gate:

- **hermetic** — nearly everything: the store and status tests against real
  temp-file SQLite through the real embedded migration set with an injected
  deterministic `Clock`; **every git claim against the real `git` binary** —
  custody and archive over bare repositories under `t.TempDir()`, the commit
  paths through real plumbing, and real `git clone`/`fetch`/`push` from a
  temporary client working copy against the shipped smart-HTTP handler mounted
  on an `httptest` server; the loopback filesystem routes through
  `net/http/httptest`; the committed-file scans over `etc/nginx.conf` and
  `etc/manifest.env`; the landing controller's pure-function tests in goja
  (D25); and the single headless-Chrome wiring proof (D26), which spawns a
  local Chrome subprocess against a loopback `httptest` page and reaches no
  network. Local subprocesses and loopback listeners are what the
  contract's hermetic row allows, and nothing here contacts a non-loopback
  address or reads a credential.
- **composed** — the install-layout boot smoke in `cmd/repos/main_test.go`
  (`R-4LKF-FB23`, D14): it assembles an `/opt/repos/`-shaped tree under
  `t.TempDir()`, `go build`s the real `cmd/repos` binary into it, runs
  `bin/run serve` on a free loopback port with **no credentials in the
  environment**, and asserts the served `/health`, the created database, git
  root, and generation sidecar, and that the landing page renders through the
  `share/current` web root.

repos has **no live layer**, and after the v2 rewrite it cannot acquire one by
accident: there is no external service to reach. It calls no provider, no
GitHub, no peer — so no automated test here reaches an external service or reads
a real credential, no `//go:build live` file exists, and `-tags live` is not
part of this tree's testing story. repos also carries **no tree-local manual
runbook**: no committed check of its own requires the operator. Adding either
later is a Decision, not a drift.

**No `bin/start` proof lives in this tree, and none should.** The assembled-stack
check belongs to the suite as a manual-layer item under the contract, not to
`repos/`: a phase whose exit condition depends on shared host ports and another
worktree's stack is not deterministic. The boot claim it would gesture at is
exactly what the composed smoke proves offline against a temp root.

**GOWORK mode.** repos tests, builds, and vets in **workspace mode** through the
repo-root `go.work`; the production build forces `GOWORK=off` (driven by
`bin/ship repos`) and is not part of the default gate.

**Environmental preconditions beyond the Go toolchain.** Three, all hard
failures when absent, never skips:

- The **real `git` binary on `PATH`** — including `git http-backend`, which
  ships with git and which the door tests exercise as a real CGI program. git is
  not a dependency of repos' tests, it is repos' entire domain: the service is a
  custodian of git repositories, and every claim it makes is a claim about what
  git actually does. A mocked git would accept whatever it was handed and
  falsify nothing. Absent git means the suite is **red**.
- The **`go` binary on `PATH` in the test process's environment** (not merely
  the toolchain that compiled the tests), with the module cache resolving repos'
  `replace` siblings. The composed boot smoke shells out to `go build`; it does
  no network fetch and must not acquire one.
- The **`google-chrome` binary on `PATH`** — the browser wiring proof (D26)
  launches one headless Chrome via chromedp; it spawns a local subprocess and
  talks only to loopback listeners, staying inside the hermetic row. No Chrome
  means the suite is **red**, never skipped.

**Where this lands.** The adoption is carried by two tagged tests and by the
`AGENTS.md` Tests section stating the facts above.

**Rejected.**

- *Restating the layer definitions, the live-tag mechanism, or the skip ban in
  this design.* Citation is the mechanism: a local copy of a suite contract is
  drift by construction the moment the umbrella moves.
- *Re-minting local ids for the two behaviors.* The umbrella marks R-O1AD-MRKW
  and R-O2IA-0JBL `[proof: per-service]`; citing those exact ids **is** the
  adoption, and a fresh local id would be a second handle for one behavior.
- *Filing the real-`git` tests as composed because they spawn subprocesses.* The
  layer is defined by what a test may **touch**. Local subprocesses and loopback
  listeners are explicitly hermetic under the contract; git here operates
  entirely on `t.TempDir()` fixtures and an in-process `httptest` listener, and
  reaches no network. Only building and running repos' own binary crosses into
  composed.
- *Declaring `git` an optional precondition and skipping the git tests when it
  is absent.* That is the shape the contract bans outright: repos' single most
  load-bearing mechanism would go silently green on a box without git.
- *Introducing a `Git` fake so the door and custody tests can run without the
  binary.* It would convert the tree's most valuable tests — the ones a wrong
  hook, a wrong CGI environment, or a wrong plumbing sequence actually fails —
  into assertions that the right strings were passed to a stub.

**Verification.**

- R-O1AD-MRKW — cited from `root project/design/D23.md` (`[proof:
  per-service]`); adopted here. A test reads repos' committed `AGENTS.md` from
  disk and asserts its Tests section declares the default-gate test command, the
  layers present in the contract's vocabulary (hermetic and composed), every
  environmental precondition beyond the Go toolchain (the real `git` binary,
  the `go` binary, and the `google-chrome` binary), and the tree's GOWORK
  mode. Substrate: hermetic (real
  committed file read from disk).
- R-O2IA-0JBL — cited from `root project/design/D23.md` (`[proof:
  per-service]`); adopted here. A source scan over repos' `*_test.go` files,
  excluding files carrying the `live` build constraint, finds **zero**
  occurrences of `t.Skip`, `t.Skipf`, or `t.SkipNow`. The scan assembles its
  needle from parts so it never matches itself. Substrate: hermetic (source
  scan).
