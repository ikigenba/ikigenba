# Decision 16 — Adopt the suite testing-language contract

**Decision.** repos adopts the suite's testing-language contract,
`root project/design/D23.md`, by citation. That contract owns the four test
layers (**hermetic / composed / live / manual**) and what each may touch, the
single mechanism for live tests (`//go:build live`, invoked as
`go test -tags live ./...`, hard-failing on absent credentials), the ban on
`t.Skip` outside live-tagged files, and the requirement that every tree declare
its own testing facts in its `AGENTS.md`. This Decision restates none of that.
It records only the repos-specific facts the contract asks this tree to declare,
and adopts the contract's two per-service ids.

**The layers repos has.** Two, both in the default gate:

- **hermetic** — the bulk of the suite: the store and intake tests against real
  temp-file SQLite through the real embedded migration set, with an injected
  deterministic `Clock`; **the git custody and worktree tests against the real
  `git` binary** over local fixture remotes (`git init --bare` under
  `t.TempDir()`, `file://` URLs, and a locally spawned `git http-backend`) —
  never a mocked git; the github and webhooks peers as recording `httptest`
  stubs mirroring their real wire shapes; the runner tests against a scripted
  fake engine over real worktrees; the injected-outbound-client tests, whose
  substrate is a recording `RoundTripper`; and the committed-file scans over
  `etc/nginx.conf` and `etc/manifest.env`. Local subprocesses and loopback
  listeners are what the contract's hermetic row allows, and nothing here
  contacts a non-loopback address or reads a credential.
- **composed** — the install-layout boot smoke in `cmd/repos/main_test.go`
  (`R-4LKF-FB23`, D14): it assembles an `/opt/repos/`-shaped tree under
  `t.TempDir()`, `go build`s the real `cmd/repos` binary into it, runs
  `bin/run serve` on a free loopback port with a throwaway `ANTHROPIC_API_KEY`,
  and asserts the served `/health`, the created database and generation sidecar,
  and that the landing page renders through the `share/current` web root.

repos has **no live layer**: no automated test here reaches an external service
or reads a real credential — the GitHub half of the peer contract is proven on
github's side, and the agent engine is a scripted fake — so no `//go:build live`
file exists and the `-tags live` invocation is not part of this tree's testing
story. repos also carries **no tree-local manual runbook**: no committed check
of its own requires the operator. Adding either later is a Decision, not a
drift.

**There is no `bin/start` proof in this tree, and there should not be.** This
design's *Conventions* carried a sentence — "The live end-to-end proof runs
against `bin/start`" — that nothing committed ever implemented and that D14
already rejected on its merits (a phase whose exit condition depends on shared
host ports and another worktree's stack is not deterministic). It is removed
rather than reworded: the assembled-stack check belongs to the suite as a
manual-layer item under the contract, not to `repos/`, and the boot claim it
gestured at is exactly what the composed smoke proves offline against a temp
root. The same correction applies to D6's parenthetical: the real-GitHub half of
the peer contract is proven on github's side, and the assembled stack is the
suite's manual-layer check — not a repos gate item.

**GOWORK mode.** repos tests, builds, and vets in **workspace mode** through the
repo-root `go.work`; the production build forces `GOWORK=off` (driven by
`bin/ship repos`) and is not part of the default gate.

**Environmental preconditions beyond the Go toolchain.** Two, both hard failures
when absent, never skips:

- The **real `git` binary on `PATH`**. Git custody is repos' core mechanism and
  is deliberately never mocked: the clone, worktree, branch, push, and
  `http-backend` tests shell out to real `git` against local fixture remotes,
  because only real git can falsify a claim about what a clone or a worktree
  actually does. This design's *Conventions* already state the substrate
  choice; the contract's declaration requirement is what lifts it out of the
  design and into `AGENTS.md`, where someone setting up a box will see it.
- The **`go` binary on `PATH` in the test process's environment** (not merely the
  toolchain that compiled the tests), with the module cache already resolving
  repos' `replace` siblings and the pinned `agentkit` module. The composed boot
  smoke shells out to `go build`; it does no network fetch and must not acquire
  one.

**Where this lands.** Nothing in repos' shipped source changes. The adoption is
carried by two tagged tests and by the `AGENTS.md` Tests section stating the
facts above; the plan phase that realizes this Decision does both. The
*Conventions* and D6 corrections are design-side only and schedule no work.

**Rejected.**

- *Restating the layer definitions, the live-tag mechanism, or the skip ban in
  this design.* Citation is the mechanism (`$ikispec`, "cite, never restate"): a
  local copy of a suite contract is drift by construction the moment the umbrella
  moves. This file names only what is particular to repos.
- *Re-minting local ids for the two behaviors.* The umbrella marks R-O1AD-MRKW
  and R-O2IA-0JBL `[proof: per-service]`; citing those exact ids **is** the
  adoption, and a fresh local id would be a second handle for one behavior.
- *Rewording the `bin/start` sentence into a manual-layer runbook item for this
  tree.* There is no repos-specific check behind it — it was a description of a
  proof that was never built, and the only claim it named (the service boots and
  answers `/health`) is already proven by the composed smoke, deterministically
  and offline. Inventing a runbook to preserve a stale sentence would commit the
  tree to an operator ritual with no content.
- *Filing the real-`git` tests as composed because they spawn subprocesses.*
  The layer is defined by what a test may **touch**. Local subprocesses and
  loopback listeners are explicitly hermetic under the contract; `git` here
  operates entirely on `t.TempDir()` fixtures and `file://` remotes and reaches
  no network. Only building and running repos' own binary crosses into composed.
- *Declaring `git` an optional precondition and skipping the custody tests when
  it is absent.* That is the shape the contract bans outright: repos' single
  most load-bearing mechanism would go silently green on a box without git.
  Absent git means the suite is **red**.

**Verification.**

- R-O1AD-MRKW — cited from `root project/design/D23.md` (`[proof:
  per-service]`); adopted here. A test reads repos' committed `AGENTS.md` from
  disk and asserts its Tests section declares the default-gate test command, the
  layers present in the contract's vocabulary (hermetic and composed), every
  environmental precondition beyond the Go toolchain (the real `git` binary and
  the `go` binary), and the tree's GOWORK mode. Substrate: hermetic (real
  committed file read from disk).
- R-O2IA-0JBL — cited from `root project/design/D23.md` (`[proof:
  per-service]`); adopted here. A source scan over repos' `*_test.go` files,
  excluding files carrying the `live` build constraint, finds **zero**
  occurrences of `t.Skip`, `t.Skipf`, or `t.SkipNow`. The scan assembles its
  needle from parts so it never matches itself. Substrate: hermetic (source
  scan).
