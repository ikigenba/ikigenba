# Decision 37 — Testing-language conformance: the suite's four layers, declared in `AGENTS.md`

**Decision.** The dashboard adopts the suite's **testing-language contract** —
`root project/design/D23.md` — which owns the four layer names, the rule for what
each layer may touch, the `//go:build live` mechanism, the ban on skipping outside
live-tagged files, and the requirement that every tree declare its testing facts in
its `AGENTS.md`. This Decision is the **citation, and citation is adoption**: the
dashboard owns none of that contract's content and restates none of it normatively.
What is local — and all this Decision adds — is **the dashboard's own testing facts**
and **where the proof of the declaration lives**.

The contract carries two `[proof: per-service]` ids, which the dashboard therefore
proves in its own tree:

- `R-O1AD-MRKW` — the doc-truth test over the committed `AGENTS.md`.
- `R-O2IA-0JBL` — the source scan banning `t.Skip` outside live-tagged files.

**The dashboard's testing facts** (the content its `AGENTS.md` Tests section must
declare, and what the doc-truth test asserts):

- **Default-gate test command:** `cd dashboard && go test ./...`, inside the green
  bar the design Conventions already fix (`go build ./...`, `go vet ./...`,
  `gofmt -l .` silent, `go test ./...`).
- **Layers present: hermetic, composed, and manual — no live layer.**
  - **hermetic** is the bulk of the suite: the `internal/server` HTTP-level tests
    driving the real route table through `httptest` over a real temp
    `modernc.org/sqlite` migrated by the appkit runner; the `internal/identity`,
    `internal/oauth`, `internal/pat`, `internal/session`, `internal/oauthstate`,
    `internal/ratelimit`, `internal/audit`, `internal/grantevents`, `internal/ids`
    and `internal/db` package tests; the `internal/metrics` readers against
    fixtures, temp trees, and a real `statfs`; the `googleidp`/`githubidp` tests
    against `httptest` fakes of the provider bases; the edge-telemetry tests
    against an in-process `httptest` ingest sink and a closed listener; and the
    **shipped-file guards** — the `etc/nginx.conf` fragment content assertions
    (D20, D33) and the committed-`manifest.env` scans (D34) — which read committed
    files from disk and touch nothing else.
  - **composed** is the boot smoke in `cmd/dashboard/main_test.go` (D34): it builds
    the dashboard's own binary, assembles an `/opt/dashboard/`-shaped tree under
    `t.TempDir()`, runs `bin/run serve` on a free loopback port, and asserts the
    served `/health`, the created DB, and the composed cache path. It is offline by
    construction — throwaway syntactically-valid credentials, no provider contacted.
  - **manual** is the interactive provider sign-in. A real Google or GitHub login is
    a browser handshake automation cannot drive even with credentials, so the live
    302/401 apex routing, the live identity-header emission through nginx, and the
    GitHub org-membership gate against the real org are **manual-layer** checks
    exercised at deploy time, not gate tests. The design's testing strategy already
    says so for GitHub and for the nginx fragment; this Decision only gives that
    practice the contract's name.
  - **no live layer.** The dashboard carries no `//go:build live` file and needs
    none: every claim it can automate is falsifiable hermetically or composed, and
    the residue is interactive, which is the manual layer's definition, not live's.
- **Environmental preconditions beyond the Go toolchain: none.** The composed boot
  smoke shells out only to `go build` and the binary it just built; nothing needs
  `git`, `python3`, a browser, a credential, or a running suite.
- **GOWORK mode: workspace.** The gate resolves `appkit`, `eventplane`, and
  `registry` through the repo-root `go.work` and the committed replace-siblings.
  The production build's `GOWORK=off` is `bin/ship`'s, not the test gate's, and the
  dashboard commits no separate standalone build check.

**Where the proof lives.** Both adopted ids are proven in
**`cmd/dashboard/docs_test.go`**, the file the dashboard already uses for doc-truth
(D6's `AGENTS.md` assertion lives there). The doc-truth test reads the committed
`dashboard/AGENTS.md` from disk and asserts its Tests section declares the four
facts above; the source scan walks the tree's `*_test.go` files, skips any file
carrying the `live` build constraint, and asserts zero occurrences of the skip
verbs — assembling its needle from parts so the scan never matches its own source.

**Rejected.**

- **Restate the contract's layer definitions locally so this design reads
  self-contained.** A local restatement is drift by construction: it goes stale the
  moment `root project/design/D23.md` is rewritten, and the suite's rule is cite,
  never restate. The citation is the whole mechanism. Rejected.
- **Keep the conventional `unit` / `integration` / `end-to-end` names and map them
  in prose.** Rejected by the contract itself, and for the dashboard specifically:
  "unit" is exactly what its `AGENTS.md` calls a Tests section whose suite includes
  a boot smoke that compiles and runs a real binary. The layer names say what a
  test may *touch*, which is the property actually being policed.
- **Re-mint local ids for the two behaviors instead of citing
  `R-O1AD-MRKW` / `R-O2IA-0JBL`.** Both are `[proof: per-service]`: the ids are the
  suite's handles for one behavior each, proven once per adopting tree. Minting
  parallel local ids would give one behavior two handles and break the id-to-behavior
  invariant. Rejected.
- **Declare the dashboard's interactive sign-in a `live` layer.** Live means a real
  external service reachable with credentials under `go test -tags live`. An
  interactive browser consent screen is not reachable that way at all; calling it
  live would promise an invocation that cannot exist. Manual is the contract's name
  for it. Rejected.
- **Fold this citation into D34 (the install-layout / manifest conformance
  Decision).** D34 adopts two different contracts with their own proof sites; a
  separate Decision keeps each citation greppable and each Decision readable.
  Rejected.

**Verification.**

  default-gate test command (`go test ./...`), the layers present (hermetic,
  composed, manual, and no live), that there are no environmental preconditions
  beyond the Go toolchain, and the GOWORK mode (workspace).
- `R-O2IA-0JBL` — adopted from `root project/design/D23.md`. Substrate: hermetic —
