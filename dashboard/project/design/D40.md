# Decision 40 — The install page: connect-your-agent moves to `/install`

**Decision.** The connect-your-agent surface is its own page at `GET /install`
(route and gate: D1), wearing the shared shell (D10). Its body is one section:

- **`<h2>Connect your agent</h2>`**, followed by a one-paragraph lede in body
  text (max-width 680px):

  > A single command to wire your agent to every Ikigenba MCP Service.
  > Requires a personal access token (PAT), created on the profile page,
  > assigned to the `IKIGENBA_TOKEN` environment variable.

  with `IKIGENBA_TOKEN` rendered as inline code in the wiki idiom (mono,
  surface background, hairline border).
- **Two stacked agent subsections**, Claude Code first, Codex second — peers,
  vertically stacked in the 680px content column, each:
  - a display `<h3>` (`Claude Code` / `Codex`),
  - a one-line muted description (`Adds each service to <agent>'s MCP
    configuration.`),
  - a **snippet box**: flat `--color-surface` box with hairline border holding
    the install command in mono —
    `curl -fsSL {{.Scheme}}://{{.Host}}/install/claude | bash` (resp.
    `…/install/codex`) — and a flush **Copy** control on its right edge
    (borderless, separated by a hairline left border; part of the box, unlike
    the free-standing bordered row buttons), wired to the shared copy JS.

The `/install/claude` and `/install/codex` script endpoints are untouched; the
page presents them. The home page no longer carries any of this (D5,
R-VJH9-9GQY).

**Rejected.**
- **Side-by-side agent columns** — the command lines don't fit half the
  column without wrapping or shrinking the mono size; stacked full-width
  snippets keep one consistent type scale.
- **Repeating the snippets on the home page too** — one home for a task; two
  copies drift.
- **Bordered button style for the snippet's copy control** — inside the box
  the flush style reads as part of the snippet; the bordered style is for
  free-standing row actions (D5).

**Verification.**
- R-VVO9-365W — `GET /install` (live session) renders, in order: an `<h2>`
  reading `Connect your agent`; an `<h3>` reading `Claude Code` above a
  snippet containing `/install/claude | bash` with a copy control; then an
  `<h3>` reading `Codex` above a snippet containing `/install/codex | bash`
  with a copy control — Claude Code strictly before Codex in the body.
- R-VWW5-GXWL — The install page's lede paragraph mentions the personal
  access token: it contains `personal access token`, the literal
  `IKIGENBA_TOKEN` inside a `<code>` element, and a reference to the profile
  page.
