# Decision 30 — The served-tree root composes from `IKIGENBA_ROOT`; no box-path literal in sites code

**Problem.** The served-tree root is the one sites path the root env contract
did not reach (the gap D14 records): `internal/sites/layout.go` compiles in
`DefaultRoot = "/opt/sites/state/www"` and falls back to it whenever
`SITES_ROOT` is unset — an absolute box path baked into production Go source,
exactly the pattern root `project/design/D11.md` now forbids (its
box-path-literal guard R-VKB6-SHHV). Nothing in the production launch chain
sets `SITES_ROOT`, so the deployed binary runs on the compiled-in path, and a
dev process started without the harness would silently target `/opt`.

**Decision.** The served-tree root resolves **once, at the composition root**
(`cmd/sites/main.go`), by the root env contract's ladder — the same shape
appkit's `composeDataPaths` uses for the DB and generation paths:

```go
// resolveSitesRoot: explicit override → IKIGENBA_ROOT composition → dev fallback.
func resolveSitesRoot(getenv func(string) string) string {
    if v := strings.TrimSpace(getenv("SITES_ROOT")); v != "" {
        return v // dev harness (bin/start) and opsctl keep their explicit path
    }
    if root := strings.TrimSpace(getenv("IKIGENBA_ROOT")); root != "" {
        return filepath.Join(root, "sites", "state", "www") // /opt/sites/state/www on a box
    }
    return "./tmp/www" // dev checkout fallback, wiped by bin/stop --clean
}
```

- **Production needs no new variable**: `IKIGENBA_ROOT=/opt` is already in every
  unit's environment, and the composed value is byte-identical to the old
  compiled-in default, so the deployed layout does not move.
- The root lands inside `state/` deliberately — site files are owner data on the
  backup side of the root `state/` ÷ `cache/` boundary; composition preserves
  that placement.
- **`internal/sites` stops defaulting** — validate at the boundary, trust
  internal code: the `DefaultRoot` constant is **deleted**, `NewLayout` returns
  an error on an empty root instead of substituting one, and the zero-`Layout`
  fallback in `root()` goes with it (an empty root reaching the layout is a
  programming error, not a fallback site). The path helpers (`Seg`, `SiteDir`,
  `SiteBase`, the segment constants) are unchanged.
- The appkit fail-loud guard already covers the misconfigured-production case
  (`IKIGENBA_DOMAIN` set without `IKIGENBA_ROOT` refuses to start), so the
  ladder never silently composes the dev fallback on a box.

**Adoption of the box-path-literal guard.** This Decision adopts the root env
contract's `[proof: per-service]` id **R-VKB6-SHHV** (root
`project/design/D11.md`): a source-scan test in `cmd/sites/main_test.go` walks
sites' non-test `.go` files and fails on any `"/opt` string literal — which is
what keeps `DefaultRoot` from quietly returning.

Classification note (root `project/design/D21.md`): `SITES_ROOT` is a
dev/opsctl **override** (channel 4), like `<APP>_DB_PATH` — never a manifest
key: its production value is an absolute box path, which the manifest's
portability proof (R-8DF1-W89F) forbids the committed file to carry.

**Rejected.**
- *Promote `SITES_ROOT` into `manifest.env`.* The production value is an
  absolute `/opt` path; a portable committed manifest cannot carry it, and a
  relative manifest value would just re-encode the composition this Decision
  does explicitly. Rejected.
- *Keep `DefaultRoot` as a belt-and-braces fallback under the composition.* A
  silent compiled-in box path is the defect, not a safety net; the fail-loud
  guard owns the misconfiguration case. Rejected.
- *Compose inside `internal/sites` (read env in `NewLayout`).* Moves an env
  read into a pure package and duplicates the single point of wiring; the
  layout file's own header states the root is injected. Rejected — composition
  stays in `cmd/sites`.

**Verification.**
- R-YWR7-Z1GM — the served-tree root resolution follows the ladder exactly:
  with `SITES_ROOT=/x` set the resolved root is `/x` regardless of
  `IKIGENBA_ROOT`; with only `IKIGENBA_ROOT=/y` set it is `/y/sites/state/www`;
  with neither it is `./tmp/www` — never `/opt/sites/state/www`. Substrate:
  unit test over the resolver with an injected `getenv`.
- R-YXZ4-CT7B — `internal/sites` fails loudly on a missing root instead of
  defaulting: `NewLayout("")` returns an error (no Layout is constructed), and
  no code path in the package substitutes a compiled-in root for an empty one.
  Substrate: unit test in `internal/sites`.
- Adopts **R-VKB6-SHHV** (root `project/design/D11.md`, `[proof: per-service]`)
  — no `"/opt` string literal in sites' non-test Go source. Substrate: the
  source-scan test in `cmd/sites/main_test.go`.
