# D01-layout-and-run-seam

The CLI composes small domain packages. Host execution, time, DNS and cloud
access have injected boundaries so callers can exercise commands against a
temporary host tree without changing the machine running the tests.

The production cloud adapter is `internal/cloud/aws`. It uses the approved AWS
SDK v2 S3 and SSM modules behind the same injected boundary used by tests; no
gate contacts AWS. The bucket a host backs up to is named after the root
domain (`ikigenba.dev`), and a bucket name with dots in it cannot be addressed
as a hostname over TLS, so the adapter's S3 client always addresses the bucket
path-style, and it leaves the SDK's own endpoint configuration in force so a
gate test can point the client at a fake endpoint and watch the request shape.

`internal/host` also holds the one derivation every apex-aware command shares:
`Apex` turns the host's own name into the parent domain it may answer at
(`ikigenba.dev` for `sbx.ikigenba.dev`) or refuses a name too short to have
one. It is a pure function of the host's name, which is a host fact, and it
lives here because `cli`, `nginx`, and `cert` may all import `host` and none
of them may import each other. Beside it sits `NormalizeName`, the one
spelling rule for a stored `host.name` (lowercase, one trailing dot dropped),
so every reader of the store hands the same bytes to `Apex`, to paths, and to
output.

- R-5E43-77RM: `Run` MUST normalize nil `Deps.Getenv` to an empty environment, nil `Deps.LookPath` to `exec.LookPath`, nil `Deps.LookupHost` to `net.DefaultResolver.LookupHost`, and nil `Deps.Now` to `time.Now`; it MUST pass the corresponding normalized environmental values to domain operations without replacing a supplied dependency.
- R-GU6L-Z0L7: Every host path a command invoked through `cli.Run` reads or writes MUST be resolved under `Deps.Root`, verified by invoking commands with a temporary directory as `Root` and observing their filesystem effects only under that directory; domain functions receiving a root or `host.Env` MUST preserve that boundary.

- R-DP30-VDTS: `internal/cloud/aws.Open` MUST leave the SDK's documented endpoint configuration in force for its S3 client, so that when the environment variable `AWS_ENDPOINT_URL_S3` names a URL the returned client sends its S3 requests to that URL instead of the AWS endpoint; the path-style rule MUST be verified against a fake HTTP endpoint reached this way and addressed by host name rather than IP literal, observing an object request whose `Host` is the endpoint's own host and whose path begins with `/<bucket>/`.
