# D01-layout-and-run-seam

The CLI composes small domain packages. Host execution, time, DNS and cloud
access have injected boundaries so callers can exercise commands against a
temporary host tree without changing the machine running the tests.

The production cloud adapter is `internal/cloud/aws`. It uses the approved AWS
SDK v2 S3 and SSM modules behind the same injected boundary used by tests; no
gate contacts AWS.

## REQUIREMENTS

- R-EL9M-CEGL: The module MUST be `github.com/ikigenba/ikigenba/opsctl` with its own `go.mod` that specifies a Go version, and the module paths of the direct (non-`// indirect`) `require` entries of that `go.mod` MUST be exactly `github.com/aws/aws-sdk-go-v2`, `github.com/aws/aws-sdk-go-v2/config`, `github.com/aws/aws-sdk-go-v2/service/route53`, `github.com/aws/aws-sdk-go-v2/service/s3`, and `github.com/aws/aws-sdk-go-v2/service/ssm`, verified by a test that reads `go.mod`.
- R-MUPN-JCBU: Package `internal/cli` MUST export `Run(args []string, stdin io.Reader, stdout, stderr io.Writer, deps Deps) int`, and calling it MUST return an exit code in-process without terminating the calling program.
- R-5CW6-TG0X: Package `internal/cli` MUST export `Deps` with exactly the fields `Root string`, `EUID int`, `Getenv func(key string) string`, `DNS dns.Env`, `LookPath func(file string) (string, error)`, `LookupHost func(ctx context.Context, host string) ([]string, error)`, `Execute func(context.Context, host.Command) (host.Result, error)`, `Now func() time.Time`, and `Cloud cloud.Env`.
- R-5E43-77RM: `Run` MUST normalize nil `Deps.Getenv` to an empty environment, nil `Deps.LookPath` to `exec.LookPath`, nil `Deps.LookupHost` to `net.DefaultResolver.LookupHost`, and nil `Deps.Now` to `time.Now`; it MUST pass the corresponding normalized environmental values to domain operations without replacing a supplied dependency.
- R-GU6L-Z0L7: Every host path a command invoked through `cli.Run` reads or writes MUST be resolved under `Deps.Root`, verified by invoking commands with a temporary directory as `Root` and observing their filesystem effects only under that directory; domain functions receiving a root or `host.Env` MUST preserve that boundary.
- R-5FBZ-KZIB: The module MUST contain `cmd/opsctl` for process wiring, `internal/cli` for grammar, diagnostics, dispatch and workflow composition, `internal/config` for the configuration store, `internal/dns` for DNS domain operations, `internal/dns/route53` for its provider, `internal/host` for host execution dependencies, `internal/cloud` for object and secret access, `internal/cloud/aws` for its production provider, `internal/apps` for service discovery, manifests and app operations, `internal/nginx` for nginx generation and application, `internal/cert` for certificate inspection and obtaining, and `internal/backup` for backup, restore, replication and timer operations; within this module `cmd/opsctl` MAY import `cli`, `dns`, `dns/route53`, `cloud`, `cloud/aws`, and `host`, `cli` MAY import all domain packages except `dns/route53` and `cloud/aws`, `dns/route53` MAY import `dns`, `cloud/aws` MAY import `cloud`, `dns` MAY import `config`, `apps` MAY import `config`, `host`, and `cloud`, `nginx` MAY import `config`, `host`, and `apps`, `cert` MAY import `config` and `host`, and `backup` MAY import `config`, `host`, `cloud`, and `apps`; these are the only permitted production import edges. Only `dns/route53` MAY import the approved AWS SDK v2 core, `config`, and `service/route53` modules, and only `cloud/aws` MAY import the approved AWS SDK v2 core, `config`, `service/s3`, and `service/ssm` modules.
- R-5GJV-YR90: Package `internal/host` MUST export `Env` with exactly the fields `Root string`, `Getenv func(string) string`, `Execute func(context.Context, Command) (Result, error)`, and `Now func() time.Time`.
- R-5HRS-CIZP: Package `internal/host` MUST export `Command` with exactly the fields `Name string`, `Args []string`, `Dir string`, `Env []string`, and `Stdin io.Reader`.
- R-5IZO-QAQE: Package `internal/host` MUST export `Result` with exactly the fields `Stdout []byte`, `Stderr []byte`, and `ExitCode int`.
- R-5LFH-HU7S: Package `internal/host` MUST export `Exec(ctx context.Context, command Command) (Result, error)`; it MUST invoke `Command.Name` directly with `Command.Args`, without shell interpretation, use `Command.Dir` as the working directory when nonempty, overlay `Command.Env` entries on the inherited environment, connect `Command.Stdin` to standard input, and capture standard output and standard error separately without altering their bytes; a completed process returns its exit status in `Result.ExitCode` with nil error, including a nonzero exit status, while inability to start or await completion returns an error.
- R-AMEV-4J2G: Domain operations receiving `host.Env` MUST perform external process execution only through their supplied `host.Env.Execute`, obtain the current time only through `host.Env.Now`, and read environment variables only through `host.Env.Getenv`; a missing required dependency MUST return an operational error before that dependent action rather than falling back to a live process, clock, or environment, and host filesystem paths supplied to process arguments or working directories MUST be resolved under `host.Env.Root` just as direct filesystem access is.
- R-5NVA-9DP6: Package `internal/cloud` MUST export `Env` with exactly the field `Open func(ctx context.Context, region string) (Client, error)`.
- R-5P36-N5FV: Package `internal/cloud` MUST export `Client` as an interface with methods `GetObject(ctx context.Context, uri string) (io.ReadCloser, error)`, `PutObject(ctx context.Context, uri string, body io.Reader) error`, `ListObjects(ctx context.Context, prefix string) ([]Object, error)`, and `ReadSecrets(ctx context.Context, parameter string) (map[string]string, error)`.
- R-5QB3-0X6K: Package `internal/cloud` MUST export `Object` with exactly the fields `URI string`, `Size int64`, and `Modified time.Time`.
- R-5RIZ-EOX9: Package `internal/cloud` MUST export sentinel `ErrNotFound error`; a missing object or secret parameter MUST be reported by an error matching it through `errors.Is`, distinct from denied access and transport errors.
- R-ANMR-IAT5: Cloud-consuming operations MUST open `cloud.Env` with the configured region and use its returned `Client` for object and parameter access; an absent `Open` MUST return an operational error without network access, and `GetObject` readers MUST be closed by callers. `internal/cloud/aws.Open` MUST load the default AWS SDK configuration with the supplied region and return one client backed by S3 and SSM. The adapter's operational client MUST depend only on injected interfaces containing the S3 `GetObject`, `PutObject`, and `ListObjectsV2` operations and the SSM `GetParameter` operation; `Open` MUST supply the concrete SDK clients, allowing gate tests to exercise adapter behavior without network access. Object operations MUST accept only absolute `s3://` URIs with a nonempty bucket, no userinfo, port, opaque form, query or fragment, remove exactly one leading slash from the URL-decoded path without cleaning other key bytes, and require a nonempty key for get and put. `GetObject` MUST return the S3 response body unchanged and map only S3 `NoSuchKey` to an error matching `cloud.ErrNotFound`. `ListObjects` MUST call `ListObjectsV2` without a delimiter, follow every paginator page, return no successful partial list after a later-page failure, reject malformed entries missing their key, size or modification time, and return every object as the canonical `s3://` URI plus its size and modification time without assuming provider order. `ReadSecrets` MUST call SSM `GetParameter` with the exact parameter name and decryption enabled, map only `ParameterNotFound` to an error matching `cloud.ErrNotFound`, and decode the value as one UTF-8 JSON object with unique member names and string values, preserving empty objects and empty values while rejecting null, other JSON shapes, duplicate names and trailing non-whitespace data. Provider responses, parameter JSON source text, and decoded secret values MUST NOT appear in adapter errors or diagnostics; the adapter MAY identify the caller-supplied parameter name, and callers retain D09's obligation to identify a missing requested manifest secret without exposing its value.
- R-AOUN-W2JU: Package `internal/cloud` MUST export sentinel `ErrAlreadyExists error`.
- R-AQ2K-9UAJ: `internal/cloud/aws` MUST implement `Client.PutObject` with one direct S3 `PutObject` call using the parsed bucket and key, the supplied body, and `IfNoneMatch` exactly `*`; it MUST report success only after that call accepts the complete body. It MUST map only the exact conditional errors `PreconditionFailed` with HTTP status 412 and `ConditionalRequestConflict` with HTTP status 409 to errors matching `cloud.ErrAlreadyExists`, preserving the provider error as a cause; it MUST NOT retry the conditional conflict or map unrelated 409 or 412 responses. Therefore an existing object remains unchanged, and when concurrent writers target the same initially absent URI at most one may succeed while every colliding writer receives `ErrAlreadyExists` through `errors.Is`.
- R-5TYS-68EN: `cmd/opsctl` MUST wire `os.Args[1:]`, `os.Stdin`, `os.Stdout`, and `os.Stderr` to `cli.Run` with `Root: "/"`, `EUID: os.Geteuid()`, `Getenv: os.Getenv`, `DNS: dns.Env{Open: route53.Open}`, `LookPath: exec.LookPath`, `LookupHost: net.DefaultResolver.LookupHost`, `Execute: host.Exec`, `Now: time.Now`, and `Cloud: cloud.Env{Open: awscloud.Open}`, and pass the returned code to `os.Exit`; it MUST contain no command behavior.
- R-N0T5-G71B: The binary built from `./cmd/opsctl`, run with the single argument `--help`, MUST print the usage text of D2 to stdout, write nothing to stderr, and exit 0.

- R-GWME-QK2L: Package `internal/host` MUST export `CommandError` with exactly the fields `Label string`, `Result Result`, and `Err error`; domain operations MUST use this error type to preserve the concise command label and captured result when reporting an external process failure to the CLI.
- R-GXUB-4BTA: `*host.CommandError` MUST implement `Error() string`, returning `Label + ": " + Err.Error()` when `Err` is non-nil and otherwise `Label + ": exit status "` followed by the decimal `Result.ExitCode`.
- R-GZ27-I3JZ: `*host.CommandError` MUST implement `Unwrap() error`, returning `Err`.
