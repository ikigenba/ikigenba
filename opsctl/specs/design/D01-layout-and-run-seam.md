# D01-layout-and-run-seam

The CLI composes small domain packages. Host execution, time, DNS and cloud
access have injected boundaries so callers can exercise commands against a
temporary host tree without changing the machine running the tests.

The cloud contract supports authoring the new command workflows; approval and
evidence for its production adapter are tracked outside this design.

## REQUIREMENTS

- R-EL9M-CEGL: The module MUST be `github.com/ikigenba/ikigenba/opsctl` with its own `go.mod` that specifies a Go version, and the module paths of the direct (non-`// indirect`) `require` entries of that `go.mod` MUST be exactly `github.com/aws/aws-sdk-go-v2`, `github.com/aws/aws-sdk-go-v2/config`, and `github.com/aws/aws-sdk-go-v2/service/route53`, verified by a test that reads `go.mod`.
- R-MUPN-JCBU: Package `internal/cli` MUST export `Run(args []string, stdin io.Reader, stdout, stderr io.Writer, deps Deps) int`, and calling it MUST return an exit code in-process without terminating the calling program.
- R-5CW6-TG0X: Package `internal/cli` MUST export `Deps` with exactly the fields `Root string`, `EUID int`, `Getenv func(key string) string`, `DNS dns.Env`, `LookPath func(file string) (string, error)`, `LookupHost func(ctx context.Context, host string) ([]string, error)`, `Execute func(context.Context, host.Command) (host.Result, error)`, `Now func() time.Time`, and `Cloud cloud.Env`.
- R-5E43-77RM: `Run` MUST normalize nil `Deps.Getenv` to an empty environment, nil `Deps.LookPath` to `exec.LookPath`, nil `Deps.LookupHost` to `net.DefaultResolver.LookupHost`, and nil `Deps.Now` to `time.Now`; it MUST pass the corresponding normalized environmental values to domain operations without replacing a supplied dependency.
- R-GU6L-Z0L7: Every host path a command invoked through `cli.Run` reads or writes MUST be resolved under `Deps.Root`, verified by invoking commands with a temporary directory as `Root` and observing their filesystem effects only under that directory; domain functions receiving a root or `host.Env` MUST preserve that boundary.
- R-5FBZ-KZIB: The module MUST contain `cmd/opsctl` for process wiring, `internal/cli` for grammar, diagnostics, dispatch and workflow composition, `internal/config` for the configuration store, `internal/dns` for DNS domain operations, `internal/dns/route53` for its provider, `internal/host` for host execution dependencies, `internal/cloud` for object and secret access, `internal/apps` for service discovery, manifests and app operations, `internal/nginx` for nginx generation and application, `internal/cert` for certificate inspection and obtaining, and `internal/backup` for backup, restore, replication and timer operations; within this module `cmd/opsctl` MAY import `cli`, `dns`, `dns/route53`, and `host`, `cli` MAY import all domain packages except `dns/route53`, `dns/route53` MAY import `dns`, `dns` MAY import `config`, `apps` MAY import `config`, `host`, and `cloud`, `nginx` MAY import `config`, `host`, and `apps`, `cert` MAY import `config` and `host`, and `backup` MAY import `config`, `host`, `cloud`, and `apps`; these are the only permitted production import edges, and only `dns/route53` MAY import the approved AWS modules.
- R-5GJV-YR90: Package `internal/host` MUST export `Env` with exactly the fields `Root string`, `Getenv func(string) string`, `Execute func(context.Context, Command) (Result, error)`, and `Now func() time.Time`.
- R-5HRS-CIZP: Package `internal/host` MUST export `Command` with exactly the fields `Name string`, `Args []string`, `Dir string`, `Env []string`, and `Stdin io.Reader`.
- R-5IZO-QAQE: Package `internal/host` MUST export `Result` with exactly the fields `Stdout []byte`, `Stderr []byte`, and `ExitCode int`.
- R-5LFH-HU7S: Package `internal/host` MUST export `Exec(ctx context.Context, command Command) (Result, error)`; it MUST invoke `Command.Name` directly with `Command.Args`, without shell interpretation, use `Command.Dir` as the working directory when nonempty, overlay `Command.Env` entries on the inherited environment, connect `Command.Stdin` to standard input, and capture standard output and standard error separately without altering their bytes; a completed process returns its exit status in `Result.ExitCode` with nil error, including a nonzero exit status, while inability to start or await completion returns an error.
- R-AMEV-4J2G: Domain operations receiving `host.Env` MUST perform external process execution only through their supplied `host.Env.Execute`, obtain the current time only through `host.Env.Now`, and read environment variables only through `host.Env.Getenv`; a missing required dependency MUST return an operational error before that dependent action rather than falling back to a live process, clock, or environment, and host filesystem paths supplied to process arguments or working directories MUST be resolved under `host.Env.Root` just as direct filesystem access is.
- R-5NVA-9DP6: Package `internal/cloud` MUST export `Env` with exactly the field `Open func(ctx context.Context, region string) (Client, error)`.
- R-5P36-N5FV: Package `internal/cloud` MUST export `Client` as an interface with methods `GetObject(ctx context.Context, uri string) (io.ReadCloser, error)`, `PutObject(ctx context.Context, uri string, body io.Reader) error`, `ListObjects(ctx context.Context, prefix string) ([]Object, error)`, and `ReadSecrets(ctx context.Context, parameter string) (map[string]string, error)`.
- R-5QB3-0X6K: Package `internal/cloud` MUST export `Object` with exactly the fields `URI string`, `Size int64`, and `Modified time.Time`.
- R-5RIZ-EOX9: Package `internal/cloud` MUST export sentinel `ErrNotFound error`; a missing object or secret parameter MUST be reported by an error matching it through `errors.Is`, distinct from denied access and transport errors.
- R-ANMR-IAT5: Cloud-consuming operations MUST open `cloud.Env` with the configured region and use its returned `Client` for object and parameter access; an absent `Open` MUST return an operational error without network access, `GetObject` readers MUST be closed by callers, `ListObjects` MUST include every matching object across pagination, and `ReadSecrets` MUST return the named parameter as a map of secret names to values without exposing those values through diagnostics or command arguments.
- R-AOUN-W2JU: Package `internal/cloud` MUST export sentinel `ErrAlreadyExists error`.
- R-AQ2K-9UAJ: `Client.PutObject` MUST atomically create an object only when its URI is absent, report success only when the complete supplied body has been accepted, and return an error matching `ErrAlreadyExists` through `errors.Is` when the URI already exists; a collision MUST preserve the existing object unchanged, including when concurrent writers target the same initially absent URI, for which at most one writer may succeed and every colliding writer MUST receive that error.
- R-5TYS-68EN: `cmd/opsctl` MUST wire `os.Args[1:]`, `os.Stdin`, `os.Stdout`, and `os.Stderr` to `cli.Run` with `Root: "/"`, `EUID: os.Geteuid()`, `Getenv: os.Getenv`, `DNS: dns.Env{Open: route53.Open}`, `LookPath: exec.LookPath`, `LookupHost: net.DefaultResolver.LookupHost`, `Execute: host.Exec`, and `Now: time.Now`, and pass the returned code to `os.Exit`; it MUST contain no command behavior.
- R-N0T5-G71B: The binary built from `./cmd/opsctl`, run with the single argument `--help`, MUST print the usage text of D2 to stdout, write nothing to stderr, and exit 0.

- R-GWME-QK2L: Package `internal/host` MUST export `CommandError` with exactly the fields `Label string`, `Result Result`, and `Err error`; domain operations MUST use this error type to preserve the concise command label and captured result when reporting an external process failure to the CLI.
- R-GXUB-4BTA: `*host.CommandError` MUST implement `Error() string`, returning `Label + ": " + Err.Error()` when `Err` is non-nil and otherwise `Label + ": exit status "` followed by the decimal `Result.ExitCode`.
- R-GZ27-I3JZ: `*host.CommandError` MUST implement `Unwrap() error`, returning `Err`.
