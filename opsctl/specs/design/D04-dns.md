# D04-dns

Package `internal/dns` owns configured-zone selection, DNS records, and the
provider interface. `internal/dns/route53` supplies the sole production
provider. Additive mutations support certbot's overlapping DNS-01 tokens.

## REQUIREMENTS

- R-DISH-VEPP: Package `internal/dns` MUST export the constant `KeyZones = "dns.zones"`.
- R-DMG7-0PXS: Package `internal/dns` MUST export the sentinel error `ErrNotConfigured`.

- R-EC23-1WID: Package `internal/dns` MUST export `(*Client) ZoneFor(name string) (Zone, error)`.

- R-EGXO-KZH5: Package `internal/dns` MUST export `(*Client) Add(ctx context.Context, name, typ string, ttl int, value string) error`.
- R-EJDH-CIYJ: Package `internal/dns` MUST export `(*Client) Remove(ctx context.Context, name, typ, value string) error`.
- R-ELTA-42FX: Package `internal/dns` MUST export `(*Client) Check(ctx context.Context, zone Zone) (CheckResult, error)`.
- R-XS5E-41C6: `Open` MUST return an error that `errors.Is` `ErrNotConfigured`, without calling `Env.Open`, whose `Error()` is exactly `dns.provider not set` when `dns.provider` is unset or empty, exactly `dns.zones not set` when `dns.zones` is unset or empty, and otherwise `dns.zones malformed: ` followed by the first comma-separated entry, rendered with `%q`, that is invalid under the zone-entry validation requirements.
- R-YVC3-MFBD: `Open` MUST split `dns.zones` on commas and each entry on its first colon into a name and an id, trim surrounding whitespace from both, lowercase the name and strip one trailing dot from it, leave the id unchanged apart from trimming, preserve order, and populate `Client.Zones` with each resulting name and id.
- R-L1RD-UPSF: `Open` MUST call `Env.Open` with the value of `dns.provider` and return its error unchanged, and when `Env.Open` is nil MUST return an error wrapping `ErrUnknownProvider` that names the provider.
- R-L2ZA-8HJ4: `ZoneFor` MUST lowercase the name and strip one trailing dot, return the configured zone with the longest name that equals the name or is a suffix of it preceded by a dot, and return an error wrapping `ErrNoZone` when no zone matches.
- R-L476-M99T: `Client.Add` and `Client.Remove` MUST resolve the zone with `ZoneFor` and call the provider's `Add` or `Remove` with that zone's `ID`, the normalised name, the type uppercased, and the value unchanged, and MUST return the provider's error unchanged.
- R-XTDA-HT2V: `Check` MUST call `Provider.Records` for the zone, return its error unchanged on failure, set `ZoneName` to the name of the `SOA` record and `Nameservers` to the values of the `NS` record at that name, return an error when no `SOA` record is present, return a resolver error unchanged when `Env.LookupNS(zone.Name)` fails, and otherwise set `Delegated` to true exactly when `Nameservers` is non-empty and the resolver returns the same set of names ignoring order, case, and trailing dots.
- R-L6MZ-DSR7: `Check` with a nil `Env.LookupNS` MUST resolve NS records through `net.DefaultResolver`.
- R-7JWE-YKBM: Package `internal/dns/route53` MUST export the constant `Region = "us-east-1"`.
- R-ERWS-0X5E: Package `internal/dns/route53` MUST export `New(ctx context.Context, endpoint string) (dns.Provider, error)`.
- R-EUCK-SGMS: Package `internal/dns/route53` MUST export `Open(ctx context.Context, provider string) (dns.Provider, error)`.
- R-L92S-5C8L: `route53.Open` MUST return the provider from `New(ctx, "")` for `"route53"` and an error wrapping `dns.ErrUnknownProvider` naming the provider for any other value.
- R-LAAO-J3ZA: The provider returned by `New` MUST send every Route 53 request signed for region `Region` to `endpoint` when it is non-empty, verified against a fake HTTP endpoint, and MUST read credentials only through the SDK's default credential chain.
- R-EWSD-K046: The Route 53 provider's `Records` MUST return every record set across all pages as one `Record` per set, with names lowercased, one trailing dot removed, and `\052` decoded to `*`; TXT values MUST be unquoted, NS values MUST have one trailing dot removed, and other values, including SOA data, MUST retain their provider representation.
- R-LDYD-OF7D: `Add` of the Route 53 provider MUST create the record set with `ttl` when it is absent, MUST otherwise submit the set with the existing values, the existing TTL, and the new value appended, MUST send TXT values enclosed in double quotes, and MUST return nil without submitting a change when the value is already present.
- R-LF6A-26Y2: `Remove` of the Route 53 provider MUST submit the set without the value when other values remain, MUST delete the set when the value is its last, and MUST return nil without submitting a change when the set or the value is absent.
- R-EY09-XRUV: After submitting a change, the Route 53 provider's `Add` and `Remove` MUST return nil only after `GetChange` reports `INSYNC`, return an error wrapping `ctx.Err()` if the context ends first, and leave the submitted change in place without rollback; an idempotent operation that submits no change MUST return nil without waiting for `GetChange`.
- R-F1NZ-332Y: `opsctl dns --help` and `opsctl dns -h` MUST, for any effective uid and without reading configuration, opening a provider, making network calls, or changing state, exit 0 with empty stderr and stdout exactly the escaped string `"Usage: opsctl dns <subcommand> [options] [arguments]\n\nManage DNS records in the zones opsctl owns, through the configured provider.\n\nSubcommands:\n  list ZONE               print every record in ZONE, one line per value\n  add NAME TYPE VALUE     add VALUE to the record NAME/TYPE, creating it if absent\n  remove NAME TYPE VALUE  remove VALUE from the record NAME/TYPE; succeeds if absent\n  check                   verify every configured zone is reachable and delegated\n  acme-auth               certbot --manual-auth-hook: add the DNS-01 challenge record\n  acme-cleanup            certbot --manual-cleanup-hook: remove the challenge record\n\nOptions (add, remove, acme-auth, acme-cleanup):\n  --timeout DURATION  how long to wait for the change to be live (default 2m)\n  --ttl SECONDS       TTL when add creates a record (default 300; acme-auth uses 60)\n\nConfiguration keys:\n  dns.provider  the active provider; only 'route53' is supported\n  dns.zones     comma-separated NAME:ID pairs of the zones opsctl owns\n\nNAME is mapped to a zone by longest suffix match against the zone names.\n"`.
- R-LITZ-7I65: `opsctl dns` with no subcommand MUST write exactly the three lines `opsctl: no dns subcommand given`, an empty line, and `see 'opsctl dns --help' for usage` to stderr and exit 2, and with an unknown subcommand MUST write exactly the three lines `opsctl: unknown dns subcommand '<name>'`, an empty line, and `see 'opsctl dns --help' for usage` to stderr and exit 2.
- R-WL0S-P73L: Every recognized `dns` operation (`list`, `add`, `remove`, `check`, `acme-auth`, and `acme-cleanup`) whose grammar and required hook environment are valid MUST obtain its configuration only from the D3 config store through `dns.Open` with `Deps.DNS`, never from bootstrap files or provider discovery; missing or malformed configuration MUST produce exit 1, empty stdout, and stderr exactly `opsctl: <error>\n` using the `ErrNotConfigured` error text, without opening a provider or making a network call.
- R-LL9R-Z1NJ: `opsctl dns list ZONE` MUST print one line `NAME TYPE TTL VALUE` per value of every record in ZONE, sorted by name, then type, then value, to stdout and exit 0, and MUST write `opsctl: zone not configured: ZONE` followed by an empty line and `configured zones: <comma-separated Client.Zones names>` to stderr and exit 2 when ZONE is not a configured zone.
- R-LMHO-CTE8: `opsctl dns add [--ttl SECONDS] [--timeout DURATION] NAME TYPE VALUE` MUST call `Client.Add` with TTL defaulting to 300 and a context whose deadline is DURATION from now defaulting to 2 minutes, print nothing to stdout, and exit 0 on success; `opsctl dns remove [--timeout DURATION] NAME TYPE VALUE` MUST likewise call `Client.Remove`.
- R-LNPK-QL4X: `add` and `remove` with a wrong number of positional arguments, a `--ttl` that is not a positive integer, or a `--timeout` that is not a positive duration MUST exit 2 with a diagnostic on stderr, and when `ZoneFor` fails MUST write `opsctl: no configured zone contains '<NAME>'` followed by an empty line and `configured zones: <comma-separated Client.Zones names>` to stderr and exit 2.
- R-LOXH-4CVM: When the provider returns an error wrapping `context.DeadlineExceeded`, `add`, `remove`, `acme-auth`, and `acme-cleanup` MUST write the single line `opsctl: change to <NAME> not confirmed within <DURATION>` to stderr and exit 1, and for any other provider error MUST write `opsctl: <error>` and exit 1.
- R-F6JK-M61Q: `opsctl dns check` MUST call `Client.Check` for every configured zone in order despite earlier failures, print exactly one newline-terminated line per zone to stdout and nothing to stderr, and exit 0 if all zones pass or 1 otherwise; the line MUST be `<zone>: ok (<provider> <id>, <n> nameservers delegated)` when `ZoneName` equals the configured zone name and `Delegated` is true, `<zone>: failed: nameservers not delegated` when that name matches but `Delegated` is false, `<zone>: failed: provider zone name is <ZoneName>` when it differs, or `<zone>: failed: <error>` on a `Client.Check` error.
- R-9T74-56HN: `opsctl dns acme-auth [--timeout DURATION]` MUST read `CERTBOT_DOMAIN` and `CERTBOT_VALIDATION` through `Deps.Getenv`, exit 2 with the single line `opsctl: acme-auth must be run by certbot as --manual-auth-hook` on stderr when either is empty, and otherwise call `Client.Add` with name `_acme-challenge.<CERTBOT_DOMAIN>`, type `TXT`, requested TTL 60, and the validation as the value, printing nothing to stdout and exiting 0 on success; the hook MUST use TTL 60 only when creating an absent TXT record set, preserve the TTL of an existing set, and preserve every other value in either case.
- R-LSL6-9O3P: `opsctl dns acme-cleanup [--timeout DURATION]` MUST read the same variables through `Deps.Getenv`, exit 2 with the single line `opsctl: acme-cleanup must be run by certbot as --manual-cleanup-hook` on stderr when either is empty, and otherwise call `Client.Remove` with name `_acme-challenge.<CERTBOT_DOMAIN>`, type `TXT`, and the validation as the value, printing nothing to stdout and exiting 0 on success.
- R-F8ZD-DPJ4: Every `dns` invocation other than `--help` and `-h` MUST be subject to the root check of D2.
- R-FBF6-590I: `Client.Records` MUST return `Provider.Records(ctx, zone.ID)` records and error unchanged for a configured `Zone`; `Client.Records` and `Client.Check` MUST reject a `Zone` whose name and ID pair is absent from `Client.Zones` with an error wrapping `ErrNoZone` before calling the provider or resolver.
- R-FF2V-AK8L: `dns.Open` MUST read `KeyProvider` before `KeyZones`, validate all zone entries after trimming, and reject a missing colon, an empty normalized name, or an empty trimmed ID with the malformed-configuration error before opening a provider; errors reading the store other than an unset key MUST be returned unchanged.
- R-FIQK-FVGO: `Provider.Records` and `Client.Check` MUST perform no writes; provider `Add` and `Remove` MUST change only the requested value of the requested name/type in the given zone, preserve every other value and record and the TTL of an existing set, and perform no other persistent host-state changes.
- R-FL6D-7EY2: An unsuccessful zone match for `add`, `remove`, `acme-auth`, or `acme-cleanup` MUST produce exit 2, empty stdout, and stderr exactly `opsctl: no configured zone contains '<NAME>'\n\nconfigured zones: <names>\n`, with names in configured order separated by commas, and MUST make no provider call; a rejected `list ZONE` MUST likewise make no provider call.
- R-FME9-L6OR: Successful `dns list` MUST leave stderr empty and render each record value as the rest of its line without quoting or escaping, with literal wildcard names, no trailing dot on names, and unquoted TXT values that can be passed unchanged to `add` or `remove`.
- R-FOU2-CQ65: Successful `dns add`, `dns remove`, `dns acme-auth`, and `dns acme-cleanup` MUST write nothing to stdout or stderr; failure diagnostics MUST leave stdout empty, end with a newline, and follow D2 diagnostic formatting; missing or unknown subcommands, invalid arguments or options, missing hook environment, and configuration failures MUST leave all persistent state unchanged.
- R-WM8P-2YUA: `acme-auth` and `acme-cleanup` MUST accept no positional arguments and derive the domain and value exclusively from `CERTBOT_DOMAIN` and `CERTBOT_VALIDATION` through `Deps.Getenv`; after the root and grammar checks, missing or empty values MUST be rejected with the specified hook-purpose diagnostic before reading configuration, opening a provider, or making a network call, even when the store is absent, corrupt, or inaccessible.
- R-FTPN-VT4X: The mutation commands MUST accept `--timeout` as a positive Go duration before positional arguments, default it to `2m`, and apply that deadline to the provider operation; hooks MUST reject invalid duration or unexpected arguments with exit 2 and a diagnostic, and all mutation commands MUST accept a positive integer `--ttl` before positional arguments, using it only when `add` creates a set, with `acme-auth` always using 60 and removal operations ignoring it.
- R-FW5G-NCMB: `dns list` MUST require exactly one zone argument and `dns check` MUST accept no positional arguments or mutation options; invalid grammar MUST exit 2 with a diagnostic and without provider calls, and a provider-opening error or a `list` provider error MUST exit 1 with empty stdout and stderr `opsctl: <error>\n`.

- R-WJSW-BFCW: Each `Client` returned by `Open` MUST retain the `Env.LookupNS` supplied to that call for every subsequent `Check` on that client; `Check` MUST pass its context and the configured zone name to that resolver, using `net.DefaultResolver` only when that client's supplied resolver is nil, independently of any other client opened before or afterward.
- R-XUL6-VKTK: At the `Provider` boundary, `Record.Name` MUST be lowercase with no trailing dot and literal `*` rather than a provider wildcard escape, `Record.Type` MUST be uppercase, TXT `Record.Values` MUST contain the logical unquoted values, and NS `Record.Values` MUST have no trailing dot; `Provider.Add` and `Provider.Remove` MUST accept the same name, type, and value representations returned by `Provider.Records`, so listing a value and adding or removing it does not require caller knowledge of provider encoding.
