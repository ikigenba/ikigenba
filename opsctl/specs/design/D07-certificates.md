# D07-certificates

The host serves one certbot lineage for its apex and wildcard. Certificate
operations own issuance and inspection; DNS owns challenge hooks, init owns
sequencing, and backup timer setup owns scheduled renewal. The CLI composes
configuration with these operations.

Every hook opsctl hands certbot is a plain command, never a shell fragment.
certbot validates each hook before it does any ACME work: it splits the hook
string like a shell command line and requires the first word to resolve to an
executable on PATH, refusing the whole invocation otherwise (observed against
certbot 2.6.0 on the live host; see `specs/review/`). So the auth and cleanup
hooks are `opsctl dns acme-auth` and `opsctl dns acme-cleanup`, and the deploy
hook is `systemctl try-reload-or-restart nginx`, which reloads a running nginx,
does nothing for a stopped one, and fails when the reload fails.

## REQUIREMENTS

- R-YBCV-JK0W: Package `internal/cert` MUST own obtaining and inspecting the host certificate, depend within this module only on `internal/host`, and leave command parsing, configuration-store reads, output formatting, and exit codes to `internal/cli`.
- R-YCKR-XBRL: Package `internal/cert` MUST export `Obtain(ctx context.Context, env host.Env, hostName, email string) error`.
- R-YDSO-B3IA: Package `internal/cert` MUST export `Info` with exactly the fields `Names []string`, `Issuer string`, and `Expires time.Time`.
- R-YF0K-OV8Z: Package `internal/cert` MUST export `Inspect(env host.Env, hostName string) (Info, error)`.
- R-YG8H-2MZO: Package `internal/cert` MUST export the sentinel error `ErrNotFound`.
- R-YHGD-GEQD: `opsctl cert --help` and `opsctl cert -h` MUST, for any effective uid and without reading configuration, executing commands, or changing host state, exit 0 with empty stderr and stdout exactly `"Usage: opsctl cert <subcommand>\n\nObtain and inspect the one certificate this host serves: host.name and\n*.host.name, proved over DNS-01 through 'opsctl dns acme-auth'.\n\nSubcommands:\n  show    print the certificate's names, issuer, and expiry\n  obtain  obtain the certificate, or renew it if it is due\n\nConfiguration keys:\n  acme.email  the address the CA sends expiry warnings to\n  host.name   the fully-qualified name this host answers at\n\nRenewal is certbot's: 'certbot renew' re-runs the same hooks and reloads\nnginx, with no further configuration. 'opsctl init' writes the timer that\nruns it twice a day, ikigenba-renew-certificate.timer.\n"`, where `\n` denotes LF.
- R-YIO9-U6H2: The `cert` command MUST accept exactly `show` and `obtain`, each without options or positional arguments; non-help invocations MUST obey D02's root check, and a root invocation with no subcommand or an unknown subcommand MUST leave state unchanged, write no stdout, exit 2, and write respectively `"opsctl: no cert subcommand given\n\nsee 'opsctl cert --help' for usage\n"` or `"opsctl: unknown cert subcommand '<name>'\n\nsee 'opsctl cert --help' for usage\n"` to stderr, substituting the given subcommand for `<name>`; invalid extra arguments or options MUST likewise fail with exit 2 and a D02 diagnostic before configuration reads or external execution.
- R-YJW6-7Y7R: Before a root `cert show` or `cert obtain` action, the CLI MUST read `host.name` from `config.Store` rooted at `Deps.Root`, and before `obtain` additionally read `acme.email` from that store; checking `host.name` first, an unset or empty required value MUST produce exactly `opsctl: <key> not set` followed by LF on stderr, empty stdout, exit 1, and no external execution or state change, while any other store error MUST produce a D02 diagnostic and exit 1 without running the certificate operation.
- R-FRFQ-VNTM: `Obtain` MUST reject an empty `hostName` with an error whose text is exactly `host.name not set`, or, when `hostName` is nonempty and `email` is empty, with an error whose text is exactly `acme.email not set`; these checks MUST precede any external execution or state change, including when called by init, and a rejected call MUST invoke no `env.Execute` and leave host state unchanged.
- R-K9Q8-1AET: For a nonempty DNS `hostName` and nonempty `email`, `Obtain` MUST execute `certbot` once through `env.Execute` with ordered arguments `["certonly", "--non-interactive", "--agree-tos", "--email", email, "--manual", "--preferred-challenges", "dns", "--manual-auth-hook", "opsctl dns acme-auth", "--manual-cleanup-hook", "opsctl dns acme-cleanup", "--deploy-hook", "systemctl try-reload-or-restart nginx", "--cert-name", hostName, "-d", hostName, "-d", "*." + hostName, "--keep-until-expiring", "--config-dir", C, "--work-dir", W, "--logs-dir", L]`, where C, W, and L are respectively `/etc/letsencrypt`, `/var/lib/letsencrypt`, and `/var/log/letsencrypt` resolved under `env.Root`; it MUST pass the supplied context, use empty `Dir`, nil `Env`, and nil `Stdin`, and MUST NOT request forced renewal or directly write DNS records.
- R-KAY4-F25I: Every hook value `Obtain` passes to `certbot` (the `--manual-auth-hook`, `--manual-cleanup-hook`, and `--deploy-hook` arguments) MUST, when split into words the way a POSIX shell splits a command line, begin with the bare name of an executable that resolves on PATH, and MUST NOT begin with a shell keyword, operator, or compound command, because certbot resolves each hook's first word on PATH before performing any ACME work and refuses the invocation when it does not resolve.
- R-YMBY-ZHP5: Successful `Obtain` for an absent or due certificate MUST establish certbot's lineage `/etc/letsencrypt/live/<hostName>/` under `env.Root` containing `fullchain.pem` and `privkey.pem` for both `hostName` and `*.<hostName>`, with renewal configuration retaining the authentication, cleanup, and deploy hooks from the obtain invocation so subsequent `certbot renew` uses those hooks without further configuration; successful DNS challenges MUST leave none of their added TXT values behind.
- R-YNJV-D9FU: `Obtain` on a certificate that certbot considers not due MUST succeed without changing the certificate, writing DNS records, or requesting issuance from the CA; certbot owns the due decision and `Obtain` MUST NOT impose a separate renewal threshold.
- R-YORR-R16J: A failed certbot invocation in `Obtain` MUST return an error containing `*host.CommandError` with `Label` equal to `certbot certonly`, preserving its `Result` and execution `Err`; a successful execution with `ExitCode` 0 MUST return nil, and captured subprocess output MUST remain available on failure and MUST NOT itself be printed by the package.
- R-3Y2Q-E7IX: When the CA refuses issuance, `Obtain` MUST leave any earlier certificate unchanged and nginx serving it, publish no replacement certificate, and use the recorded cleanup hook to remove every challenge value whose cleanup certbot reaches.
- R-YR7K-IKNX: `Inspect` MUST read the first PEM certificate in `/etc/letsencrypt/live/<hostName>/fullchain.pem` resolved under `env.Root`, return its DNS subject alternative names in encoded order in `Names`, its issuer common name in `Issuer` (or the issuer distinguished-name string when the common name is empty), and its NotAfter instant in `Expires`; it MUST perform no writes, external execution, or network requests and MUST report expired certificates as certificate data rather than an operation failure.
- R-YSFG-WCEM: When the lineage directory or its `fullchain.pem` is absent, `Inspect` MUST return an error matching `ErrNotFound` through `errors.Is` and having exactly the text `no certificate for <hostName>`; unreadable files, missing PEM certificate blocks, and invalid X.509 certificate data MUST return an operational error rather than successful empty information.
- R-YTND-A45B: A root `opsctl cert show` with nonempty `host.name` MUST call `Inspect` with that host name and the host environment from `Deps`, exit 0 on success with empty stderr and exactly three LF-terminated stdout lines `names: <names>`, `issuer: <issuer>`, and `expires: <expires>`, where names are `Info.Names` joined with comma-space, issuer is `Info.Issuer`, and expires is `Info.Expires` formatted in UTC as RFC3339 with seconds and a `Z` suffix.
- R-YUV9-NVW0: A failing `cert show` MUST exit 1 with empty stdout, one LF-terminated `opsctl: <error>` diagnostic on stderr, and no state change; for missing `ikigenba.dev` this MUST be exactly `opsctl: no certificate for ikigenba.dev` followed by LF.
- R-YXB2-FFDE: A root `opsctl cert obtain` with its required configuration MUST call `Obtain` with the host environment from `Deps`, the configured host name and ACME email, exit 0 with empty stdout and stderr on nil error, and otherwise exit 1 with empty stdout and D02's diagnostic including captured external output; a completed certbot exit status 1 MUST begin with exactly `opsctl: certbot certonly: exit status 1` followed by LF, and any captured detail MUST follow one blank line with every line prefixed `> `.
- R-YYIY-T743: The certificate workflow MUST use D05's `certificate` init step before `nginx.conf`, D04's DNS authentication and cleanup hooks, D12's always-enabled twice-daily persistent renewal timer and service, and the host-backup contract's inclusion of `/etc/letsencrypt`; `cert` MUST expose no renewal subcommand or configurable renewal period and MUST leave scheduled timer creation and masking of the package timer to the init `timers` step.
