# D09-per-app-host

A *per-app host* (D08) is the legacy layout: no `/opt/ikigenba/current`, and
each app under `/opt/<app>/` holding `bin/`, `etc/`, and `share/`, run by a
socket unit and a service unit that name `/opt/<app>/bin/<app>`. No command
creates that layout any more; a host that has it keeps it until its first
activate cuts it over (D18). Until then three things still write its apps'
files, and this design owns what they write: `init`'s `apps` step rewrites
every app's timing settings and service unit (`SetupTimeouts`), and `restore`
writes a restored app's environment file (D14). The slice units every host
runs in are `init`'s too, and are stated here beside them (`SetupSlices`).

The per-app service unit is the one the per-app layout runs: it names the
app's binary under `/opt/<app>/`, its data directory as its working directory
(D08), its environment file, the stop timeout, and the resource settings its
manifest declares, defaults filled in, as systemd.resource-control(5) and
systemd.service(5) document them. It sets no `KillMode=`, so by systemd's
default `KillMode=control-group` (systemd.kill(5)) everything the app starts
counts against its limits and stops with it. `SetupTimeouts` rewrites it only
with the resources the installed manifest declares, so `init` never loosens or
drops a limit, and it rewrites no socket unit.

The per-app environment file is `/etc/opt/ikigenba/<app>/env` (D08), owned by
root alone in a directory of its own. It holds the app's secrets from the
parameter `/<host.name>/<app>`, the manifest's `[env]`, `DRAIN_SECONDS`, and
`IKIGENBA_SERVICES` naming the per-app services file,
`/var/lib/ikigenba/services.json`. A restore writes it whole; `SetupTimeouts`
edits only its `DRAIN_SECONDS` and `IKIGENBA_SERVICES` lines and refuses an
app that has none, since it reads no parameter. An app laid out before the
file lived there keeps it at `/opt/<app>/etc/env`, which nothing reads but a
unit written in those days.

The slices are `init`'s: `SetupSlices` writes `ikigenba.slice` (80% of the
host's `MemTotal`), `ikigenba-core.slice`, `ikigenba-apps.slice` (two thirds
of the first, with a `MemoryHigh` of fifteen sixteenths of its own), and
nginx's drop-in that puts nginx in the core slice, reloading systemd only when
a file's bytes changed and restarting nginx only when its drop-in did, since a
running service changes slice only when it starts. `activate` reads the slice
units, not the host's memory (D18).

## REQUIREMENTS

- R-CZG7-Z276: An app `<app>`'s *per-app service unit*, for a stop value `t` and a `Resources` `r` (D08), MUST be exactly the bytes `"[Unit]\nDescription=Ikigenba <app> app\nRequires=ikigenba-<app>.socket\nAfter=ikigenba-<app>.socket\n\n[Service]\nType=notify\nExecStart={O}/bin/<app>\nWorkingDirectory={D}\nEnvironmentFile={E}\nUser=ikigenba\nRestart=on-failure\nTimeoutStopSec={T}\n{R}\n[Install]\nWantedBy=multi-user.target\n"`, where `\n` denotes one LF byte, `<app>` is the app name, `{O}` is `/opt/<app>`, `{E}` is the app's environment file `/etc/opt/ikigenba/<app>/env` (D08 R-9571-QYXP), and `{D}` is the app's data directory `/var/opt/ikigenba/<app>` (D08 R-CVSI-TQZ3) without a trailing slash, each resolved under `env.Root` by D01's root boundary, `{T}` is `t` in decimal without leading zeros, and `{R}` is, for `r`, `Slice=ikigenba-<s>.slice\n` with `<s>` its `Slice`, then `CPUWeight=<c>\n`, then `MemoryMax=<m>\n` with `<m>` its `MemoryMax` byte count, then `MemoryLow=32M\n` exactly when `Slice` is `core`, then `Environment=GOMEMLIMIT=<g>\n` with `<g>` its `GoMemoryLimit` byte count, then `Delegate=yes\n` exactly when `Delegate` is true, then `OOMPolicy=continue\n` exactly when `OOMPolicy` is `continue`, every number in decimal without leading zeros; so a manifest with no `[resources]` gives `{R}` exactly `Slice=ikigenba-apps.slice\nCPUWeight=100\nMemoryMax=134217728\nEnvironment=GOMEMLIMIT=100663296\n`, and one whose table holds `slice = "core"` and `memory_max = "256M"` gives `Slice=ikigenba-core.slice\nCPUWeight=100\nMemoryMax=268435456\nMemoryLow=32M\nEnvironment=GOMEMLIMIT=201326592\n`; it holds no `IOWeight=` and no `KillMode=` line.
- R-UUUF-JC2O: Package `internal/apps` MUST export `SetupTimeouts(ctx context.Context, env host.Env, store config.Store) error`.
- R-CM1B-RL1J: `SetupTimeouts` MUST obtain the timing settings through `ReadTimeouts` and return its error before any write. It MUST treat as installed apps exactly the services `Discover` returns whose name `ValidateName` accepts and that hold a regular file `/opt/<name>/bin/<name>`, and for each MUST set the `DRAIN_SECONDS` entry of its environment file (D08 R-9571-QYXP) to the drain value in decimal without leading zeros, replacing an existing `DRAIN_SECONDS` entry in place or appending one when absent, and MUST set its `apps.ServicesEnv` entry to exactly `apps.PerAppServicesPath` (D08 R-93Z5-D770), unquoted, replacing an existing entry for that name in place or appending one after any appended `DRAIN_SECONDS` entry when absent, leaving every other line byte-identical, owned `root:root` with mode `0600`, and MUST make `/etc/systemd/system/ikigenba-<name>.service` hold the per-app service unit (R-CZG7-Z276) for that name, the stop value, and the `Resources` of the `Manifest` `Discover` returned for that service (the defaults D08 gives a manifest with no `[resources]` when it has no manifest), so a rewritten unit keeps the resource settings its manifest declares, and a unit file whose resource lines differ from what the installed manifest declares is rewritten to the manifest's. Before any write it MUST examine every installed app, and when any has no entry named `env` in `/etc/opt/ikigenba/<name>/`, judged without following a symbolic link, it MUST return, for the first such app in ascending name order and ahead of any manifest fault, an error identifying the app whose `Error()` is exactly `<name>: /opt/<name>/etc/env has not moved`, the paths written as host paths rather than resolved under `env.Root`, so an installed `crm` with no environment file stops it, `init` writes `opsctl: crm: /opt/crm/etc/env has not moved` (D05 R-LXGW-8J1R), and no app's files change. Otherwise, before any write, when any installed app carries a `ManifestError` it MUST return, for the first such app in ascending name order, an error identifying the app, whose `Error()` is exactly `<name>: etc/manifest.toml: <reason>` with `<reason>` the `Error()` of `ParseManifest` on that manifest's bytes when `ParseManifest` rejects them, so an installed `repos` whose manifest holds `io_weight = 50` stops it with `repos: etc/manifest.toml: 'resources.io_weight' is not allowed; the resources are slice, memory_max, go_memory_limit, cpu_weight, delegate, and oom_policy` and no app's files change. It MUST judge only what `ParseManifest` judges: it MUST NOT read the slice units, refuse an app whose `MemoryMax` exceeds a slice's, or report oversubscription; an app's settings changed exactly when either file's bytes differ from their previous bytes, and a file whose bytes would not change MUST NOT be rewritten. An environment file of an installed app that is present but cannot be read MUST return an error identifying the app, and `SetupTimeouts` MUST NOT create an environment file or directory, `EnvRoot`, or `/etc/opt/`, nor read or write `/opt/<name>/etc/env`. Services that are not installed apps MUST NOT be written, and no unit may be created for them.
- R-Y1GZ-HRRY: After its writes `SetupTimeouts` MUST execute `systemctl daemon-reload` exactly when some service unit file changed, then, in ascending name order, `systemctl restart ikigenba-<name>.service` for every installed app whose settings changed, which `Disabled` (D10) does not report disabled, and whose `ikigenba-<name>.socket` is active, so every running app, idle service included, runs with the new values, while an app whose socket an operator stopped is not started and takes them at its next start; it MUST NOT start, restart, enable, or disable either unit of a disabled app or of an app whose settings did not change, and MUST NOT stop, start, or restart any socket unit, so a disabled app is rewritten and left disabled. A rerun with unchanged settings MUST write no file and execute no `systemctl` command other than the read-only `Disabled` query.
- R-ZI7A-VEAB: `SetupTimeouts` MUST return discovery, configuration, filesystem, and unit-operation failures as errors, representing execution failures and nonzero process exits with `host.CommandError`, perform no later action after a failure, and preserve earlier effects without rollback; it MUST NOT change the store, anything under `/var/opt/ikigenba/`, anything under `/opt/<name>/state/` or `/opt/<name>/cache/`, any socket unit file, or any file other than the environment files and service unit files it is specified to write, and it MUST create no `/opt/<name>/` for a service that is not an installed app.

- R-T787-GQP5: On a per-app host, an app's secrets MUST be obtained for every distinct name in `Manifest.Secrets` from the parameter `/<host.name>/<app>`, where `<host.name>` is the normalised host name (`host.NormalizeName` of the `host.name` store value), through `Client.ReadSecrets`, skipping the parameter read for an empty secret list, omitting unrequested parameter keys, and treating a missing parameter as containing no keys, and MUST report the first missing name in manifest order as `<app>: no value for '<name>' in /<host.name>/<app>` with that same normalised host name; an empty present value MUST count as present.
- R-T8G3-UIFU: On a per-app host, opsctl MUST validate that an app's secret and plain-setting names match `[A-Za-z_][A-Za-z0-9_]*`, that neither source defines `DRAIN_SECONDS` or the name `apps.ServicesEnv` holds, that the two sources have no overlapping names, and that values contain no NUL, CR or LF, rejecting violations before writing anything without printing their values; the app's environment file (D08 R-9571-QYXP) MUST hold one LF-terminated `NAME=value` entry per requested secret and plain setting plus `DRAIN_SECONDS=<n>`, where `<n>` is the `Timeouts.DrainSeconds` value `ReadTimeouts` (D08) returned, in decimal without leading zeros, and, for every app, the unquoted entry `apps.ServicesEnv`, `=`, `apps.PerAppServicesPath` (D08 R-93Z5-D770), that is `IKIGENBA_SERVICES=/var/lib/ikigenba/services.json`, the per-app host's services file; the other values MUST be encoded for systemd EnvironmentFile syntax to preserve their literal value, and the file MUST hold no `PORT` entry and no other parameter keys.
- R-T9O0-8A6J: *Writing a per-app environment file* MUST leave, under `env.Root`, `/etc/opt/`, `/etc/opt/ikigenba/` (`EnvRoot`, D08 R-02XL-DHW4), and the app's environment directory `/etc/opt/ikigenba/<app>/` (D08 R-9571-QYXP) present, each it creates owned by user `root` and group `root` (`root:root`) with its mode set to `0755` directly under `env.Root` whatever the process umask, so a test observes it with `Lstat`, and each that already exists unchanged in ownership and mode; it MUST then replace the environment file whole with exactly the bytes R-T8G3-UIFU specifies, never editing the previous file in place or keeping any line of it, owned `root:root` with mode `0600` set directly under `env.Root`, by writing a temporary file in the environment directory and renaming it over the destination, leaving no temporary file behind, creating nothing else in the environment directory, and executing no `chown` that names `/etc/opt/` or any path beneath it.

- R-02VD-34HM: Package `internal/apps` MUST export `SetupSlices(ctx context.Context, env host.Env) error`.
- R-NN3P-UABM: `SetupSlices` MUST read `/proc/meminfo` under `env.Root` and take the host's memory `B` as 1024 times the decimal count on its line made of `MemTotal:`, one or more spaces, that count, and ` kB` (so `MemTotal:       1954816 kB` and `MemTotal: 1954816 kB` both read 1954816); from it, `T` MUST be the multiple of 67108864 (64 MiB) nearest to four fifths of `B`, the larger on a tie, `A` the multiple of 67108864 nearest to two thirds of `T`, and `H` fifteen sixteenths of `A` rounded down to a multiple of 1048576, each written below as its number of MiB followed by `M`. It MUST make `/etc/systemd/system/ikigenba.slice` hold exactly `"[Unit]\nDescription=Ikigenba suite\n\n[Slice]\nCPUWeight=100\nMemoryMax=<T>\n"`, `/etc/systemd/system/ikigenba-core.slice` exactly `"[Unit]\nDescription=Ikigenba core\n\n[Slice]\nCPUWeight=300\n"`, `/etc/systemd/system/ikigenba-apps.slice` exactly `"[Unit]\nDescription=Ikigenba apps\n\n[Slice]\nCPUWeight=100\nMemoryMax=<A>\nMemoryHigh=<H>\n"`, and `/etc/systemd/system/nginx.service.d/ikigenba.conf` exactly `"[Service]\nSlice=ikigenba-core.slice\nCPUWeight=100\nMemoryMax=128M\nMemoryLow=32M\n"`, each under `env.Root` and each with mode `0644` after the call, creating `nginx.service.d/` with mode `0755` when absent; so `MemTotal: 1954816 kB` gives `MemoryMax=1536M`, `MemoryMax=1024M`, and `MemoryHigh=960M`, and `MemTotal: 3964928 kB` gives `MemoryMax=3072M`, `MemoryMax=2048M`, and `MemoryHigh=1920M`.
- R-IEQF-0ZI8: `SetupSlices` MUST write its files in the order `ikigenba.slice`, `ikigenba-core.slice`, `ikigenba-apps.slice`, then the nginx drop-in, and MUST NOT rewrite a file whose bytes and mode would not change; after its writes it MUST execute `systemctl daemon-reload` exactly when one of its four files was created or its bytes changed, and then `systemctl restart nginx` exactly when the drop-in was created or its bytes changed, and no other command, a file whose bytes are already right but whose mode is not `0644` having its mode set without either command, so a rerun with the same `MemTotal` writes no file and executes nothing, and a rerun after `MemTotal` changed rewrites only the slice units whose bytes change, reloads, and does not restart nginx or any app.
- R-Y2EV-URH5: `SetupSlices` MUST return an error identifying `/proc/meminfo`, before writing any file or executing any command, when that file cannot be read, holds no `MemTotal:` line of the form R-NN3P-UABM reads, gives a count whose byte count exceeds 9223372036854775807, or gives a `T` of zero; it MUST return filesystem and unit-operation failures as errors, representing execution failures and nonzero process exits with `host.CommandError`, perform no later action after a failure, and preserve earlier effects without rollback; and it MUST NOT change the store, any app's files or units, or any file other than its four.
