# Decision 16 — Stage preflight without the retired manifest verb; one version channel

**Decision.** `stage`'s preflight — the gate that refuses a bad bundled binary
before any tier is placed — is specified here (it previously existed only in
code), and two of its mechanisms change to conform to suite contracts opsctl
does not own.

**What preflight checks, in order** (in `internal/opsctl/preflight.go`, called
from `Stage` before tier placement):

1. **Static ELF** — the bundled binary parses as a static linux/amd64 ELF (no
   `PT_INTERP`, no `DT_NEEDED`). Unchanged.
2. **Version self-report** — run the binary's `version` verb; the output must
   be a valid full version (`root project/design/D03.md`) and equal the stage
   version argument. The box cannot lie about what is deployed. Unchanged.
3. **App identity from the authored tier** — `APP=` is read from the bundle's
   **own `etc/<version>/manifest.env`** (already unpacked into the stage
   scratch tree) and must equal the app argument. This **replaces** running the
   binary's `manifest` verb: that verb is retired by the umbrella's reduced
   verb set (`root project/design/D11.md` — config is authored input, not
   binary output), so a conforming binary answers it with an unknown-verb
   error and the old preflight would refuse every valid bundle. The authored
   file the bundle carries is the identity of record; preflight reads it
   directly and **never invokes a `manifest` verb**.

**The dead second version channel is deleted.** `commitToken` parsed a
`(<sha>[-dirty])` suffix out of `version` output — a form no shipped binary has
ever emitted, because the SHA travels *inside* the full version identity as
`+<sha>` build metadata (`root project/design/D03.md`), not beside it.
`commitToken` and its call sites go:

- The **stage collision guard** compares the staged and incoming **artifact
  bytes** (content hash), exactly as D15's stage step 2 already states —
  identical bytes → idempotent no-op; differing bytes → loud refusal without
  `--force`. Comparing always-empty commit tokens had reduced the guard to a
  silent always-no-op: a differing rebuild of an already-staged version was
  silently kept stale, the precise failure D15's Rejected list exists to
  prevent. Bytes are the discriminating property; they also catch two `-dirty`
  builds that self-report identically.
- **`status`** drops its commit column: the version string it already shows
  carries the `+<sha>` identity, so there is nothing separate to display.

**Rejected.**
- *Keep running the `manifest` verb in preflight.* Retired suite-wide by
  `root project/design/D11.md`; the moment the chassis conforms, every stage of
  every new bundle fails. Rejected.
- *Derive `APP` from the binary some other way (flag, env probe).* Recreates
  "config as binary output" under a new spelling; the bundle already carries
  the authored identity file that dev, prod, and the dashboard inventory all
  read. Rejected.
- *Keep `commitToken` and make `ship` stamp a commit.* A second channel for a
  fact the version identity already carries, plus parsing rules for a
  parenthesized form nothing else uses. Rejected — one version channel.
- *Compare version self-reports in the collision guard instead of bytes.* Two
  differing `-dirty` builds self-report identically, and D15 already promises
  bytes. Rejected.

**Verification.**
- R-TA75-P0NF — `stage` preflight refuses (non-zero, nothing placed) a bundle
  whose `etc/<version>/manifest.env` carries an `APP=` differing from the app
  argument, and accepts one whose `APP=` matches — with the `AppRunner` seam
  recording **no** `manifest` verb invocation in either case, even against a
  fake binary that would answer it. Substrate: opsctl unit test (fake runner
  recording verbs, real temp-dir bundle tree).
- R-TBF2-2SE4 — the stage collision guard is byte-based: re-staging an
  already-present version with a byte-identical artifact is an idempotent
  no-op, while a byte-differing artifact for the same version is refused
  without `--force` — falsified by the always-empty-token comparison this
  replaces, which no-ops both cases. Substrate: opsctl unit test (real
  temp-dir files with controlled bytes).
