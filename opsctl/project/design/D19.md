# Decision 19 — `opsctl seed-state`: bootstrap a rotating credential into a service's `state/`

**Decision.** opsctl gains the box-side half of the suite's rotating-credential
contract (`root project/design/D32.md`, channel 5): a generic one-off verb that
writes a **named rotating credential** into a service's `state/` on the box. This
Decision owns the verb's local shape (CLI, value ingress, path composition, error
surface); the contract it conforms to — that such a value is per-environment,
single-holder, never pushed, and owned by the service after bootstrap — is the
umbrella's and is cited, never restated.

**The verb.**

    opsctl seed-state <svc> <NAME> [--force]

- **Value ingress is stdin, never argv.** The credential value is read from
  standard input, so it never appears on a command line or in the process table
  — the same value discipline `bin/push-secrets` uses for a pushed secret. A
  trailing newline is trimmed; interior bytes are preserved verbatim.
- **Path is composed, not configured.** The target is
  `${IKIGENBA_ROOT}/<svc>/state/<NAME>`, composed from the box-global
  `IKIGENBA_ROOT` opsctl already loads at startup (D3) exactly as every other
  `state/` path is composed (`root project/design/D05.md`,
  `root project/design/D11.md`). No new configuration knob: the operator names
  the service and the credential, and the location follows.
- **Write is `0600`, owned by the service user.** The file is created mode
  `0600` under the service's `state/` (the backed-up region,
  `root project/design/D05.md`), owned by the service user like the rest of
  `state/`, written atomically (temp file in the same dir, then rename).
- **Write-once, `--force` to replace.** If the target file already exists the
  verb **refuses and changes nothing** (non-zero exit), because the service may
  already have rotated the credential and a re-seed would destroy the current
  token. `--force` replaces it deliberately, for a re-bootstrap paired
  out-of-band with revoking the old grant.
- **Error surface.** Refuses (non-zero, no write) on: an existing file without
  `--force`; an unknown `<svc>` (no `${IKIGENBA_ROOT}/<svc>/` tree); an unset
  `IKIGENBA_ROOT`; or empty stdin. Each names the service and the credential so
  a failed bootstrap is legible, never silent.

**Local development uses the same verb** against the local checkout's `state/`
(with `IKIGENBA_ROOT` pointing at it), so dev and prod are each seeded once with
their own independently-consented value and never share one — the property the
contract exists to guarantee.

**Rejected.**
- *Taking the value as a positional argument.* Puts the credential on the command
  line and in the process table and any shell history. Rejected — stdin only.
- *Overwriting by default.* A routine re-run would silently destroy a token the
  service had already rotated to. Rejected — write-once, explicit `--force`.
- *A credential-specific verb per service (`seed-gmail-token`).* The contract is
  generic — one write-once state-file seed serves every rotating credential of
  every service. Rejected — one verb, parameterized by `<svc> <NAME>`.
- *Writing into the service's SQLite DB.* Couples opsctl to another process's
  schema and locks; the contract makes the value a plain `state/` file for
  exactly this reason (`root project/design/D32.md`). Rejected.

**Verification.** The two behaviors this verb realizes are the umbrella
contract's, minted there and marked `[proof: opsctl]` — opsctl is the named tree
that carries their tagged tests; this Decision owns the verb's shape but not the
contract, and mints **no ids of its own** (the two contract behaviors are the
verb's whole observable surface).

- R-EK9S-F7RY (owned by `root project/design/D32.md`, `[proof: opsctl]`) — the
  verb, fed a value on stdin, writes `${IKIGENBA_ROOT}/<svc>/state/<NAME>` as a
  `0600` file whose bytes equal the supplied value (trailing newline trimmed).
  Substrate: opsctl unit test over a real temp-dir `IKIGENBA_ROOT` tree.
- R-ELHO-SZIN (owned by `root project/design/D32.md`, `[proof: opsctl]`) — run
  against an already-present credential file the verb refuses and leaves the file
  byte-unchanged (non-zero exit); with `--force` it replaces the file. Substrate:
  opsctl unit test over a real temp-dir tree with a pre-existing file.
