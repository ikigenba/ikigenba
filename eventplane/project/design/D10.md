# Decision 10 — Adopt the suite testing-language contract

**Decision.** eventplane adopts the suite's testing-language contract, `root
project/design/D23.md`, by citation. That contract owns the four test layers
(**hermetic / composed / live / manual**) and what each may touch, the single
mechanism for live tests (`//go:build live`, invoked as `go test -tags live
./...`, hard-failing on absent credentials), the ban on `t.Skip` outside
live-tagged files, and the requirement that every tree declare its own testing
facts in its `AGENTS.md`. This Decision restates none of it. It records only the
eventplane-specific facts the contract asks this tree to declare, and adopts the
contract's two per-service ids.

**The layers eventplane has.** eventplane is a library — no binary, no port, no
deploy — and its whole suite is **hermetic**:

- `outbox` DDL, append atomicity, backpressure, correlation and retention claims
  run against real `t.TempDir()` SQLite databases through `modernc.org/sqlite`
  and the real schema;
- feed and consumer wire claims run the real `outbox.FeedHandler()` in an
  `httptest.Server` with a real HTTP client, or a real `consumer.Run` on the
  other end of it — loopback listeners only;
- `routing` and `correlation` are pure and table-tested;
- `observe`'s import-discipline claim execs `go list -deps` — a local subprocess,
  which the contract's hermetic layer admits explicitly.

eventplane has **no composed layer** (there is no eventplane binary to build and
run), **no live layer** (it touches no external service and reads no credential,
so no `//go:build live` file exists here and the `-tags live` invocation is not
part of this tree's testing story), and **no manual layer** (no committed
runbook: every claim in this design is reachable from the default gate).

**GOWORK mode: workspace.** eventplane tests, vets, and builds in **workspace
mode** through the repo-root `go.work`; **`GOWORK=off` is deliberately not set
here.** The contract declines to unify GOWORK mode across the suite precisely
because the split is load-bearing, and eventplane sits on the library side: it
is consumed in-repo through committed `replace` directives and has no
standalone production build to mirror. Forcing `GOWORK=off` would prove nothing
this tree ships and would break local resolution of its in-repo siblings.

**Environmental preconditions beyond the Go toolchain.** eventplane has one: the
`observe` import-discipline test shells out to `go list -deps` **at test time**,
so the `go` binary must be on `PATH` in the test process's environment (not
merely the toolchain that compiled the tests), with a module cache that already
resolves this module's dependencies — the test does no network fetch and must
not acquire one. This is a hard failure when absent, never a skip.

**Where this lands.** No eventplane source outside the test files changes. The
adoption is carried by two tagged tests and by the `AGENTS.md` Tests section
stating the facts above; the plan phase that realizes this Decision does both.

**Rejected.**

- *Restating the layer definitions, the live-tag mechanism, or the skip ban in
  this design.* Citation is the mechanism (`$ikispec`, "cite, never restate"): a
  local copy of a suite contract is drift by construction the moment the
  umbrella moves. This file names only what is particular to eventplane.
- *Re-minting local ids for the two behaviors.* The umbrella marks
  R-O1AD-MRKW and R-O2IA-0JBL `[proof: per-service]`; citing those exact ids is
  the adoption, and a fresh local id would be a second handle for one behavior.
- *Adding `GOWORK=off` checks to match `registry`.* The two trees differ on
  purpose — see above. Uniformity here would be cosmetic and would cost real
  resolution correctness.
- *Treating eventplane as exempt from the per-service ids because it is a
  library.* This design's *Conventions* correctly say eventplane never adopts a
  per-service **behavioral** contract on a service's behalf. These two ids are
  different in kind: they prove facts about **this tree's own** committed
  `AGENTS.md` and **this tree's own** test sources, which exist here and nowhere
  else.

**Verification.**

- R-O1AD-MRKW — cited from `root project/design/D23.md` (`[proof:
  per-service]`); adopted here. A test reads eventplane's committed `AGENTS.md`
  from disk and asserts its Tests section declares the default-gate test
  command, the layers present in this tree's contract vocabulary, every
  environmental precondition beyond the Go toolchain, and the tree's GOWORK
  mode. Substrate: hermetic (real committed file read from disk).
- R-O2IA-0JBL — cited from `root project/design/D23.md` (`[proof:
  per-service]`); adopted here. A source scan over eventplane's `*_test.go`
  files, excluding files carrying the `live` build constraint, finds **zero**
  occurrences of `t.Skip`, `t.Skipf`, or `t.SkipNow`. The scan assembles its
  needle from parts so it never matches itself. Substrate: hermetic (source
  scan).
