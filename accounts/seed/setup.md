# Setup

Walk the user through the questions below, one at a time.

- Write each answer into `team.md` as soon as it is given, so a walk-through that stops can be picked up later by anyone.
- If `team.md` already holds an answer, don't ask for it again.

## Questions

1. What is the team or business called?
2. What does it do, in a sentence or two?
3. Who is on the team, and what does each person do?

## Where the answers go

Write `team.md` in this shape:

```
# <the name>

<what it does>

## People

- <person>: <what they do>
```

## When every question is answered

1. In `AGENTS.md`, replace the whole Setup section with this line: `team.md` says who the team is and what it does.
2. Delete `setup.md`.
3. Commit.
