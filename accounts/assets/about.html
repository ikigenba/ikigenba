How it works

accounts runs SSH as a service. It keeps a fleet of machines, hosts, named host01, host02 and on in order, each with an Elastic IP, a data volume holding /home and /srv, and SSH host keys kept on that volume, so a host keeps its address, its data and its identity across stop, start and resize. A host starts on the type and sizes the tools choose, a {{.DefaultType}} with a {{.DefaultRootGB}} GB root and a {{.DefaultDataGB}} GB data volume when they choose none; changing its type stops and starts it, and volumes only grow. Long operations run in the background: a host shows provisioning, running, stopping, stopped, starting, resizing, deleting or failed with its reason, and a failed operation can be retried.

An account is one business, placed on one host. Its slug names a Linux group, a service account of the same name and the folder /srv/<account>, which every user of the account writes to and nobody else reads, and reserves the DNS name <account>.<hosts domain>, which points at its host. Each account runs in a slice of its own with an equal share of the host's CPU and a memory ceiling, so one busy business slows only itself. Account slugs and user names are unique across every host. An account with users cannot be removed, and removing an empty one leaves its folder on the data volume; a host with accounts cannot be deleted, and deleting an empty one keeps its data volume.

A user is a person in exactly one account, with a login name, one or more ed25519 public keys and a state, active or locked. They sign in with ssh <user>@<account>.<hosts domain> and a key, never a password, and get a home readable by them alone. Locking a user ends their access and keeps their home; only a locked user can be deleted, which removes their home. Each host runs a daemon that fetches what the host should hold and makes it so, and reports back each cycle; a change shows as pending until the host reports it applied. A host keeps working with what it last applied when accounts cannot be reached.

Every change is made by an agent with the tools, and each change, and each host going silent, coming back in sync or failing to apply, is recorded in telemetry. This page only shows the hosts, accounts and users.
