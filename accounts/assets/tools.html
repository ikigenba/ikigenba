Tools

Agents run SSH hosting with these tools, through the MCP gateway's call and mutate: they create, stop, start, resize and delete hosts, keeping a deleted host's data volume or deleting it with the host, list and delete the data volumes kept from deleted hosts, create accounts on a host and remove them, add users to an account with a key, add and remove keys, lock, unlock and delete users, set or clear a user's admin flag, make, list and revoke the invite links a person joins an account by, lift an address's ban and allow or disallow an address on a host, close a host and confirm it is fully backed up, open it again, put a host on a new machine keeping its data volume or restored from backup, read each account's backup health and what can be restored, restore a database or files as of an earlier time beside the originals, delete the backups of a removed account, and list and read them all. A tool records the change and returns at once; an invite's link is answered once, when it is made; a host's state, a restore, and a pending user or key, show when it is done. On a space that operates no hosts the host and account tools refuse, saying the space is not configured.
