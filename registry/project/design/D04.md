# Decision 4 — Adopt the suite testing-language contract

**Decision.** registry adopts the suite's testing-language contract, `root
project/design/D23.md`, by citation. That contract owns the four test layers
(**hermetic / composed / live / manual**) and what each may touch, the single
mechanism for live tests (`//go:build live`, invoked as `go test -tags live
./...`, hard-failing on absent credentials), the ban on `t.Skip` outside
live-tagged files, and the requirement that every tree declare its own testing
facts in its `AGENTS.md`. This Decision restates none of it. It records only the
registry-specific facts the contract asks this tree to declare, and adopts the
contract's two per-service ids.

**The layers registry has.** registry is the smallest tree in the suite: one
flat, pure package of compile-time data and total functions over it. Every test
is **hermetic**, and trivially so — the package does no I/O, reads no
environment, and has no clock or randomness, so the tests are in-process
assertions against the real code with no substrate to reach for.

registry has **no composed layer** (it builds no binary), **no live layer** (it
touches no external service and reads no credential, so no `//go:build live`
file exists here and the `-tags live` invocation is not part of this tree's
testing story), and **no manual layer** (no committed runbook: every claim in
this design is reachable from the default gate).

**GOWORK mode: `GOWORK=off`.** registry builds and tests with **`GOWORK=off`
forced** — `GOWORK=off go build ./...` and `GOWORK=off go test ./...` from
`registry/`. This is load-bearing rather than stylistic: registry's promise is
that it resolves standalone with zero third-party dependencies, so that `opsctl`
and anyone else can adopt it without inheriting the chassis's dependency graph.
Running under the workspace would let a sibling's `replace` mask a resolution
failure the production build would hit. The contract declines to unify GOWORK
mode across the suite for exactly this reason, and registry sits on the
standalone side.

**Environmental preconditions beyond the Go toolchain: none.** The package
imports only the standard library and its tests spawn no subprocess, read no
file, and reach no network address. A working Go toolchain is the whole
requirement.

**Where this lands.** No registry source outside the test files changes. The
adoption is carried by two tagged tests in the existing package-local test home
and by the `AGENTS.md` Tests section stating the facts above; the plan phase
that realizes this Decision does both.

**Rejected.**

- *Restating the layer definitions, the live-tag mechanism, or the skip ban in
  this design.* Citation is the mechanism (`$ikispec`, "cite, never restate"): a
  local copy of a suite contract is drift by construction the moment the
  umbrella moves. This file names only what is particular to registry.
- *Re-minting local ids for the two behaviors.* The umbrella marks
  R-O1AD-MRKW and R-O2IA-0JBL `[proof: per-service]`; citing those exact ids is
  the adoption, and a fresh local id would be a second handle for one behavior.
- *Skipping the adoption because this tree is too small to have a testing
  story.* Size is not the criterion — the contract asks every tree to declare,
  and a tree with one test file is exactly where an undeclared GOWORK mode or a
  quietly-added skip would go unnoticed longest.
- *Dropping `GOWORK=off` to match the library trees.* It would erase the
  standalone-resolution proof this module exists to offer. Declared per tree, as
  the contract intends.

**Verification.**

- R-O1AD-MRKW — cited from `root project/design/D23.md` (`[proof:
  per-service]`); adopted here. A test reads registry's committed `AGENTS.md`
  from disk and asserts its Tests section declares the default-gate test
  command, the layers present in this tree's contract vocabulary, the absence of
  any environmental precondition beyond the Go toolchain, and the tree's
  `GOWORK=off` mode. Substrate: hermetic (real committed file read from disk).
- R-O2IA-0JBL — cited from `root project/design/D23.md` (`[proof:
  per-service]`); adopted here. A source scan over registry's `*_test.go` files,
  excluding files carrying the `live` build constraint, finds **zero**
  occurrences of `t.Skip`, `t.Skipf`, or `t.SkipNow`. The scan assembles its
  needle from parts so it never matches itself. Substrate: hermetic (source
  scan).
